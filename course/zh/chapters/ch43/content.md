## 1. 本章目标

1. **掌握贝叶斯共轭更新与预测分布**：从先验与似然出发，完整推导 Beta-Binomial 的后验参数 $(\alpha_{\mathrm{post}}, \beta_{\mathrm{post}})$；推导未来单期预测均值 $E[\tilde{y} \mid y]$ 与未来两期联合预测概率 $E[\tilde{y}_1 \tilde{y}_2 \mid y] = E[p^2 \mid y]$；证明两次未来的伯努利试验给定参数 $p$ 是条件独立的，但在边际后验预测分布下是相关的，其协方差严格等于后验方差 $\operatorname{Var}(p \mid y)$。
2. **理解层级模型与部分池化（Partial Pooling）的收缩机制**：以 Gelman et al. (BDA3) 第 5.4 节为基准，在已知超参数 $(\mu, \tau^2, \sigma^2)$ 条件下，推导各连续收益率资产组后验均值的精度加权收缩权重 $w_j = \frac{n_j / \sigma^2}{1/\tau^2 + n_j / \sigma^2}$；手算小样本组 ($n=4$) 与大样本组 ($n=36$) 向全市场先验均值 $\mu=0.0$ 的收缩差异，并推导包含群组不确定性与新观测噪声的后验预测方差 $\operatorname{Var}_{\mathrm{pred}, j} = V_j + \sigma^2$。明确本章限定在已知超参数的教学范围，不夸大为估计未知超参数的经验贝叶斯。
3. **建立因果图（DAG）与潜在结果框架（Potential Outcomes）**：区分统计关联 $P(Y \mid T=t)$ 与因果干预 $P(Y \mid \operatorname{do}(T=t))$；逐项列出识别因果平均处理效应（ATE）的四大假设：一致性（Consistency）、条件可交换性（Conditional Exchangeability）、正值性/重叠（Positivity / Overlap）以及稳定个体处理值假设（SUTVA，包含无个体间干扰与无隐藏处理版本）；手算 Simpson 悖论案例，说明二值成功率的未调整粗差 ($+0.38$，即 $+38$ 个百分点) 如何通过分层标准化得到负向观测差，并在识别假设下解释为ATE ($-0.10$，即 $-10$ 个百分点)；强调不能脱离识别假设将调整后关联等同于无条件真实因果；编写对撞物（Collider）偏误的可运行反例并推导负协方差 $-1/9$。
4. **规范非结构化替代数据的时点契约（PIT Contract）**：建立包含 `event_time`、`available_at`、`ingested_at`、`revision_time`、`signal_time`、`trade_time` 与 `label_available_at` 的多时区规范账本；以美股盘后 16:05 财报电话会为例，施加 20 分钟供应商延迟与 5 分钟内部入库延迟，推演夏令时（EST/EDT）与 UTC 转换规则；编写对晚于信号时间的修订版本（Amendments）与延迟入库记录的剔除逻辑；明确区分公开可访问性与商业抓取/训练/再分发授权许可边界。
5. **构建防泄漏文本预测管线与基准对齐**：使用4固定模板循环形成的120条构造业绩电话会事件（带有 `CONSTRUCTED_CALL_` 前缀，明确教学构造），严格执行训练集（59 篇）、验证集（29 篇）与测试集（30 篇）时序划分（训练与验证标签成熟时点严格在后续块首个信号时点之前成熟，`<`）；在训练窗内独立拟合词表与 IDF，冻结后投影至验证集与测试集；处理测试窗外（OOV）词汇时确保训练特征不变异；在统一的测试集上比较全局均值基准与 TF-IDF + Ridge 回归；保留低信噪比下的真实负结果（测试集 MSE $2.3603 \times 10^{-4}$ vs 均值基准 $2.3274 \times 10^{-4}$，相对 $R^2 = -0.0141$；时序汇总 Spearman 秩相关系数 $+0.0763$；明确每日仅单一资产因而截面 IC 未定义，均值常数基准秩相关未定义）；本章为 prediction-only，提供对接下游真实投资组合账本与费用测算的接口规约，不虚构轮换资产的成交换手。

7. **建立严密的大语言模型（LLM）离线研究台账**：建立离线提示词模板、版本控制与包含完整实际输入文本的 SHA-256 哈希校验机制；模型明确标记为未调用（`not_run / unknown`），预训练截止日仅作为假设反例；深入剖析大模型预训练语料截止时间为何不能等同于可核查的历史 PIT 资格；阐明零温与种子不能消除硬件及底层非确定性漂移；分析量化研究中的幻觉、不可复现性与事实性核验方法。

## 2. 为什么 Quant 需要它

以下公司与电话会场景均为构造教学情境，不是已取得的市场事实。先验错误、样本依赖和因果假设不成立仍可能使结论失效。

量化研究员经常面临三类典型的认知陷阱与建模失败：

第一类陷阱是**小样本下的点估计幻觉**。在低频宏观对冲或特定事件驱动（如违约事件、CEO 离职、重大并购）策略中，历史样本量极小（可能仅有十几次甚至几次观测）。频率学派的点估计（如样本均值）会剧烈波动；若某行业仅有 4 家公司披露了业绩预喜且全部上涨，样本频率点估计为100%，但这不表示频率学派推断断言总体胜率必为100%；小样本区间仍表达不确定性。贝叶斯方法提供了一套公理化的不确定性更新框架，通过引入合理的先验分布，将极端小样本估计拉向全市场先验均值（收缩效应），并输出完整的后验分布与后验预测方差。收缩有助于降低小样本估计的敏感性，但不能保证优化器配置稳定；错误先验也会引入偏差。

第二类陷阱是**把混杂关联当成干预效果**。本章构造的补充电话会案例中，处理组总体达标率比对照组高38个百分点；高关注度公司在处理组占比更高，且基础达标率更高。按关注度分层后，两层内的观测差都为−10个百分点。这个方向反转说明总体关联受分组权重影响；把标准化差解释为ATE仍须后文的识别假设，不能从这张表推断管理层行为的真实机制或实际交易盈亏。

第三类陷阱是**非结构化数据与大模型应用中的前瞻泄漏（Look-ahead Leakage）**。随着另类数据（新闻、研报、电话会、社交媒体）与大语言模型的普及，文本数据已成为前沿量化的兵家必争之地。然而，文本数据的时点结构极其脆弱：
1. **入库延迟**：新闻发布于盘后 16:05，供应商分发需 20 分钟，公司内部入库需 5 分钟。在 16:30 之前，本地量化研究数据库根本不可用该文本，若策略信号在 16:15 生成并假想在盘后撮合，则直接构成了实盘不可行的时间穿越；
2. **事后修订**：财务电话会速记稿常常在次日被发行人更正或补充，若直接拿最新的修订版本回测历史信号，便泄漏了未来更正信息；
3. **预训练语料污染**：大语言模型的预训练语料爬取自互联网，假设模型训练截止至 2023 年底，那么训练语料可能包含 2022 年事件发生后的报道。仅凭截止声明不能证明用于 2022 年历史信号的输出没有未来知识；是否实际受污染仍需专门实验。

本章在数理上打通贝叶斯推断与因果识别，在工程上落地严密的 Point-in-Time 文本处理链条，为量化研究建立起不可逾越的时间与因果护城河。

## 3. 直觉

为了建立清晰的物理图像，我们从三个金融与统计案例出发：

### 3.1 贝叶斯共轭更新与资产收益率层级收缩
- **共轭更新直觉**：设某量化策略的交易胜率为 $p \in [0, 1]$。在实盘之前，你基于全市场同类策略的先验认知设定 $p \sim \operatorname{Beta}(2, 2)$（期望胜率 0.5）。若10次构造交易中8次盈利，极大似然点估计为80%，但这个点估计不表达小样本不确定性。本例所设先验下，贝叶斯更新给出后验均值 $\approx 71.4\%$，自适应地在先验常识与微弱样本之间取得平衡。
- **连续资产收益率的部分池化（Partial Pooling）**：考虑跨行业或风格群组的连续超额收益率估计。设全市场长期无条件超额收益先验中枢为 $\mu = 0.0$，组间离散度为 $\tau = 0.02$，单笔交易观测噪声为 $\sigma = 0.04$。
  - 组 1 为新上市科技股，历史样本极小（$n_1 = 4$），样本均值为 $\bar{y}_1 = +0.03$（$+3\%$）。由于样本量极低，模型赋予其 $50\%$ 的收缩权重，后验均值被强烈拉回至 $+0.015$；
  - 组 2 为成熟大盘蓝筹，历史样本充分（$n_2 = 36$），样本均值为 $\bar{y}_2 = +0.01$（$+1\%$）。由于证据扎实，模型赋予其 $90\%$ 的样本权重，后验均值为 $+0.009$。
  部分池化机制自动完成了“对缺乏证据的群组克制信任、对证据确凿的群组尊重数据”的收缩折衷。

### 3.2 辛普森悖论与分析师关注度混杂
本例构造200家公司记录，处理是“盘后补充电话会（发布补充指引，$T=1$）”，结果是次日开盘超额收益是否达标（$Y \in \{0,1\}$）。观察表中，处理组达标率64%，对照组26%，未调整差为38个百分点；这只是关联。
按分析师关注度 $Z$ 分层：高关注度层中处理组90家、达标63家，对照组10家、达标8家，组内差为$0.70-0.80=-0.10$；低关注度层中处理组10家、达标1家，对照组90家、达标18家，组内差同样为$0.10-0.20=-0.10$。
处理组90%来自高关注度层，而对照组90%来自低关注度层，因此总体关联与组内差方向相反。使用目标总体各层50%的权重，标准化差为$-0.10$。只有在一致性、条件可交换性、正值性及所列SUTVA等识别假设下，才可把它解释为目标总体ATE；四格表本身不能验证这些假设，也不提供实际市场干预证据。

### 3.3 电话会文本的时间旅行
某上市公司于盘后 16:05 结束了电话会。你在历史数据库里检索到该电话会的文本，并用它计算次日 09:30 开盘买入的信号。看似时间是顺流而下的，但数据库里的这篇文本很可能是次日上午 10:00 经过公司法律与投资者关系部门二次校对后的修订版（更正了口误数据）。如果在 09:00 就使用这篇文本计算情感得分，你的算法实际上搭乘了“时间机器”。必须在信号时点冻结历史入库账本，严格拒绝未来版本。

## 5. 正式定义

### 5.1 贝叶斯共轭更新（Conjugate Bayesian Updating）
参数 $\theta$ 的先验（prior）$p(\theta)$ 表示观察数据前的概率分布；似然（likelihood）$p(y\mid\theta)$ 是固定数据 $y$ 后关于参数的函数，通常不是参数上的归一化密度。贝叶斯定理将二者组合为后验（posterior）：
$$
p(\theta\mid y)=\frac{p(y\mid\theta)p(\theta)}{p(y)},\qquad
p(y)=\int p(y\mid\theta)p(\theta)\,d\theta>0.
$$
分母是边际似然（marginal likelihood），保证后验积分为 1；离散参数时将积分换为求和。它不是把数据概率与参数概率混为一谈。

在贝叶斯统计中，若先验分布 $p(\theta)$ 与后验分布 $p(\theta \mid y)$ 属于同一概率分布族，则称该先验分布为似然函数 $p(y \mid \theta)$ 的**共轭先验（Conjugate Prior）**。对于二项似然 $y \sim \operatorname{Binomial}(n, p)$，其共轭先验是 Beta 分布 $\operatorname{Beta}(\alpha, \beta)$。后验分布同样为 Beta 分布：
$$
p \mid y \sim \operatorname{Beta}(\alpha + y, \beta + n - y)
$$

### 5.2 后验预测分布（Posterior Predictive Distribution）
后验预测分布是在观测到已有数据 $y$ 后，对未来新观测 $\tilde{y}$ 的边际概率分布。它通过对模型参数 $\theta$ 的后验不确定性进行积分而得到：
$$
p(\tilde{y} \mid y) = \int_{\Theta} p(\tilde{y} \mid \theta) p(\theta \mid y) \, d\theta
$$
**核心命题**：对于未来两次共享同一未知参数 $p$ 的伯努利试验 $(\tilde{y}_1, \tilde{y}_2)$，在给定参数 $p$ 的条件下，它们是**条件独立**的：$P(\tilde{y}_1=1, \tilde{y}_2=1 \mid p) = p^2$。但对 $p$ 积分消除后，它们在边际后验预测分布下是**相关的**：
$$
P(\tilde{y}_1=1, \tilde{y}_2=1 \mid y) = E[p^2 \mid y] = \operatorname{Var}(p \mid y) + (E[p \mid y])^2 \ne (E[p \mid y])^2
$$
当后验浓度有限且两个 Beta 参数均为正时，协方差精确等于 $\operatorname{Var}(p \mid y)>0$。这来自共享参数的不确定性，不表示一次未来结果物理上导致另一次结果。

### 5.3 正态层级模型与部分池化（Normal Hierarchical Model & Partial Pooling）
以下闭式解假设：给定已知超参数时各组先验独立；给定各自 $\theta_j$ 时，组内观测条件独立、同方差且为所述正态分布。新观测噪声独立于 $\theta_j$ 和旧观测。若组内有时间相关或异方差，不能直接沿用 $\sigma^2/n_j$ 和本节固定精度权重。
考虑 $J$ 个资产或分析师组，组 $j$ 的参数 $\theta_j$ 来自公共先验 $\theta_j \sim \mathcal{N}(\mu, \tau^2)$，组内样本观测满足 $y_{j, i} \sim \mathcal{N}(\theta_j, \sigma^2)$。样本均值 $\bar{y}_j$ 的抽样方差为 $\sigma_j^2 = \sigma^2 / n_j$。  
在**已知超参数** $(\mu, \tau^2, \sigma^2)$ 条件下，组均值 $\theta_j$ 的后验均值满足部分池化闭式解（Gelman et al. BDA3 式 5.17）：
$$
\hat{\theta}_j = (1 - w_j)\mu + w_j \bar{y}_j, \quad w_j = \frac{n_j / \sigma^2}{1/\tau^2 + n_j / \sigma^2} = \frac{n_j}{n_j + \sigma^2 / \tau^2}
$$
后验精度是先验精度与样本精度之和：$1/V_j = 1/\tau^2 + n_j/\sigma^2$。对该组未来新观测 $\tilde{y}_j$ 的后验预测方差为 $\operatorname{Var}_{\mathrm{pred}, j} = V_j + \sigma^2$。

### 5.4 潜在结果（Potential Outcomes）与平均处理效应（ATE）
设二值处理变量 $T \in \{0, 1\}$。对每个个体，定义一对潜在结果：
- $Y(1)$：该个体接受处理（$T=1$）时的潜在结果；
- $Y(0)$：该个体未接受处理（$T=0$）时的潜在结果。  
因果推断的根本难题在于，现实中每个个体只能观察到其中一个潜在结果：$Y = T \cdot Y(1) + (1-T) \cdot Y(0)$。  
目标人群的**平均处理效应（Average Treatment Effect, ATE）**定义为：
$$
\operatorname{ATE} = E[Y(1) - Y(0)]
$$

#### 5.5 因果识别的四大假设（Causal Identification Assumptions）
依据 Hernán & Robins (2020)，要将观测数据中的统计对比转化为因果 ATE，必须满足以下四大基础假设：
1. **一致性（Consistency）**：若个体实际接受处理 $T=t$，则其观察到的结果 $Y$ 等于潜在结果 $Y(t)$，即 $Y = Y(T)$。
2. **条件可交换性（Conditional Exchangeability / No Unmeasured Confounding）**：在充分控制混杂协变量 $Z$ 的条件下，潜在结果分布与实际处理分配条件独立：$(Y(0), Y(1)) \perp T \mid Z$。在 DAG 中，这意味着控制 $Z$ 能够完全阻断所有连接 $T$ 与 $Y$ 的后门路径（Backdoor Paths）。
3. **正值性 / 重叠（Positivity / Overlap）**：在目标总体的每一个混杂分层 $z$（即 $P(Z=z) > 0$）内，接受处理和对照的概率均严格大于零：
   $$
   0 < P(T=1 \mid Z=z) < 1
   $$
正值性是指所有分层均有正概率接受任一处理，**绝非**变量服从正态分布。若某层全部接受处理或全部未接受处理，该层的对照潜在结果无法从数据中识别，算法必须显式报错拒绝，绝不可静默填充！
4. **稳定个体处理值假设（Stable Unit Treatment Value Assumption, SUTVA）**：包含两个紧密关联的核心维度：
   - **无个体间干扰（No Interference）**：某个体的处理状态不会影响其他个体的潜在结果（例如一只股票召开电话会并被纳入策略买入，不会直接改变未开会股票在平行世界下的潜在超额收益）；
   - **无处理版本变异 / 无隐藏版本（Treatment Variation Irrelevance / No Hidden Versions of Treatment）**：对于声明的处理水平 $T=t$，不存在未被观测到的异质处理版本导致潜在结果产生差异（例如不论由 CEO 还是 CFO 召开、不论语速快慢，处理定义 $T=1$ 在因果机制上是同质等价的）。

### 5.6 分层标准化（Standardization）
在条件可交换性、正值性、一致性与 SUTVA 同时满足时，目标总体因果 ATE 可通过在目标人群边际分布 $P(Z)$ 上对各层条件效应进行标准化加权计算：
$$
\operatorname{ATE} = \sum_{z} \Big( E[Y \mid T=1, Z=z] - E[Y \mid T=0, Z=z] \Big) P(Z=z)
$$
必须强调：分层标准化计算得到的数值对比，仅在上述四大识别假设完全成立时才能被解释为目标总体因果平均处理效应（Causal ATE）；若存在未观测混杂（Unmeasured Confounder）、违反 SUTVA 或发生样本选择偏误，调整后的统计关联仍然只是特定控制下的条件关联，绝不能直接无条件宣称为真实因果。

### 5.7 时点可得性（Point-in-Time, PIT）与延迟契约
输入必须具有非缺失、带时区的完整事件、修订、可用、入库、信号、成交和标签时间。教学选择器要求每个 source_id 只有一个决策截止，版本编号为递增正整数；重复版本、矛盾时间和缺失正文会报错，晚入库版本被过滤。许可字段只保存来源说明，不由程序自动认定法律授权。直接训练入口也执行这些检查。
替代数据必须记录每个版本的完整生命周期时间戳：
- 资格判定（在上述有效输入与版本语义前提下）：当且仅当 $\max(\operatorname{available\_at}, \operatorname{ingested\_at}) \le \operatorname{signal\_time}$ 时，该版本在决策时刻具备可用资格。
- 版本更替：若同一事件发布了多个修订版，决策时点只能使用在信号截止前最新已入库的合规版本，禁止事后向前覆盖。

### 5.8 词袋模型（Bag-of-Words, BoW）与 TF-IDF 特征表示
- 词袋模型将一段文本视作词汇出现频数的无序多重集（Multiset），忽略词序、语法与句法依存。
- **重要概念澄清**：词袋特征表示法本身**并不假设词语在统计上相互独立**（将各个特征的条件分布视为相互独立的假设属于朴素贝叶斯分类器 Naive Bayes 等特定模型，而非 BoW 向量表示本身）。词袋表示的根本局限在于丢弃了顺序信息，无法原生捕捉修饰词、短语组合与否定词极性翻转。
- 词频-逆文档频率（TF-IDF）通过对常见虚词降权、对领域特异性信息词赋权，构建反映词项重要程度的连续稠密/稀疏向量。

### 5.9 离线大语言模型审查台账与不可复现性防御
在量化研究中规范使用大语言模型（LLM）时，必须构建具备离线审计能力的哈希摘要校验台账：
- 完整提示词（Prompt Template + 实际输入文本）进行 SHA-256 密码学哈希（摘要）；
- 密码学哈希只校验摘要一致性，需要独立可信的预期摘要基准；不是加密，也不是不可变时间戳存证。若输入和记录内摘要一起改变，本地重算仍可一致。独立保存的可信摘要能用于对照，但本教学代码不提供该基准的可信保管机制。
- 模型调用状态显式记录为未调用（`model_status: not_run`），模型标识记录为 `not_run / unknown`，训练语料截断日仅能作为反例检验假设；
- 明确记录复现性局限：设置 `temperature=0` 和固定种子并不能保证跨硬件架构、跨推理引擎版本的比特级复现；模型底层更新或浮点计算漂移会显著影响文本特征输出。

## 6. 推导

### 6.1 Beta-Binomial 共轭后验与预测协方差推导

**步骤 1：先验密度与似然函数。**  
设参数 $p \in [0, 1]$ 服从 Beta 先验：
$$
f(p) = \frac{1}{\mathrm{B}(\alpha, \beta)} p^{\alpha - 1} (1-p)^{\beta - 1} \propto p^{\alpha - 1} (1-p)^{\beta - 1}
$$
在给定共享 $p$ 条件下，$n$ 次条件独立同分布伯努利试验中观察到 $y$ 次成功，其二项似然函数为：
$$
L(y \mid p) = \binom{n}{y} p^y (1-p)^{n-y} \propto p^y (1-p)^{n-y}
$$

**步骤 2：后验密度计算。**  
根据贝叶斯定理，后验密度与先验和似然的乘积成正比：
$$
f(p \mid y) \propto f(p) L(y \mid p) \propto p^{\alpha - 1} (1-p)^{\beta - 1} \cdot p^y (1-p)^{n-y} = p^{(\alpha + y) - 1} (1-p)^{(\beta + n - y) - 1}
$$
对比 Beta 分布的核，直接识别出后验分布为：
$$
p \mid y \sim \operatorname{Beta}(\alpha_{\mathrm{post}}, \beta_{\mathrm{post}}), \quad \alpha_{\mathrm{post}} = \alpha + y, \quad \beta_{\mathrm{post}} = \beta + n - y
$$

**步骤 3：后验均值与方差。**  
由 Beta 分布的一阶和二阶矩性质：
$$
E[p \mid y] = \frac{\alpha_{\mathrm{post}}}{\alpha_{\mathrm{post}} + \beta_{\mathrm{post}}}
$$
$$
\operatorname{Var}(p \mid y) = \frac{\alpha_{\mathrm{post}} \beta_{\mathrm{post}}}{(\alpha_{\mathrm{post}} + \beta_{\mathrm{post}})^2 (\alpha_{\mathrm{post}} + \beta_{\mathrm{post}} + 1)}
$$

**步骤 4：后验预测概率与协方差。**  
对单次未来试验 $\tilde{y} \in \{0, 1\}$：
$$
P(\tilde{y} = 1 \mid y) = \int_0^1 P(\tilde{y} = 1 \mid p) f(p \mid y) \, dp = \int_0^1 p f(p \mid y) \, dp = E[p \mid y]
$$
对未来两次试验 $(\tilde{y}_1, \tilde{y}_2)$：
$$
P(\tilde{y}_1 = 1, \tilde{y}_2 = 1 \mid y) = \int_0^1 P(\tilde{y}_1 = 1, \tilde{y}_2 = 1 \mid p) f(p \mid y) \, dp = \int_0^1 p^2 f(p \mid y) \, dp = E[p^2 \mid y]
$$
利用方差恒等式 $E[p^2 \mid y] = \operatorname{Var}(p \mid y) + (E[p \mid y])^2$，代入 Beta 分布二阶原始矩公式：
$$
E[p^2 \mid y] = \frac{\alpha_{\mathrm{post}} (\alpha_{\mathrm{post}} + 1)}{(\alpha_{\mathrm{post}} + \beta_{\mathrm{post}})(\alpha_{\mathrm{post}} + \beta_{\mathrm{post}} + 1)}
$$
两期联合成功的协方差为：
$$
\begin{aligned}\operatorname{Cov}(\tilde{y}_1,\tilde{y}_2\mid y)&=P(\tilde{y}_1=1,\tilde{y}_2=1\mid y)\\ &\quad-P(\tilde{y}_1=1\mid y)P(\tilde{y}_2=1\mid y)\\ &=E[p^2\mid y]-(E[p\mid y])^2=\operatorname{Var}(p\mid y)>0\end{aligned}
$$
证毕。在上述有限正参数条件下，两次试验给定 $p$ 条件独立，但积分后正相关。若随后观察到第一期成功，会进一步更新 $p$ 的后验，提高对第二期成功的条件预测；这是信息更新，不是两次结果之间的因果作用。本例相关系数为 $1/(10+4+1)=1/15$。

### 6.2 正态层级均值收缩（Partial Pooling）推导

**前提假设**：沿用§5.3的组先验独立与给定组均值后条件独立同方差假设；超参数 $\mu, \tau^2, \sigma^2$ 已知。组 $j$ 的均值潜变量 $\theta_j \sim \mathcal{N}(\mu, \tau^2)$，组内样本 $y_{j, 1}, \dots, y_{j, n_j} \sim \mathcal{N}(\theta_j, \sigma^2)$。样本均值 $\bar{y}_j = \frac{1}{n_j}\sum_{i=1}^{n_j} y_{j, i}$ 满足 $\bar{y}_j \mid \theta_j \sim \mathcal{N}(\theta_j, \sigma^2 / n_j)$。

**步骤 1：共轭更新精度合成。**  
组样本均值的抽样精度为 $n_j / \sigma^2$，先验精度为 $1 / \tau^2$。  
由正态分布的共轭性质，对数后验密度为二次型：
$$
\ln p(\theta_j \mid \bar{y}_j) = -\frac{1}{2\tau^2}(\theta_j - \mu)^2 - \frac{n_j}{2\sigma^2}(\bar{y}_j - \theta_j)^2 + \text{const}
$$
展开二次项系数：
$$
-\frac{1}{2}\theta_j^2 \left( \frac{1}{\tau^2} + \frac{n_j}{\sigma^2} \right) + \theta_j \left( \frac{\mu}{\tau^2} + \frac{n_j \bar{y}_j}{\sigma^2} \right) + \text{const}
$$
直接识别后验精度 $1/V_j$ 与后验方差 $V_j$：
$$
\frac{1}{V_j} = \frac{1}{\tau^2} + \frac{n_j}{\sigma^2} \implies V_j = \frac{1}{\frac{1}{\tau^2} + \frac{n_j}{\sigma^2}}
$$

**步骤 2：后验均值加权分解。**  
线性项系数除以二次项系数，得到后验均值 $\hat{\theta}_j$：
$$
\hat{\theta}_j = \frac{\frac{\mu}{\tau^2} + \frac{n_j \bar{y}_j}{\sigma^2}}{\frac{1}{\tau^2} + \frac{n_j}{\sigma^2}} = \frac{1/\tau^2}{1/\tau^2 + n_j/\sigma^2} \mu + \frac{n_j/\sigma^2}{1/\tau^2 + n_j/\sigma^2} \bar{y}_j
$$
定义收缩权重 $w_j$：
$$
w_j = \frac{n_j/\sigma^2}{1/\tau^2 + n_j/\sigma^2} = \frac{n_j}{n_j + \sigma^2 / \tau^2}
$$
则后验均值表示为先验均值与样本均值的凸组合：
$$
\hat{\theta}_j = (1 - w_j)\mu + w_j \bar{y}_j
$$

**步骤 3：后验预测方差。**  
对该组未来的新观测 $\tilde{y}_j = \theta_j + \tilde{\epsilon}$，其中 $\tilde{\epsilon} \sim \mathcal{N}(0, \sigma^2)$ 独立于 $\theta_j$ 及旧观测：
$$
\operatorname{Var}(\tilde{y}_j \mid y) = \operatorname{Var}(\theta_j \mid y) + \operatorname{Var}(\tilde{\epsilon}) = V_j + \sigma^2
$$
证毕。

### 6.3 辛普森反转与因果标准化推导

设二值混杂变量 $Z \in \{1, 2\}$，二值处理 $T \in \{0, 1\}$，二值结果 $Y \in \{0, 1\}$。

**步骤 1：未调整关联差异。**  
根据全概率公式，未调整条件期望为：
$$
E[Y \mid T=t] = \sum_{z} E[Y \mid T=t, Z=z] P(Z=z \mid T=t)
$$
因此，未调整差为：
$$
\begin{aligned}E[Y\mid T=1]-E[Y\mid T=0]&=\sum_z E[Y\mid T=1,Z=z]P(Z=z\mid T=1)\\ &\quad-\sum_z E[Y\mid T=0,Z=z]P(Z=z\mid T=0)\end{aligned}
$$
注意：$P(Z=z \mid T=1) \ne P(Z=z \mid T=0)$，权重的剧烈失衡会引发辛普森反转。

**步骤 2：因果标准化的识别推导。**  
由一致性与条件可交换性 $(Y(t) \perp T \mid Z)$：
$$
E[Y(t) \mid Z=z] = E[Y(t) \mid T=t, Z=z] = E[Y \mid T=t, Z=z]
$$
在目标人群 $P(Z)$ 上取边际期望：
$$
E[Y(t)] = \sum_z E[Y(t) \mid Z=z] P(Z=z) = \sum_z E[Y \mid T=t, Z=z] P(Z=z)
$$
在上述识别假设与目标总体正值性下，相减得到因果平均处理效应：
$$
\operatorname{ATE} = E[Y(1)] - E[Y(0)] = \sum_z \Big( E[Y \mid T=1, Z=z] - E[Y \mid T=0, Z=z] \Big) P(Z=z)
$$
此式中，两项在每一层使用的权重均为**相同的**目标总体边际分布 $P(Z=z)$，在所列识别假设下消除了此DAG中由 $Z$ 引起的混杂偏差。

### 6.4 TF-IDF 形式化数学与双文档逐步手算

**步骤 1：形式化数学定义。**  
设语料库包含 $|D|$ 篇文档，词表大小为 $M$。
1. **词频（Term Frequency, TF）**：文档 $d$ 中词项 $t$ 的出现次数记为 $f_{t, d}$。在标准词频中取原始词频 $\mathrm{tf}(t, d) = f_{t, d}$。
2. **平滑逆文档频率（Smooth Inverse Document Frequency, IDF）**：为防止零除及对仅出现一次的罕见词过分赋权，采用 scikit-learn 标准平滑对数公式：
   $$
   \mathrm{idf}(t, D) = \ln\left(\frac{1 + |D|}{1 + \mathrm{df}(t)}\right) + 1
   $$
   其中 $\mathrm{df}(t)$ 为语料库中包含词项 $t$ 的文档总数。
3. **加权向量与 L2 归一化**：
   $$
   x(t, d) = \mathrm{tf}(t, d) \times \mathrm{idf}(t, D)
   $$
   为了减弱文档长度尺度差异，当 $\|\mathbf x(d)\|_2>0$ 时进行 L2 单位化：
   $$
   \mathbf{v}(d) = \frac{\mathbf{x}(d)}{\|\mathbf{x}(d)\|_2} = \frac{\mathbf{x}(d)}{\sqrt{\sum_{t=1}^M x(t, d)^2}}
   $$

若文档为空或全部词项为 OOV，本实现保留零向量，不做除零；零向量与其他向量的余弦相似度未定义。

**步骤 2：两篇教学文档手算实例。**  
设训练语料仅包含两篇微型文档：
- 文档 1: $d_1 = \text{"growth profit"}$
- 文档 2: $d_2 = \text{"growth loss"}$  
语料库文档数 $|D| = 2$。

1. **提取词表与词频**：
   按字母表排序的词表为：`["growth", "loss", "profit"]` ($M=3$)。
   - $d_1$ 词频向量：$\mathrm{tf}_1 = [1, 0, 1]$
   - $d_2$ 词频向量：$\mathrm{tf}_2 = [1, 1, 0]$
2. **计算文档频数 $\mathrm{df}$ 与平滑 $\mathrm{idf}$**：
   - 词项 `"growth"` 出现在 $d_1$ 和 $d_2$ 中，$\mathrm{df}=2$：
     $$
     \mathrm{idf}(\text{"growth"}) = \ln\left(\frac{1+2}{1+2}\right) + 1 = \ln(1) + 1 = 0.0 + 1.0 = 1.000000
     $$
   - 词项 `"loss"` 仅出现在 $d_2$ 中，$\mathrm{df}=1$：
     $$
     \mathrm{idf}(\text{"loss"}) = \ln\left(\frac{1+2}{1+1}\right) + 1 = \ln(1.5) + 1 \approx 0.405465 + 1.0 = 1.405465
     $$
   - 词项 `"profit"` 仅出现在 $d_1$ 中，$\mathrm{df}=1$：
     $$
     \mathrm{idf}(\text{"profit"}) = \ln\left(\frac{1+2}{1+1}\right) + 1 = \ln(1.5) + 1 \approx 0.405465 + 1.0 = 1.405465
     $$
3. **计算未归一化特征向量 $\mathbf{x} = \mathrm{tf} \times \mathrm{idf}$**：
   - $\mathbf{x}_1 = [1 \times 1.0, 0 \times 1.405465, 1 \times 1.405465] = [1.0, 0.0, 1.405465]$
   - 模长 $\|\mathbf{x}_1\|_2 = \sqrt{1.0^2 + 0^2 + 1.405465^2} = \sqrt{1.0 + 1.975332} = \sqrt{2.975332} \approx 1.724915$
   - 归一化向量 $\mathbf{v}_1$：
     $$
     \mathbf{v}_1 = \left[ \frac{1.0}{1.724915}, 0.0, \frac{1.405465}{1.724915} \right] \approx [0.579739, 0.000000, 0.814802]
     $$
   - $\mathbf{x}_2 = [1 \times 1.0, 1 \times 1.405465, 0 \times 1.405465] = [1.0, 1.405465, 0.0]$
   - 模长 $\|\mathbf{x}_2\|_2 \approx 1.724915$
   - 归一化向量 $\mathbf{v}_2$：
     $$
     \mathbf{v}_2 = \left[ \frac{1.0}{1.724915}, \frac{1.405465}{1.724915}, 0.0 \right] \approx [0.579739, 0.814802, 0.000000]
     $$
4. **计算两文档余弦相似度**：
   $$
   \cos(\mathbf{v}_1, \mathbf{v}_2) = \mathbf{v}_1 \cdot \mathbf{v}_2 = 0.579739^2 + 0.0 \times 0.814802 + 0.814802 \times 0.0 = 0.579739^2 \approx 0.336097
   $$
   该近似数值表明，两篇文档虽然共享高频词 `"growth"`，但由于特征词 `"profit"` 与 `"loss"` 的 IDF 赋权更高且相互正交，归一化后的余弦相似度被拉低至约 $0.3361$。

### 6.5 稠密词嵌入空间几何与均值池化（Mean Pooling）推导

设每个词汇被映射到一个 $K$ 维欧氏空间中的单位向量 $\mathbf{e}(w) \in \mathbb{R}^K, \|\mathbf{e}(w)\|_2 = 1$。
1. **短语/句子均值池化（Mean Pooling）**：
   对于包含 $L$ 个词项的文本序列 $S = (w_1, w_2, \dots, w_L)$，其未归一化稠密句子表征为词向量的简单代数均值：
   $$
   \mathbf{s} = \frac{1}{L} \sum_{l=1}^L \mathbf{e}(w_l)
   $$
2. **单位球投影**（要求 $L>0$ 且 $\|\mathbf s\|_2>0$）：
   $$
   \mathbf{u}_S = \frac{\mathbf{s}}{\|\mathbf{s}\|_2}
   $$
单位词向量也可能相消：$[1,0]$ 与 $[-1,0]$ 的均值是零，不能归一化；空文本也需另定处理。本例非零，通用流程应拒绝或显式保留零向量并将余弦记为未定义。
3. **两段文本语义相似度**（两个归一化向量均存在）：
   $$
   \operatorname{Sim}(S_A, S_B) = \mathbf{u}_{S_A} \cdot \mathbf{u}_{S_B}
   $$
   与稀疏高维的 TF-IDF 相比，稠密词嵌入将同义词（如 `"growth"` 与 `"expansion"`）映射在临近的超球面区域，从而能够绕过一元词袋的完全正交限制。但在金融场景下，若无特定领域微调，通用嵌入极易将反义词（如 `"profit"` 与 `"loss"`）判定为高度相似（因为它们经常出现在相同的语法上下文中）。这也是金融量化必须严格审查嵌入表征质量的核心原因。

## 7. 金融解释

### 7.1 贝叶斯收缩如何表达组合输入的不确定性？
在量化资产配置（如 Black-Litterman 模型或多因子收益预测）中，直接使用历史样本均值进行均值-方差优化是著名的“误差放大器”（Error Maximizer）。历史样本均值受短期市场特质冲击扰动巨大。  
正态层级模型（Partial Pooling）的金融学实质是：**全市场的所有资产共享一个基准的长期风险溢价均值 $\mu$，但在截面上具有异质性 $\tau^2$**。对于披露样本极少的小盘股（$n_j=4$），数据包含的信息量低，模型将其估计值强烈收缩至市场中枢（收缩权重 $w_j=0.5$）；对于数据充分的大盘股（$n_j=36$），模型给予自身样本更高信任度（$w_j=0.9$）。后验预测方差 $\operatorname{Var}_{\mathrm{pred}}=V_j+\sigma^2$ 中，小样本增加的是组均值不确定性 $V_j$；两组未来观测噪声 $\sigma^2$ 相同。这里的超参数均已知，各组数据不用于估计共享超参数；这不同于经验贝叶斯或未知超参数的完整层级推断。该教学算例未证明实盘收益或优化稳定性改善。

### 7.2 混杂与做市商策略中的逆向选择
考虑一种可能的微观结构机制：主动订单流 $T$ 与随后价格变化 $Y$ 的关联，可能同时受到交易者信息、订单规模等 $Z$ 的影响。总体相关不能直接解释为买单的因果价格冲击；知情与非知情交易者的分层关联也须实际数据与识别模型支持。本章未估计各组真实价格冲击，不能据此断言哪一组冲击更小。

### 7.3 替代数据时间延迟与过拟合虚荣
量化团队在向管理层汇报另类数据回测时，极易展示虚高 Sharpe 的回测曲线。其根源往往是“时间戳造假”：新闻或文本虽然在 16:05 发生，但在实际生产中，数据供应商的解析服务常因网络抖动发生排队，或者内部数据工程 ETL 在盘后存在并发瓶颈。只有严格把关可用与入库时间均不晚于信号，才满足文本可得性的必要条件；成交、标签、样本选择和模型有效性仍需另行验证。

## 8. Numerical Example

本节继承历史 A8-C 冻结协议 `qa/a8/ch42_ch43_batch/EXPERIMENT_PROTOCOL.json` 与同目录 `EXPERIMENT_ADDENDUM_v1.json` 下的构造结果。历史手算/代码核对和补充演示保持原身份；BIL20未重跑。

### 8.1 Beta-Binomial 手算实例
- **输入**：先验 $\alpha = 2, \beta = 2$；观察到 $n = 10$ 次试验，成功 $y = 8$ 次。
- **后验参数**：
  $$
  \alpha_{\mathrm{post}} = 2 + 8 = 10, \quad \beta_{\mathrm{post}} = 2 + 10 - 8 = 4
  $$
- **后验均值与方差**：
  $$
  E[p \mid y] = \frac{10}{10 + 4} = \frac{10}{14} = \frac{5}{7} \approx 0.714286
  $$
  $$
  \operatorname{Var}(p \mid y) = \frac{10 \times 4}{14^2 \times (14 + 1)} = \frac{40}{196 \times 15} = \frac{40}{2940} = \frac{2}{147} \approx 0.013605
  $$
- **未来预测**：
  - 单次试验预测成功概率：$P(\tilde{y} = 1 \mid y) = 10/14 = 5/7 \approx 0.714286$。
  - 两次试验联合成功概率：
    $$
    E[p^2 \mid y] = \frac{10 \times (10 + 1)}{14 \times (14 + 1)} = \frac{110}{210} = \frac{11}{21} \approx 0.523810
    $$
  - 后验均值平方：$(E[p \mid y])^2 = (10/14)^2 = 100/196 = 25/49 \approx 0.510204$。
  - 差值核对：
    $$
    E[p^2 \mid y] - (E[p \mid y])^2 = \frac{11}{21} - \frac{25}{49} = \frac{77 - 75}{147} = \frac{2}{147} \equiv \operatorname{Var}(p \mid y)
    $$
  两者完全精确吻合。

### 8.2 正态层级收缩手算实例

本例的收益用小数表示：$0.02=2\%$，$0.03=3\%$。均值与标准差都使用收益小数单位；后验方差 $V_j$ 和预测方差使用该单位的平方。例如组1的 $V_1=0.0002$ 是均值参数的不确定性，开方后为 $0.014142$（约1.4142个百分点的收益尺度）；未来单笔收益另有观测噪声，故预测方差为 $0.0002+0.0016=0.0018$，开方后约为 $0.042426$（4.2426个百分点的收益尺度）。若把收益数值改用百分数表示，均值与标准差乘100，方差须乘 $100^2$；收缩权重不变。本例的超参数仍为已知常数，不在此估计。
- **已知超参数**：先验均值 $\mu = 0.0$，先验标准差 $\tau = 0.02$；观测标准差 $\sigma = 0.04$。
- **精度常数**：
  $$
  \tau^{-2} = \frac{1}{0.02^2} = 2500, \quad \sigma^{-2} = \frac{1}{0.04^2} = 625, \quad \frac{\sigma^2}{\tau^2} = \frac{0.0016}{0.0004} = 4
  $$
- **组 1**：$n_1 = 4$, 样本均值 $\bar{y}_1 = 0.03$。
  - 收缩权重：$w_1 = \frac{4}{4 + 4} = 0.5$。
  - 后验均值：$\hat{\theta}_1 = (1 - 0.5) \times 0.0 + 0.5 \times 0.03 = 0.015$。
  - 后验精度：$1/V_1 = 2500 + 4 \times 625 = 5000 \implies V_1 = 1/5000 = 0.0002$。
  - 后验标准差：$\sqrt{0.0002} \approx 0.014142$。
  - 后验预测方差：$\operatorname{Var}_{\mathrm{pred}, 1} = V_1 + \sigma^2 = 0.0002 + 0.0016 = 0.0018$。
  - 预测标准差：$\sqrt{0.0018} \approx 0.042426$。
- **组 2**：$n_2 = 36$, 样本均值 $\bar{y}_2 = 0.01$。
  - 收缩权重：$w_2 = \frac{36}{36 + 4} = \frac{36}{40} = 0.9$。
  - 后验均值：$\hat{\theta}_2 = (1 - 0.9) \times 0.0 + 0.9 \times 0.01 = 0.009$。
  - 后验精度：$1/V_2 = 2500 + 36 \times 625 = 2500 + 22500 = 25000 \implies V_2 = 1/25000 = 0.00004$。
  - 后验标准差：$\sqrt{0.00004} \approx 0.006325$。
  - 后验预测方差：$\operatorname{Var}_{\mathrm{pred}, 2} = V_2 + \sigma^2 = 0.00004 + 0.0016 = 0.00164$。
  - 预测标准差：$\sqrt{0.00164} \approx 0.040497$。

### 8.3 辛普森因果分层手算实例
- **评估指标定义**：本案例中的结果变量 $Y \in \{0, 1\}$ 表示次日开盘超额收益达到基准阈值的二值成功事件，其均值 $E[Y]$ 代表无量纲**成功概率**；两概率之差乘以 100 才是**百分点（Percentage Points, pp）**，**绝非**平均收益率百分比。
- **列联表数据**（总样本 $N=200$）：
  - 高关注度层 $Z=\mathrm{high}$（行业龙头）：
    - 处理组 $T=1$（开会）：$n=90$，成功 $63$ 次 $\implies E[Y \mid T=1, Z=\mathrm{high}] = 63/90 = 0.70$（$70\%$）；
    - 对照组 $T=0$（未开会）：$n=10$，成功 $8$ 次 $\implies E[Y \mid T=0, Z=\mathrm{high}] = 8/10 = 0.80$（$80\%$）；
    - 层内对比：$0.70 - 0.80 = -0.10$（成功率降低 $10$ 个百分点）。
  - 低关注度层 $Z=\mathrm{low}$（微盘尾部）：
    - 处理组 $T=1$（开会）：$n=10$，成功 $1$ 次 $\implies E[Y \mid T=1, Z=\mathrm{low}] = 1/10 = 0.10$（$10\%$）；
    - 对照组 $T=0$（未开会）：$n=90$，成功 $18$ 次 $\implies E[Y \mid T=0, Z=\mathrm{low}] = 18/90 = 0.20$（$20\%$）；
    - 层内对比：$0.10 - 0.20 = -0.10$（成功率降低 $10$ 个百分点）。
- **未调整粗差对比**：
  - 处理组总计：$n=100$，总成功 $63 + 1 = 64 \implies E[Y \mid T=1] = 64/100 = 0.64$（$64\%$）；
  - 对照组总计：$n=100$，总成功 $8 + 18 = 26 \implies E[Y \mid T=0] = 26/100 = 0.26$（$26\%$）；
  - 未调整粗差：$0.64 - 0.26 = +0.38$（表面成功率高出 $38$ 个百分点）。
- **标准化观测差；在§5.5识别假设下解释为 ATE**（目标总体分布 $P(Z=\mathrm{high})=0.5, P(Z=\mathrm{low})=0.5$）：
  $$
  \operatorname{ATE} = 0.5 \times (-0.10) + 0.5 \times (-0.10) = -0.10
  $$
  未调整差为 $+38$ 个百分点，标准化差为 $-10$ 个百分点；只有在本例假定的识别条件成立时，后者才解释为目标总体 ATE。该表展示了权重引起的关联反转，本身不证明处理的真实因果方向。

### 8.6 否定词情感与手算词嵌入实例
人工矩阵每行分别对应 growth、profit、loss、decline、stable、steady，三列只是教学轴（强度、动量、不确定性），不是估计得到的金融因子：
$$
E=\begin{pmatrix}0.8&0.9&0.1\\0.9&0.7&0.1\\-0.8&-0.7&0.5\\-0.7&-0.8&0.4\\0.2&0.1&-0.8\\0.3&0.2&-0.7\end{pmatrix}.
$$
先将每行除以自身范数。例如 growth 的模长为 $\sqrt{1.46}$，profit 为 $\sqrt{1.31}$，两者余弦为：

$$\frac{1.36}{\sqrt{1.46\cdot1.31}}\approx0.9834.$$

句子先对其单位词向量取均值，再归一化；本例忽略连接词 and。以下代码给出全部向量与相似度：
```python
from quant_course.bayesian_text import hand_embedding_matrix, negation_sentiment_scorer
vectors, similarities = hand_embedding_matrix()
print(vectors, similarities)
print(negation_sentiment_scorer("earnings performance did not improve showing no growth"))
```

- **否定词翻转**：
  句子：“earnings performance did not improve showing no growth despite aggressive restructuring”
  - 固定词典的朴素一元计分（BoW 本身并不指定情感权重）：识别出 `"improve"` ($+1$) 与 `"growth"` ($+1$)，得分 $+2$（严重误判为极度乐观！）；
  - 否定词滑动窗口算法：`"not"` 激活 3 词翻转窗口，`"improve"` 被翻转为 $-1$；`"no"` 激活翻转窗口，`"growth"` 被翻转为 $-1$，综合得分 $-2$（符合本构造句的预设负面含义）。此三词窗口规则未保证复杂否定、双重否定、讽刺或一般金融文本的准确性。
- **词嵌入空间余弦相似度**（基于 $6 \times 3$ 人工指定、归一化嵌入矩阵（未训练真实语料））：
  - `growth` 与 `profit` 的余弦相似度为 $+0.9834$；
  - `growth` 与 `loss` 的余弦相似度为 $-0.8595$；
  - 短语 $S_1$ ("growth and profit") 与短语 $S_2$ ("loss and decline") 的均值池化向量余弦相似度为 $-0.8836$。

## 11. Real Market Example

真实数据应用中，非结构化文本数据的采选受到严格的技术接口、覆盖偏误与法律授权约束。

### 11.1 真实监管接口与时点审查边界
SEC 官方 API 页面说明公开申报接口与处理延迟。本轮未核对单个申报原文、字段时区或电话会原文，因此此处只说明接口线索，不能作为真实文本 PIT 或许可证明。
- **通用 API 接口与物理时延**：量化工程在接入官方数据时，必须区分物理发生时点与本地入库时点。任何在本地数据库完成解析与落库之前的外部文本，在系统时钟到达入库完成时刻之前均属于“不可用”状态。
- **日历与交易规则**：真实量化生产系统必须绑定交易所实际交易日历（如 NYSE 休市日与半日交易）。本章采用的合成工作日日历（Synthetic Weekday Calendar）仅用于剥离假期复杂度以凸显教学主线，不可直接等同于包含复杂休市规则的实盘日历。

### 11.2 替代数据许可、覆盖范围与样本选择偏差
在替代数据（Alternative Data）采选中，量化团队必须警惕两项重大非技术风险：
1. **公开可访问性 vs 法律授权许可**：
   公开网页上的文本具有“公共可访问性”（Public Accessibility），但这绝不等于具备合规的商业数据抓取、特征提取、模型训练或衍生特征交易再分发许可（Licensing & Redistribution Rights）。使用未获授权的文本训练策略，面临严重的合规与法律追索风险。本教学批次明确记录许可缺口：当前未提供全量商用授权的真实电话会速记语料，因此本章采用带有 `CONSTRUCTED_CALL_` 前缀的构造文本。
2. **供应商覆盖偏误诱发的选择偏差（Selection Bias）**：
   设某另类数据供应商提供高频电话会情绪特征，但构造一个覆盖案例：该供应商对高分析师关注度（大市值）公司的覆盖率为 $90\%$，而对低关注度（中小盘）公司的覆盖率仅为 $10\%$。若量化研究员直接在“供应商有数据”的样本集（标记为入选指示变量 $S=1$）上进行因子有效性检验，由于关注度 $Z$ 同时影响了数据可得性 $S$ 和公司基本面 $Y$，$S$ 改变了样本组成。若总体高、低关注度各占一半，覆盖后高关注度占 $0.9/(0.9+0.1)=0.9$；基准成功率分别为 0.8、0.2 时，总体均值为 0.5，覆盖样本均值为 0.74。这个 0.24 差异来自选择，不是新因子的效应。仅有 $Z\to S$ 与 $Z\to Y$ 不能把 $S$ 称为对撞节点；对撞还需两个独立原因共同指向 $S$。

## 12. Common Mistakes

### 误区 1：混淆因果重叠性（Positivity）与正态性（Normality）
- **错误理解**：认为“因果识别要求所有特征服从正态分布”。
- **事实纠正**：正值性/重叠性（Positivity）指的是在每一个混杂分层内部，处理组与对照组都有非零的采样概率：$0 < P(T=1 \mid Z=z) < 1$。
- **诊断片段（不独立运行）**：
  ```text
  # 错误做法：某层没有对照组，直接填充 0 算差值
  diff_stratum = mean_t1 - 0.0  # 严重破坏潜在结果识别！
  ```
- **对应修复片段**：
  ```text
  if n_t1 == 0 or n_t0 == 0:
      raise PositivityViolationError(f"Positivity violated in stratum {z}!")
  ```

有限样本某层缺一处理组只是样本支持/可计算性防线，不能单独证明总体处理概率为0或1；目标总体有正权重但整层未出现，同样不能用静默漏项或重归一处理。

### 误区 2：在全样本上 fit 词表与 IDF 导致跨期信息泄漏
- **错误理解**：认为“文本无监督，提取 TF-IDF 词表不看未来标签，所以在全样本上 fit 不算泄漏”。
- **事实纠正**：测试集的新词频如果提前进入训练集的 IDF，会改变训练特征的尺度；更严重的是，未来重大突发事件的特有词汇（如某项专利名、重组代号）提前进入词表，使模型在历史时间点获得了“未来重要性”的先验信息。
- **修复规则**：词表与 IDF 必须且只能在训练集 fit，对验证集与测试集执行 transform，未见词（OOV）直接忽略。

### 误区 3：将大语言模型的预训练截止日期等同于历史 PIT 资格
- **错误理解**：模型训练语料截止到 2023 年 12 月，因此用它来对 2022 年的新闻打分是严格 PIT 的。
- **事实纠正**：这个假设截止日晚于历史信号，存在吸收后续报道的可能。不能只凭截止声明确认具体公司已被记忆，也不能由此自动认定每个输出都受污染；应保留模型、语料时点证据与对照实验。

## 13. Quant Research Application

### 13.1 完整量化投研设计：盘后文本到次日执行
构建基于业绩电话会的事件驱动信号提取流程：
1. **事件监听**：美东时间 16:00 盘后开始监听申报流水。16:05 会议结束，16:25 第三方供应商生成速记稿并打上 `available_at`，16:30 本地量化系统完成入库并打上 `ingested_at`。
2. **时点资格检验**：在次日美东时间 09:00（信号生成时点），执行 `filter_pit_eligible_documents`。任何入库时间晚于 09:00 或修订时间晚于 09:00 的版本一律剔除。
3. **拟议扩展：滚动前向拟合（Purged Walk-Forward）**：未来可按另行冻结的协议以滚动窗口拟合 TF-IDF 与 Ridge。本章实际执行的是固定 train/val/test 时间块，不是已执行的滚动验证。注意：窗口最后一日若标签尚未到期（`label_available_at >= next_signal_time`），必须予以严格剪除（Purge）。
4. **开盘信号输出**：在次日 09:00 输出各标的的连续预测收益率 $\hat{y}$。

### 13.2 预测专属接口与下游执行系统规约（Prediction-Only Interface Spec）
本章严格限定在**信号生成与特征预测阶段（Prediction-Only）**。在单资产时序轮换的数据构造下，不能简单对连续轮换不同资产的预测值符号差计算换手率或扣除交易成本（因为离散单资产跨期符号翻转并不构成同一投资组合的连续持仓账本）。下游执行系统须对接课程标准投资组合与执行账本（如第 29 章标准化接口）：
- **下游账本必需字段**：`doc_id`, `trade_time`, `asset_id`, `target_return_pred`, `allocated_weight`, `execution_price`, `one_way_fee_bps`。
- **边界与责任隔离**：文本预测模型仅对时点合规的文本输出 $\hat{y}$；`one_way_fee_bps / 10000` 才是既有回测函数的 `fee_rate`；这些字段是拟议适配层，而不是旧函数参数。还需完整资产价格面板和持仓政策。下游系统负责将 $\hat{y}$ 映射为多资产目标权重（考虑持仓集中度与风险预算）、结合市场冲击模型测算滑点摩擦，并在满足借券约束的前提下生成完整投资组合 PnL 账本。

1. **推断的本质**：贝叶斯推断用概率分布表示认知的不确定性。Beta-Binomial 更新展现了数据对先验的拉动；未来两期联合预测具有由参数不确定性引起的状态相关性（协方差等于后验方差）。正态层级模型在已知超参数下展示了部分池化（Partial Pooling）的自适应收缩能力。
2. **因果与统计的分野**：统计相关不等于因果效应。混杂因素通过改变处理分配的边际比例诱发辛普森悖论。只有在一致性、条件可交换性、严格正值性与无干扰假设下，通过分层标准化才能恢复真实的 ATE。
3. **文本与 PIT 的工程防线**：另类数据与大语言模型研究必须筑牢时点防线。词表必须在训练窗内隔离拟合；电话会必须接受入库与修订时间戳的严格审查；大模型离线台账必须记录提示词哈希与预训练语料截止边界。低信噪比下尊重负结果，是成熟量化研究员的基本素养。

### 43-E01 完整解答
1. **后验参数计算**：
   $$
   \alpha_{\mathrm{post}} = \alpha + y = 2 + 8 = 10, \quad \beta_{\mathrm{post}} = \beta + n - y = 2 + 10 - 8 = 4
   $$
2. **后验均值与方差**：
   $$
   E[p \mid y] = \frac{10}{10 + 4} = \frac{10}{14} = \frac{5}{7} \approx 0.714286
   $$
   $$
   \operatorname{Var}(p \mid y) = \frac{10 \times 4}{14^2 \times (14 + 1)} = \frac{40}{196 \times 15} = \frac{40}{2940} = \frac{2}{147} \approx 0.013605
   $$
3. **单期与两期预测**：
   - 单期预测：$P(\tilde{y} = 1 \mid y) = E[p \mid y] = 10/14 = 5/7$。
   - 两期预测：$P(\tilde{y}_1=1, \tilde{y}_2=1 \mid y) = E[p^2 \mid y] = \frac{10 \times 11}{14 \times 15} = \frac{110}{210} = \frac{11}{21} \approx 0.523810$。
4. **不等性机理**：
   后验均值平方为 $(10/14)^2 = 100/196 = 25/49 \approx 0.510204$。  
   差值 $E[p^2 \mid y] - (E[p \mid y])^2 = \frac{11}{21} - \frac{25}{49} = \frac{77 - 75}{147} = \frac{2}{147} \equiv \operatorname{Var}(p \mid y) > 0$。  
   原因：给定参数 $p$ 时，两次试验独立。对共同且不确定的 $p$ 积分后，预测协方差为 $\operatorname{Var}(p \mid y)>0$，因此两次试验在边际预测分布下正相关。随后若观察到第一次新试验成功，才会更新 $p$ 的后验，并提高第二次试验给定这一新结果的条件预测。

### 43-E04 完整解答

### 43-E06 完整解答

from quant_course.bayesian_text import beta_binomial_posterior_predictive

def verify_predictive_covariance(
    alpha: float, beta: float, successes: int, trials: int
) -> dict[str, float]:
    """Verify that predictive covariance equals posterior variance for arbitrary legal parameters."""
    res = beta_binomial_posterior_predictive(
        alpha_prior=alpha, beta_prior=beta, successes=successes, trials=trials
    )
    cov = res["joint_two_successes"] - (res["single_predictive_mean"] ** 2)
    var_post = res["posterior_variance"]

    return {
        "alpha_post": res["alpha_post"],
        "beta_post": res["beta_post"],
        "predictive_covariance": cov,
        "posterior_variance": var_post,
    }

# 调用验证：支持任意合法超参数

### 43-P02 参考实现
本参考函数在 `target_p_z=None` 时以经验层分布为目标；共享核心 `compute_stratified_ate` 的默认目标是 high/low 各0.5，二者不是同一默认总体。显式传入同一合法权重后才对齐。权重有限、非负且总和为1；正权重目标整层缺失须报错，不能丢弃后重归一。下列检查防止样本支持缺失，不能证明总体正值性或可交换性。
```python
import pandas as pd
from quant_course.bayesian_text import PositivityViolationError

def compute_stratified_ate_safe(
    df: pd.DataFrame,
    z_col: str = "Z",
    t_col: str = "T",
    y_col: str = "Y",
    target_p_z: dict | None = None,
) -> dict:
    """Compute stratified ATE with strict positivity defense raising custom exception."""
    import math
    if df.empty:
        raise ValueError("Input DataFrame is empty.")
    for col in (z_col, t_col, y_col):
        if col not in df:
            raise KeyError(col)
    if df[[z_col, t_col, y_col]].isna().any().any():
        raise ValueError("Causal variables cannot be missing.")
    if not set(df[t_col]).issubset({0, 1}):
        raise ValueError("Treatment must be binary.")
    if not all(math.isfinite(float(y)) for y in df[y_col]):
        raise ValueError("Outcomes must be finite.")
    strata = df[z_col].unique()
    if target_p_z is None:
        p_z = {z: len(df[df[z_col] == z]) / len(df) for z in strata}
    else:
        p_z = dict(target_p_z)
    if not p_z or any(not math.isfinite(float(p)) or not 0 <= p <= 1
                      for p in p_z.values()):
        raise ValueError("Target weights must be finite probabilities.")
    if not math.isclose(sum(p_z.values()), 1.0, rel_tol=0, abs_tol=1e-12):
        raise ValueError("Target probabilities must sum to one.")
    for z, p in p_z.items():
        if p > 0 and z not in set(strata):
            raise PositivityViolationError(
                f"Missing target stratum '{z}': treated_count=0, control_count=0."
            )
    stratum_contrasts = {}

    for z in strata:
        sub = df[df[z_col] == z]
        treated = sub[sub[t_col] == 1]
        control = sub[sub[t_col] == 0]
        n_t1, n_t0 = len(treated), len(control)
        if n_t1 == 0 or n_t0 == 0:
            raise PositivityViolationError(
                f"Positivity violation in stratum '{z}': "
                f"treated_count={n_t1}, control_count={n_t0}."
            )
        stratum_contrasts[z] = treated[y_col].mean() - control[y_col].mean()

    ate = sum(p * stratum_contrasts[z] for z, p in p_z.items() if p > 0)
    return {"ate": ate, "stratum_contrasts": stratum_contrasts}

# 测试验证：断言违背正值性时正确抛出异常
df_fail = pd.DataFrame([
    {"Z": "stratum_a", "T": 1, "Y": 1},
    {"Z": "stratum_a", "T": 1, "Y": 0},  # stratum_a 缺少 T=0
    {"Z": "stratum_b", "T": 1, "Y": 1},
    {"Z": "stratum_b", "T": 0, "Y": 0},
])

try:
    compute_stratified_ate_safe(df_fail)
    raise AssertionError("未能成功捕获正值性破坏！")
except PositivityViolationError as e:
    assert "Positivity violation in stratum 'stratum_a'" in str(e)
```

### 43-C01 完整解答、运行反例与评分标准
DAG 的箭头本身不决定选择后关联的符号；本题负号依赖独立 Bernoulli(0.5) 与 OR 规则。若保持独立输入但改为 $C=\mathbb I(T=Y)$，条件 $C=1$ 只剩00与11，相关系数为+1。这是规则不同的反例，不替换原题。
1. **理论论证与代数推导**：
   设两个二值选股因子 $T \in \{0, 1\}$（动量突破）与 $Y \in \{0, 1\}$（质量 Alpha）。假设它们在全市场独立同分布，边际概率均为 $P(T=1) = 0.5, P(Y=1) = 0.5$。
   四种联合状态 $(t, y) \in \{(0, 0), (0, 1), (1, 0), (1, 1)\}$ 各具有无条件先验概率 $1/4$。
   显然，无条件协方差为 $\operatorname{Cov}(T, Y) = 0$。
   假设投资组合选股准入规则为任一因子表现突出即可入选（对撞节点 $C = \mathbb{I}(T=1 \lor Y=1)$）。
   当研究员限定在成分股池（$C=1$）内进行实证分析时：
   - 状态 $(0, 0)$ 被完全剔除；
   - 剩余三种状态 $(0, 1), (1, 0), (1, 1)$ 在 $C=1$ 条件下具有相等的条件概率 $1/3$。
   - 条件期望：
     $$
     E[T \mid C=1] = 0 \times \frac{1}{3} + 1 \times \frac{1}{3} + 1 \times \frac{1}{3} = \frac{2}{3}
     $$
     $$
     E[Y \mid C=1] = 1 \times \frac{1}{3} + 0 \times \frac{1}{3} + 1 \times \frac{1}{3} = \frac{2}{3}
     $$
     $$
     E[TY \mid C=1] = 0 \times \frac{1}{3} + 0 \times \frac{1}{3} + 1 \times \frac{1}{3} = \frac{1}{3}
     $$
   - 条件协方差计算：
     $$
     \begin{aligned}\operatorname{Cov}(T,Y\mid C=1)&=E[TY\mid C=1]-E[T\mid C=1]E[Y\mid C=1]\\ &=\frac13-\left(\frac23\right)^2=\frac13-\frac49=-\frac19\approx-0.111111\end{aligned}
     $$
   - 条件相关系数：
     $$
     \operatorname{Var}(T \mid C=1) = \frac{2}{3} \left(1 - \frac{2}{3}\right) = \frac{2}{9}, \quad \operatorname{Corr}(T, Y \mid C=1) = \frac{-1/9}{2/9} = -0.5
     $$
   原本完全独立的两个因子，仅仅因为研究员对对撞节点 $C$ 进行了条件筛选，就在样本内部诱发了高达 $-0.5$ 的强负相关！代码实跑 2000 个样本的经验协方差约为 $-0.1144$，与理论值 $-1/9$ 数值接近；有限样本经验值不等于理论极限。
```python

r = demonstrate_collider_bias(n=2000, seed=4301)
print(r)
assert abs(r["conditioned_on_collider_covariance"] + 1/9) < 0.03
```

2. **量化投资警示**：
   在量化选股中，若研究员仅在“沪深 300”或“标普 500”等大市值指数成分股内测试因子，由于入选指数本身受到市值规模与盈利能力的共同筛选，若准入机制符合本例对撞结构，可能在指数内部诱发因子关联；仅在指数内研究本身并不能证明存在该结构或偏误（例如大市值股票内动量与价值的虚假反转），从而将样本选择偏误（Berkson's Paradox）误当成可交易的市场异象。

def validate_and_hash_audit_ledger(ledger_dict: dict, trusted_expected_hash=None) -> bool:
    """Check local digest consistency; optionally compare an independently trusted digest."""
    validate(instance=ledger_dict, schema=AUDIT_LEDGER_SCHEMA)
    
    # 重新计算哈希核验一致性
    template = (
        "You are an offline equity research audit assistant.\n"
        'Analyze the following corporate transcript snippet under strict '
        'Point-in-Time constraints:\n'
        "Snippet: \"{transcript_snippet}\"\n"
        'Identify whether the statement reports historical performance or '
        'provides future guidance.\n'
        'Output format: JSON with keys "type" '
        '(HISTORICAL/FORWARD_LOOKING) and "polarity" (POSITIVE/NEGATIVE/NEUTRAL).\n'
        "Do not assume post-event market price reactions."
    )
    expected_prompt = template.format(transcript_snippet=ledger_dict["sample_input_text"])
    expected_hash = hashlib.sha256(expected_prompt.encode("utf-8")).hexdigest()
    
    if ledger_dict["full_prompt_sha256_hash"] != expected_hash:
        raise ValueError("Recorded prompt digest does not match the current input.")
    if trusted_expected_hash is not None and expected_hash != trusted_expected_hash:
        raise ValueError("Current prompt differs from the independently trusted digest.")
    return True

def audit_cutoff_relation(ledger):
    # Unknown means unevaluated, not PIT-pass. A later cutoff flags risk, not confirmed contamination.
    import pandas as pd
    declared = ledger["declared_model_cutoff"]
    if declared == "unknown":
        return "not_evaluated"
    cutoff = pd.Timestamp(declared)
    signal = pd.Timestamp(ledger["provenance_table"]["historical_signal_time"])
    if cutoff.tz is None or signal.tz is None:
        raise ValueError("Require full timezone-aware cutoff and signal timestamps.")
    return "potential_future_corpus" if cutoff > signal else "cutoff_only_insufficient_for_PIT"

2. **三大工程防线与不可复现性防御**：
   - **防线 1（输入物理隔离与全提示词哈希）**：严禁将事后分析或后序股价反应输入给大模型；哈希必须覆盖格式化后的“模板 + 实际文本”整体，而非仅计算静态模板字符串；同时改输入与本地摘要仍可通过一致性校验，须独立可信基准对照，不能称为加密/不可变存证。
   - **防线 2（确定性局限与版本漂移防御）**：生产环境中必须清醒认识到：设置 `temperature=0` 和固定种子并不能保证跨 GPU 微架构、跨 CUDA 驱动或跨推理引擎版本的比特级复现；模型服务商的静默更新会导致特征漂移，必须对关键时点提取结果进行离线持久化与快照归档。
   - **防线 3（拒绝预训练 Cutoff 等价 PIT）**：严禁将商业大模型的预训练截止日期（如 2023-12）等同于可核查的历史时点记录；晚于历史信号的训练语料可能包含后续报道，因此截止声明不足以证明历史无泄漏。模型在未调用时必须如实登记为 `not_run / unknown`。
