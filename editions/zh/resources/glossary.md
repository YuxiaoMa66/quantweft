# 跨章术语定义与消歧

按术语查找定义、用途和易混概念。同一术语在不同章节可能有不同条件，使用时以该章的定义和单位为准。

<a id="g000"></a>

## 阿尔法（Alpha）

指定定价/回归模型中未被因子解释的平均收益分量

表达：\(R^e_t=\alpha+\beta^\top f_t+\epsilon_t\)

用途：归因与基准比较，注明模型和频率。易混点：不是可保证的未来净收益。

<a id="g001"></a>

## 贝塔（Beta）

资产对市场或指定因子的线性敏感度

表达：\(\beta=\mathrm{Cov}(R_i,R_m)/\mathrm{Var}(R_m)\)

用途：衡量与中性化暴露。易混点：不同于相关系数或总波动。

<a id="g002"></a>

## 因子（Factor）

用于解释共同收益或排序投资的特征/组合；需标明类型

表达：模型中为f，特征值可另记x

用途：因子模型与选股。易混点：characteristic与factor return不同。

<a id="g003"></a>

## 信号（Signal）

在决策时点可得、用于交易判断的量

表达：无唯一公式

用途：映射预测到目标权重。易混点：不等于Feature、Position。

<a id="g004"></a>

## 特征（Feature）

模型输入变量，具有定义、窗口与可用时间

表达：x_i,t

用途：拟合与预测。易混点：不得包含未来Label。

<a id="g005"></a>

## 标签（Label）

训练用预测目标及测量区间

表达：未来收益或事件类别

用途：监督学习与purging。易混点：label_end仅为测量终点；实际可得a可更晚，训练须a≤fit_time，本地回放另核入库。

<a id="g006"></a>

## 暴露（Exposure）

对资产、行业、因子或风险源的敏感度/规模

表达：因子暴露可写Bᵀw

用途：风险归因与约束。易混点：头寸权重不总等于风险暴露。

<a id="g007"></a>

## 多头（Long）

正数量资产持仓或正方向合约敞口

表达：w>0需注明计量口径

用途：参与上涨或现金流。易混点：衍生品多头不必有正净现金投入。

<a id="g008"></a>

## 空头（Short）

负数量或负方向敞口，需要融资/借券安排

表达：w<0

用途：对冲与long-short。易混点：损失、借券和保证金不同于多头。

<a id="g009"></a>

## 总暴露（Gross Exposure）

多空绝对权重之和

表达：\(\sum_i\vert w_i\vert \)

用途：杠杆与规模约束。易混点：不等于Net Exposure。

<a id="g010"></a>

## 净暴露（Net Exposure）

有符号资金权重之和

表达：\(\sum_iw_i\)

用途：美元中性检查。易混点：为零不保证Beta中性。

<a id="g011"></a>

## 杠杆（Leverage）

风险/资金敞口相对净资本的比例；口径须说明

表达：gross/NAV或负债/权益

用途：保证金与压力。易混点：不同资产的名义杠杆不可直接比较风险。

<a id="g012"></a>

## 换手（Turnover）

实际交易规模或权重变化相对资本的比例

表达：sum absolute weight changes；是否除2须说明

用途：估算成本与容量。易混点：漂移后的权重才是再平衡起点。

<a id="g013"></a>

## 流动性（Liquidity）

以有限冲击和时间执行给定数量的能力

表达：价差、深度、参与率等联合衡量

用途：交易计划与容量。易混点：高成交量不保证任何规模可成交。

<a id="g014"></a>

## 逆向选择（Adverse Selection）

流动性提供者担心对手方拥有更及时/准确的信息、使其在不利时成交的风险机制

表达：无统一可直接观测公式；可研究方向修正的成交后markout

用途：报价形成与市场质量研究。易混点：不等于单笔负markout，也不自动证明私人信息。

<a id="g015"></a>

## 卖价（Ask）

指定场所、时刻与簿视图中卖方展示的价格

表达：最优Ask为有效可见卖价中的最低价

用途：估算主动买入的可见对手价。易混点：不是中间价，也不保证任意数量按该价成交。

<a id="g016"></a>

## 买价（Bid）

指定场所、时刻与簿视图中买方展示的价格

表达：最优Bid为有效可见买价中的最高价

用途：估算主动卖出的可见对手价。易混点：不是估值或保证退出价。

<a id="g017"></a>

## 深度（Depth）

某数据视图和时点的一个或多个价格层可见数量

表达：每档股数/合约数，或累计深度

用途：对照订单数量与可见对手盘。易混点：快照深度不等于历史队列或保证成交量。

<a id="g018"></a>

## 限价单（Limit Order）

含最高买价或最低卖价边界的订单

表达：买入成交价≤限价；卖出成交价≥限价

用途：控制成交价格边界。易混点：不保证成交；触价不证明成交。

<a id="g019"></a>

## 市价单（Market Order）

以尽快执行为优先、通常不含自设成交价格界限的指令

表达：按场所规则消耗可执行反向流动性

用途：需要即时性的订单。易混点：不保证单一价格；保护价和残单规则依场所而定。

<a id="g020"></a>

## 中间价（Midpoint / Mid）

最佳Bid和Ask的算术平均，仅在双边报价有效时定义

表达：\(m=(a+b)/2\)

用途：估值参考、成交质量基准之一。易混点：不保证可以成交。

<a id="g021"></a>

## 委托簿（Order Book）

指定场所维护或展示的未完成订单状态视图

表达：价位、方向和可见数量等

用途：观察报价与显示深度。易混点：数据视图不必含隐藏量或完整事件历史。

<a id="g022"></a>

## 价格冲击（Price Impact）

交易后市场价格相对指定基准/期限的变化测度

表达：可定义为有方向的成交后mid变化

用途：执行质量与成本研究。易混点：事后markout不自动等于因果冲击。

<a id="g023"></a>

## 队列（Queue）

按具体场所优先规则竞争成交的订单集合/关系

表达：需结合规则和订单事件

用途：估算等待及成交概率。易混点：FIFO并非普遍规则。

<a id="g024"></a>

## 排队位置（Queue Position）

一个订单在适用优先层级中的相对优先状态

表达：依场所、订单类别及事件序列定义

用途：限价单成交概率分析。易混点：聚合快照通常不足以恢复历史位置。

<a id="g025"></a>

## 报价点差（Quoted Spread）

最佳Ask减最佳Bid，指定场所和时点

表达：\(S=a-b\)，报价货币/股；\(s=S/m\)无量纲

用途：描述即时显示报价差。易混点：与成交滑点、实现点差不同。

<a id="g026"></a>

## 滑点（Slippage）

成交价格相对约定基准价格的偏离

表达：方向修正后的fill-reference

用途：评价执行。易混点：若含价差/冲击，不要重复扣费。

<a id="g027"></a>

## 市场冲击（Market Impact）

自身交易引起的价格变化分量

表达：依规模、速度、流动性建模

用途：成本与执行。易混点：与价格自然变动需区分。

<a id="g028"></a>

## 最小报价增量（Tick Size）

特定证券、场所、订单类别和规则版本的最小价格刻度

表达：价位增量 \(\delta\)，单位为报价单位/股或合约

用途：校验报价和订单价格。易混点：依市场和日期变化，不是全市场常数。

<a id="g029"></a>

## 场所碎片化（Venue Fragmentation）

同一证券流动性分布于多个交易场所/系统的状态

表达：需声明场所覆盖与同步口径

用途：评估路由和全市场可执行深度。易混点：单场所簿不等于合并市场。

<a id="g030"></a>

## 成交量加权均价（Volume-Weighted Average Price (VWAP)）

已成交各笔价格按成交数量加权的均值

表达：\(\sum_j q_jP_j/\sum_jq_j\)，成交量为零时未定义

用途：汇总一组实际成交。易混点：不是可保证的未来成交价或单独的市场基准。

<a id="g031"></a>

## 夏普比率（Sharpe Ratio）

平均超额收益相对波动的比例

表达：\(SR=\bar R^e/s(R^e)\)

用途：跨策略风险调整比较。易混点：年化依假设；不等于胜率。

<a id="g032"></a>

## 回撤（Drawdown）

财富相对历史峰值的下降比例

表达：\(D_t=NAV_t/\max_{s\le t}NAV_s-1\)

用途：路径风险。易混点：负值约定；最大回撤可报正损失幅度但须说明。

<a id="g033"></a>

## 信息系数（Information Coefficient (IC)）

同一截面信号与未来收益的相关度

表达：\(IC_t=\mathrm{Corr}_i(s_{i,t},R_{i,t+h})\)

用途：评价横截面预测。易混点：不等于策略Sharpe；Rank IC用秩相关。

<a id="g034"></a>

## 信息比率（Information Ratio (IR)）

主动收益均值相对跟踪误差

表达：mean(Rp-Rb)/std(Rp-Rb)

用途：评价主动管理。易混点：IC均值/IC标准差有时称ICIR，须与IR区分。

<a id="g035"></a>

## 损益（Profit and Loss (PnL)）

持仓和现金流引起的货币变化

表达：NAV变化扣除外部流入

用途：对账与归因。易混点：收益率无量纲，PnL有币种。

<a id="g036"></a>

## 管理资产规模（Assets Under Management (AUM)）

管理的资产价值；gross/net口径明确

表达：按估值时点汇总

用途：规模与容量。易混点：不等于研究策略的可执行Capacity。

<a id="g037"></a>

## 容量（Capacity）

在执行、风险与成本限制下策略可承载规模

表达：随规模的net alpha与风险约束

用途：扩容评估。易混点：不是历史最大成交量。

<a id="g038"></a>

## 净资产值（Net Asset Value (NAV)）

资产公允价值加现金减负债

表达：资产+现金-负债

用途：财富路径与单位净值。易混点：名义敞口和NAV不同。

<a id="g039"></a>

## 前视偏差（Look-ahead Bias）

决策使用当时尚不可得的信息

表达：available_at>signal_time为反例

用途：数据和回测审计。易混点：lag一列不能修复所有版本污染。

<a id="g040"></a>

## 存活者偏差（Survivorship Bias）

历史样本只保留后来仍存在的证券或基金

表达：无单一公式

用途：历史股票池与退市处理。易混点：不是普通缺失值。

<a id="g041"></a>

## 数据窥探（Data Snooping）

重复利用同数据寻找与选择规律

表达：需记录搜索与选择过程

用途：多重检验与holdout。易混点：单个p-value不包括搜索自由度。

<a id="g042"></a>

## 过拟合（Overfitting）

拟合训练噪声导致泛化能力下降

表达：IS/OOS表现与稳定性诊断

用途：模型/参数选择。易混点：高复杂度不是唯一原因。

<a id="g043"></a>

## 前推验证（Walk-forward Validation）

按时间滚动训练并评价未来区间

表达：train end<test start且标签完整可得

用途：部署近似与参数稳定性。易混点：不等于随机K-fold。

<a id="g044"></a>

## 平稳性（Stationarity）

按指定严格/弱定义对时间平移保持分布或二阶矩不变

表达：弱平稳要求恒定均值、方差及仅依lag的协方差

用途：时间序列建模。易混点：看起来平坦不能证明平稳。

<a id="g045"></a>

## 协整（Cointegration）

同阶非平稳序列存在平稳线性组合

表达：\(z_t=y_t-\beta x_t\sim I(0)\)，且x,y为I(1)

用途：配对与共同趋势。易混点：Correlation != Cointegration。

<a id="g046"></a>

## 时点可用信息（Point-in-Time (PIT)）

仅按历史时点可获得的版本构造研究输入

表达：外部源时点按 available_at；本地回放另需 ingested_at 同时达标

用途：财报、成分、另类数据。易混点：报告期末不等于公告时间。

<a id="g047"></a>

## 跟踪误差（Tracking Error）

主动收益的波动率

表达：std(Rp-Rb)，注明频率

用途：IR与基准风险。易混点：不是平均偏离。

<a id="g048"></a>

## 预期损失（Expected Shortfall (ES)）

超过给定损失分位的尾部平均，离散情形需分位积分定义

表达：连续分布时E[L\vert L≥VaR]

用途：尾部风险限制。易混点：不是VaR之上的额外损失金额。

<a id="g049"></a>

## 风险中性概率（Risk-neutral Probability）

使适当贴现可交易资产成为鞅的定价测度

表达：Q与真实测度P区分

用途：无套利衍生品定价。易混点：不表示投资者没有风险厌恶。

<a id="g050"></a>

## 剔除重叠标签（Purging）

剔除训练标签区间与测试标签区间交叠的样本

表达：区间交集非空即排除

用途：多日标签验证。易混点：固定gap未必覆盖不同标签长度。

<a id="g051"></a>

## 禁入窗口（Embargo）

测试块后按规则禁止邻近样本入训练；方向需说明

表达：预设时间/样本窗口

用途：含前后训练块的验证。易混点：纯过去训练不照抄双向CV规则。

<a id="g052"></a>

## 向量化（Vectorization）

将数组运算交给底层实现，保留形状与广播规则。

表达：无单一公式；核对输入/输出形状、轴语义和数值对齐。

用途：计算收益面板。易混点：速度不证明时间对齐正确。

<a id="g053"></a>

## 广播（Broadcasting）

按兼容轴扩展数组参与计算。

表达：无单一公式；参与数组的轴须满足广播兼容，并核对广播后的形状和轴含义。

用途：多资产资金权重运算。易混点：一维行/列向量的轴可能不同。

<a id="g054"></a>

## 滚动窗口（Rolling Window）

在每个当前位置取固定长度的最近观测；应注明端点与最少样本数。

表达：\(\mathcal W_t=\{t-W+1,\ldots,t\}\)，\(\bar x_t=W^{-1}\sum_{j=0}^{W-1}x_{t-j}\)。本章口径包含当前观测 \(t\)，不含未来观测；若信号须在本期结果形成前生成，窗口应截至 \(t-1\)（或将结果滞后一期）。

用途：估计历史均值与波动。易混点：expanding保留自起点累计数据。

<a id="g055"></a>

## 可用时点（Available At）

外部来源/供应商版本首次可供研究使用的时刻。

表达：对版本 \(v\) 和信号时点 \(s\)，点时刻示例门槛为 \(\operatorname{available\_at}(v)\le s\)；区间截止可按协议采用严格小于。

用途：公告资格过滤。易混点：不是report period或入库时间。

<a id="g056"></a>

## 入库时点（Ingested At）

本系统实际收到并持久化该版本的时刻。

表达：对版本 \(v\) 和信号时点 \(s\)，入库门槛为 \(\operatorname{ingested\_at}(v)\le s\)；须与可用时点分别满足。

用途：系统回放与延迟审计。易混点：不是源版本的新旧顺序。

<a id="g057"></a>

## 修订发布时间（Revision Time）

来源更正版发布的时刻，记录修订何时对外发布。

表达：\(\operatorname{revision\_time}(v)\) 单独保存为版本字段；没有独立通用计算公式。

用途：重述后信号更新。易混点：不回填到早于修订的信号。

<a id="g058"></a>

## 时点连接（As-of Join）

按键和时间资格匹配信号时点当时可得的版本。

表达：\(\mathrm{eligible}(v,s)=\mathbf1\{\operatorname{available\_at}(v)\le s\}\mathbf1\{\operatorname{ingested\_at}(v)\le s\}\)；合格版本按声明的期间/版本规则排序，财报先最新期间、再该期间内最新公开版本，事件连接按其键和时间契约。

用途：PIT财报与事件连接。易混点：普通latest join会泄漏未来。

<a id="g059"></a>

## 公司行动（Corporate Action）

改变股份数量、现金流或证券权利的事件。

表达：无单一公式；按事件记录有效日期、股份变化、应收/实付现金及费用；调整价格须说明事件和调整规则。

用途：拆股、股息、换股与账本。易混点：不是价格上涨的经济收益。

<a id="g060"></a>

## 总回报（Total Return）

计入该持有区间中归属于持有人的价格变化和现金分派后的收益。

表达：在数量不变、同币种同每份单位、无外部现金流的简化情形，\(R_t^{\mathrm{total}}=(P_t+D_t-P_{t-1})/P_{t-1}\)。这里区间为 \((t-1,t]\)，\(D_t\) 只计归属该区间的分派；已含股息的总回报/复权序列不得再次加 \(D_t\)。

用途：股息、组合与基准比较。易混点：不等于原价涨跌；不可重复加分红。

<a id="g061"></a>

## 退市（Delisting）

证券停止在指定市场挂牌交易或从样本中退出。

表达：无单一公式；若常规收益与退市收益是同一持仓、同一币种、按先后发生的简单收益，\(R_{\mathrm{combined}}=(1+R_{\mathrm{regular}})(1+R_{\mathrm{delist}})-1\)；若是同一期间的替代估值，不套用此式。

用途：退出、终值、历史股票池。易混点：缺少末价不能填零收益。

<a id="g062"></a>

## 永久证券标识（Permanent Security Identifier）

稳定识别证券实体且能追踪代码历史的键。

表达：无单一公式；将永久证券键与代码、交易所、币种和有效区间关联，并保留映射何时进入系统。

用途：跨源与跨时连接。易混点：ticker可能更名或复用。

<a id="g063"></a>

## 交易日历（Trading Calendar）

定义市场开放日期、交易时段、休市与特殊会话。

表达：无单一公式；按交易场所保存开放日期集合及开收市、午休、提前收市和拍卖时段。

用途：成交和收益端点。易混点：商业日历与固定工作日不够。

<a id="g064"></a>

## 基点（Basis Point (bps)）

收益率或利率变化的计量单位。

表达：\(1\,\mathrm{bp}=0.01\%=0.0001\)；\(10\,\mathrm{bp}=0.001\)。

用途：成本费率。易混点：10bps=0.001，不是0.1。

<a id="g065"></a>

## 内积（Inner Product）

对应分量乘积相加

表达：\(a^\top b\)

用途：固定持有权重与同区间收益映射。易混点：不同于逐元素乘积。

<a id="g066"></a>

## 秩（Rank）

列空间的独立方向数

表达：\(\mathrm{rank}(X)\)

用途：共线性与可解性诊断。易混点：列数不等于独立方向数。

<a id="g067"></a>

## 零空间（Null Space）

被矩阵映射为零的方向集合

表达：\(Av=0\)

用途：区分暴露相同但持仓不同的组合。易混点：不代表矩阵之外风险为零。

<a id="g068"></a>

## 半正定（Positive Semidefinite）

实对称矩阵所有方向二次型非负

表达：\(v^\top Av\ge0\)

用途：合法协方差的必要结构。易混点：允许奇异，不等于正定。

<a id="g069"></a>

## 条件数（Condition Number）

相对误差放大的数值诊断

表达：\(s_{max}/s_{min}\)

用途：诊断近奇异求解敏感性。易混点：不是预测置信度。

<a id="g070"></a>

## 奇异值分解（Singular Value Decomposition）

任意实矩阵的正交方向与非负尺度分解

表达：\(X=UDV^\top\)

用途：降维、秩、数值诊断。易混点：奇异值不总等于特征值。

<a id="g071"></a>

## 主成分分析（Principal Component Analysis）

中心化训练数据的最大投影方差正交方向

表达：\(T=X_cV_k\)

用途：风险结构与特征变换。易混点：解释方差不等于预测力。

<a id="g072"></a>

## 解释方差比（Explained Variance Ratio）

成分样本方差占总样本方差比例

表达：\(\lambda_j/\sum_l\lambda_l\)

用途：检查训练数据压缩程度。易混点：不是交易收益份额。

<a id="g073"></a>

## 估计目标（Estimand）

希望从数据推断的明确总体或模型对象

表达：如指定机制下的均值mu

用途：先写总体、窗口和条件。易混点：不等于这批样本的平均数。

<a id="g074"></a>

## 估计量（Estimator）

随机样本的函数，观察前具有抽样分布

表达：T(X1,...,Xn)

用途：比较偏差方差与风险。易混点：Estimate是观察后的数值。

<a id="g075"></a>

## 抽样分布（Sampling Distribution）

同一生成模型重复抽样时统计量的分布

表达：均值方差IID时sigma²/n

用途：标准误、区间与功效。易混点：不是单期收益分布。

<a id="g076"></a>

## 标准误（Standard Error）

估计量抽样分布的标准差

表达：IID均值SE=s/sqrt(n)

用途：衡量参数估计精度。易混点：不是单期Standard Deviation。

<a id="g077"></a>

## 一致性（Consistency）

估计量随样本量增大依概率靠近目标参数

表达：P(abs(theta_hat-theta)>epsilon)→0

用途：检验大样本条件是否适用。易混点：不等于有限样本无偏。

<a id="g078"></a>

## 最大似然估计（Maximum Likelihood Estimation）

在参数空间内使观察的模型密度或概率最大的估计

表达：argmax L(theta;x)

用途：高斯/序列参数拟合。易混点：Likelihood不是Posterior。

<a id="g079"></a>

## 置信区间（Confidence Interval）

重复抽样区间程序覆盖固定参数的性质

表达：IID Gaussian: mean±t*s/sqrt(n)

用途：同时报告效果与不确定性。易混点：不是参数后验概率或预测区间。

<a id="g080"></a>

## p值（p-value）

原假设模型下统计量至少同样极端的尾部概率

表达：双侧t: 2*SF(abs(t))

用途：预定检验规则的输出。易混点：不是H0为真概率。

<a id="g081"></a>

## 检验功效（Power）

指定备择下拒绝原假设的概率

表达：1−Type II error probability

用途：按经济效果规划样本量。易混点：不是后验策略获利概率。

<a id="g082"></a>

## 自助重采样（Bootstrap）

以经验分布近似生成机制后重复计算统计量

表达：有放回重采样

用途：估计抽样不确定性。易混点：次数不是新增市场观察。

<a id="g083"></a>

## 循环区块自助法（Circular Block Bootstrap）

固定块内保留顺序、边界循环、拼接截断的重采样

表达：块长L；总长n

用途：保留部分短期依赖。易混点：不同于随机块长Stationary Bootstrap。

<a id="g084"></a>

## 有效样本量（Effective Sample Size）

针对具体估计量匹配独立方差的近似信息量

表达：AR1均值大样本n*(1−phi)/(1+phi)

用途：解释序列依赖对均值SE的影响。易混点：不是所有模型的统一自由度。

<a id="g085"></a>

## 可信区间（Credible Interval）

指定模型和先验下具有给定后验质量的区间

表达：Beta后验分位数

用途：表达参数的后验不确定性。易混点：含义不同于Confidence Interval。

<a id="g086"></a>

## 共轭（Conjugacy）

更新后后验仍属于先验分布族

表达：Beta(a,b)+s/f→Beta(a+s,b+f)

用途：解释先验与数据权重。易混点：不代表先验已观察真实交易。

<a id="g087"></a>

## 导数（Derivative）

函数对一个输入的局部变化率；单位为输出单位除以输入单位。

表达：\(f'(x)=\lim_{h\to0}[f(x+h)-f(x)]/h\)。

用途：对价格、参数、目标评分做局部敏感度。易混点：局部响应不是走势预测。

<a id="g088"></a>

## 偏导数（Partial Derivative）

固定其余输入时，函数对一个坐标的局部变化率。

表达：\(\frac{\partial f}{\partial w_i}=\lim_{h\to0}\frac{f(w_1,\ldots,w_i+h,\ldots,w_n)-f(w)}{h}\)，若该极限存在。

用途：分离收益率和期限的影响。易混点：偏导存在不保证全可微。

<a id="g089"></a>

## 梯度（Gradient）

标量函数各偏导组成的列向量。

表达：\(\nabla f(w)=(\partial f/\partial w_1,\ldots,\partial f/\partial w_n)^\top\)。

用途：搜索下降方向、做敏感度检查。易混点：约束最优点不必全空间梯度为零。

<a id="g090"></a>

## 海森矩阵（Hessian）

收集函数全部二阶偏导的矩阵。

表达：\(H_{ij}=\partial^2 f(w)/\partial w_i\partial w_j\)。

用途：曲率、二次近似与凸性检查。易混点：半正定驻点不能自动分类为严格极小。

<a id="g091"></a>

## 泰勒展开（Taylor Expansion）

在足够光滑条件下，用局部导数近似函数，并说明余项条件。

表达：\(f(w+h)=f(w)+\nabla f(w)^\top h+\tfrac12h^\top\nabla^2f(w)h+R(h)\)。若 \(f\in C^2\)，则 \(R(h)=o(\|h\|^2)\)；三阶拉格朗日余项形式需 \(C^3\) 等条件。

用途：局部定价与数值算法。易混点：截断误差不同于参数估计误差。

<a id="g092"></a>

## 条件概率（Conditional Probability）

事件 \(B\) 已发生且 \(\Pr(B)>0\) 时事件 \(A\) 的概率。

表达：\(\Pr(A\mid B)=\Pr(A\cap B)/\Pr(B)\)，要求 \(\Pr(B)>0\)。

用途：告警后验、条件模型。易混点：\(\Pr(A\mid B)\ne\Pr(B\mid A)\)一般成立。

<a id="g093"></a>

## 随机游走（Random Walk）

由逐期随机增量累加形成的位置过程；须说明增量模型。

表达：\(S_n=\sum_{i=1}^{n}\xi_i\)。

用途：构造无趋势基准。易混点：平均增量稳定不代表累计位置稳定。

<a id="g094"></a>

## 马尔可夫过程（Markov Process）

给定当前状态后，条件未来分布不再依赖更早历史。

表达：\(\Pr(X_{t+1}\in A\mid X_0,\ldots,X_t)=\Pr(X_{t+1}\in A\mid X_t)\)。

用途：状态基准与动态决策。易混点：不自动说明可观测状态或稳定参数。

<a id="g095"></a>

## 泊松过程（Poisson Process）

具有独立、平稳增量且速率恒定的齐次计数过程。

表达：\(N(t)-N(s)\sim\operatorname{Poisson}(\rho(t-s))\)，\(0\le s<t\)；\(\rho\) 的单位为事件/时间。

用途：构造事件到达模型。易混点：强度不是区间计数；成簇到达可能违背假设。

<a id="g096"></a>

## 指数分布（Exponential Distribution）

速率 \(\rho>0\) 下的非负等待时间分布。

表达：\(\Pr(T>t)=e^{-\rho t}\)，\(\mathbb E[T]=1/\rho\)。

用途：齐次Poisson等待时间。易混点：软件scale是速率的倒数。

<a id="g097"></a>

## 普通最小二乘（OLS）

选择使残差平方和最小的系数；设计矩阵满列秩时解唯一。

表达：\(\hat\beta=\arg\min_b (y-Xb)^\top(y-Xb)\)。

用途：风险暴露与条件关系。易混点：样本内拟合不等于未来可交易预测。

<a id="g098"></a>

## 异方差（Heteroskedasticity）

条件误差方差随观测或特征改变。

表达：无单一公式；以 \(\operatorname{Var}(\varepsilon_t\mid X_t)\) 表示，并检查其是否随 \(t\) 或 \(X_t\) 变化。

用途：选择协方差估计、检查残差。易混点：HC3不修复跨期误差相关。

<a id="g099"></a>

## 异方差与自相关一致协方差（HAC）

在满列秩OLS设计下，通过加权得分自协方差估计跨期相关的系数协方差；结果依赖误差过程、样本和带宽条件。

表达：\(w_\ell=1-\ell/(L+1)\)，\(\widehat S=S_0+\sum_{\ell=1}^{L}w_\ell(S_\ell+S_\ell^\top)\)，\(\widehat V_{\mathrm{HAC}}=(X^\top X)^{-1}\widehat S(X^\top X)^{-1}\)；\(S_\ell=\sum_{t=\ell+1}^{T}x_t\widehat\varepsilon_t\widehat\varepsilon_{t-\ell}x_{t-\ell}^{\top}\)，x为列特征、ε为OLS残差（无小样本修正、得分和未除T）。

用途：等距单序列参数推断。易混点：固定滞后或robust标签不保证普遍有效。

<a id="g100"></a>

## 多重共线性（Multicollinearity）

特征列近线性依赖，可能造成参数估计不稳定。

表达：无单一公式；完全共线时 \(\operatorname{rank}(X)<k\)，系数不唯一；近共线诊断须考虑变量尺度。

用途：特征稳定性诊断。易混点：大条件数受尺度影响，非因果证据。

<a id="g101"></a>

## 软阈值（Soft Thresholding）

对标准化的一维 Lasso 系数进行收缩，并在阈值内置零的映射。

表达：\(\hat b=\operatorname{sign}(z)(\lvert z\rvert-\lambda)_+\)，其中 \((a)_+=\max(a,0)\)。

用途：一维标准化Lasso解与稀疏直觉。易混点：零系数不是经济作用为零的证明。

<a id="g102"></a>

## 目标函数（Objective Function）

需要最小化或最大化的标量，须明确单位与方向

表达：\(f_0(x)\)

用途：将收益与风险偏好转为决策准则。易混点：目标值不自动等于收益率。

<a id="g103"></a>

## 可行集合（Feasible Set）

同时满足全部约束及定义域的决策集合

表达：\(\{x:f_i(x)\leq0,\ Ax=b\}\)

用途：预算、长仓、杠杆、产能限制。易混点：有可行点不保证有限或可达最优值。

<a id="g104"></a>

## 凸函数（Convex Function）

弦上函数值不高于端点函数值的凸组合

表达：\(f(\theta x+(1-\theta)y)\leq\theta f(x)+(1-\theta)f(y)\)

用途：判断全局求解的数学结构。易混点：凸性不验证估计质量。

<a id="g105"></a>

## 二次规划（Quadratic Program (QP)）

二次目标配合线性约束；凸QP要求二次矩阵半正定

表达：\(\min \frac12x^\top Px+c^\top x\)

用途：均值—方差与最小二乘。易混点：一般QP不都凸。

<a id="g106"></a>

## 拉格朗日函数（Lagrangian）

以乘子将目标与约束组成函数

表达：\(L=f_0+\sum_i\lambda_i f_i+\nu^\top(Ax-b)\)

用途：对偶、最优性与局部敏感度。易混点：不等式方向决定乘子符号。

<a id="g107"></a>

## 弱对偶（Weak Duality）

任意可行对偶下界不超过可行原始目标

表达：\(d^\star\leq p^\star\)

用途：给最小化问题建立下界。易混点：非凸也成立；不等于零对偶间隙。

<a id="g108"></a>

## 斯莱特条件（Slater Condition）

凸问题在共同定义域相对内部存在满足等式且严格满足不等式的点；仿射不等式可用精炼版本

表达：标准 \(f_i(x)<0,\ Ax=b\)

用途：保证强对偶；有限原始最优值时保证对偶可达。易混点：充分而非必要，不可删去定义域资格。

<a id="g109"></a>

## 卡鲁什—库恩—塔克条件（KKT Conditions）

原始可行、对偶可行、互补松弛和驻点条件

表达：\(\nabla_xL=0,\ \lambda_i f_i=0\)

用途：凸可微问题完整KKT是全局最优充分条件。易混点：若要从最优反推乘子，还需适用正则条件。

<a id="g110"></a>

## 驻点条件残差（Stationarity Residual）

拉格朗日梯度距离零的数值度量

表达：\(\|\nabla_xL\|_\infty\)

用途：核对梯度与活动约束乘子的平衡。易混点：与时间序列平稳性无关；单项小不证明完整最优性。

<a id="g111"></a>

## 影子价格（Shadow Price）

当前约束右端变化对最优目标的局部边际作用

表达：最小化 \(f_i\leq u_i\) 时 \(\partial p^\star/\partial u_i=-\lambda_i^\star\)

用途：解释资源价值或限制成本。易混点：有目标/资源单位，不能跨活动集任意外推。

<a id="g112"></a>

## 清算（Clearing）

确认交易义务、净额及风险处理；CCP清算可能替代原交易关系

表达：按场所规则

用途：确定合约义务与抵押。易混点：不是证券现金实际交收。

<a id="g113"></a>

## 交收（Settlement）

按合同实际转移现金、证券或其他资产

表达：成交T与交收日分开

用途：现金与资产账本。易混点：T+1只限适用规则与营业日历。

<a id="g114"></a>

## 合约乘数（Contract Multiplier）

将报价变化转为每份合约货币损益的比例

表达：份数×货币/点×点数

用途：期货敞口与PnL。易混点：不是保证金金额。

<a id="g115"></a>

## 变动保证金（Variation Margin）

按清算规则收付的逐期价格损益现金流

表达：q M ΔF

用途：现金压力与损益结算。易混点：初始保证金是另一个资金项目。

<a id="g116"></a>

## 抵押品折扣（Haircut）

担保价值中不予融资的比例

表达：现金=担保市值×(1−h)，简化约定

用途：repo融资与压力。易混点：不是违约最大损失承诺。

<a id="g117"></a>

## 几何平均收益（Geometric Mean Return）

同长度期间增长因子乘积的n次根减1

表达：\(\prod_t(1+R_t)^{1/n}-1\)

用途：复利增长。易混点：简单收益跨资产组合仍用初始权重。

<a id="g118"></a>

## 时间加权收益（Time-weighted Return (TWR)）

在外部流量节点分段计算并复合的持有表现

表达：分段增长因子相乘减1

用途：剔除入金规模影响。易混点：不是简单终初财富比。

<a id="g119"></a>

## 内部收益率（Internal Rate of Return (IRR)）

使指定日期现金流贴现和为零的收益率

表达：以现金流时间方程求根

用途：资金时点与规模体验。易混点：非传统符号现金流可能无根或多根。

<a id="g120"></a>

## 经营活动现金流（Cash Flow from Operations (CFO)）

期间经营现金流入与流出净额

表达：依报表同期间同版本

用途：盈利现金转换。易混点：已经包含营运资金变化，不能再扣一次。

<a id="g121"></a>

## 资本开支（Capital Expenditure (CapEx)）

选定长期资产投资支出；本章将现金购置支出转为正数

表达：正支出=−负PP&E现金流行

用途：投资强度和定义FCF。易混点：现金CapEx与非现金资产新增不完全相同。

<a id="g122"></a>

## 自由现金流（Free Cash Flow (FCF)）

本章明示定义为CFO减选定现金CapEx，非统一会计行

表达：CFO−正CapEx

用途：现金特征与估值输入辨别。易混点：不自动等于FCFF/FCFE或扣完债务服务的现金。

<a id="g123"></a>

## 滚动十二个月（Trailing Twelve Months (TTM)）

截至指定报告窗口最近十二个月的累计流量

表达：同定义四季度之和需处理累计报表

用途：统一跨公司期间。易混点：TTM数据仍受每版可用时间约束。

<a id="g124"></a>

## 不应依赖通知（Non-reliance Notice）

宣布既有报表不应继续依赖的状态事件

表达：状态h_v(s)与双时钟资格共同筛选

用途：重述前空窗的特征资格。易混点：没有新数值也能令旧值失效。

<a id="g125"></a>

## 选定经营营运资本（Selected Operating Working Capital）

本章六类经营资产负债的明示子集

表达：AR+VendorRec+Inventory+OtherOpCA−AP−DeferredRevenue

用途：理解现金占用与转换。易混点：不是通用财报营运资本定义，需非现金调节。

<a id="g126"></a>

## 随机贴现因子（Stochastic Discount Factor (SDF)）

按状态将未来支付折为今天价格的正定价权重；均衡解释另需假设

表达：\(P=E[mX]\)

用途：比较风险状态中的支付价值；说明无套利/均衡分工。易混点：一般SDF未必唯一；不自动是已估计的真实偏好。

<a id="g127"></a>

## 因子载荷（Factor Loading）

指定训练样本中收益对所选因子收益的多元线性响应

表达：\(y=\alpha+\beta^\top f+\varepsilon\)

用途：控制其他因子后解释历史协动。易混点：不同于持仓资金权重或持仓加权特征。

<a id="g128"></a>

## 残差风险（Residual Risk）

相对指定因子模型未解释收益变化的风险

表达：\(\Sigma_\varepsilon=Cov(\varepsilon)\)

用途：补充共同因子风险，保留跨资产剩余相关。易混点：样本正交不表示未来独立或无风险。

<a id="g129"></a>

## 企业自由现金流（Free Cash Flow to Firm (FCFF)）

融资支付前、同经营范围全体资本提供者现金流；明确税和再投资调整

表达：\(EBIT(1-T)+DA-CapEx-\Delta NWC+Adj\)

用途：配匹配范围WACC与企业经营价值。易混点：CFO减CapEx不自动等于FCFF。

<a id="g130"></a>

## 股权自由现金流（Free Cash Flow to Equity (FCFE)）

归属于明确普通股索取权的现金流；NCI及优先股必须同范围调整

表达：\(NI+DA-CapEx-\Delta NWC+NetBorrowing\)（简化同范围普通股+债务）

用途：配普通股成本和普通股价值。易混点：母公司NI不能直接混用全集团现金项目。

<a id="g131"></a>

## 加权平均资本成本（Weighted Average Cost of Capital (WACC)）

与估值现金流范围匹配的市场价值加权必要报酬

表达：\(E/(D+E)k_e+D/(D+E)k_d(1-T)\)（简化）

用途：折现企业现金流；权益范围与NCI/优先股一致。易混点：不是任意贴现率，也不是只按母公司市值匹配合并FCFF。

<a id="g132"></a>

## 非控股权益（Noncontrolling Interest (NCI)）

并表经营范围中不归母公司股东的权益索取权

表达：合并EV桥在适用定义下加NCI

用途：匹配合并经营利润、价值桥与资本成本。易混点：账面NCI不等于已核验市场价值。

<a id="g133"></a>

## 嵌套模型（Nested Models）

较小模型是保持相同样本和旧列、限制新增参数后的较大模型特例

表达：固定X列后增加新列

用途：隔离新增变量的样本内解释作用并设正确检验。易混点：本快照官方FF3/FF5旧列不同，不能直接当严格嵌套。

<a id="g134"></a>

## 严格平稳（Strict Stationarity）

任意有限维联合分布对共同时间平移不变

表达：分布不随共同平移改变

用途：陈述时间模型的分布假设。易混点：不要求二阶矩存在；图形平坦不证明。

<a id="g135"></a>

## 弱平稳（Weak Stationarity）

有限二阶矩、固定均值与只依赖间隔的协方差

表达：\(\gamma(k)=\operatorname{Cov}(X_t,X_{t-k})\)

用途：自相关和线性预测理论。易混点：不自动推出严格平稳。

<a id="g136"></a>

## 白噪声（White Noise）

本教材指零均值、同方差、非零滞后协方差零

表达：\(\gamma(k)=0,\ k\ne0\)

用途：描述二阶剩余依赖。易混点：不等于IID或条件均值为零。

<a id="g137"></a>

## 自相关函数（Autocorrelation Function (ACF)）

不同滞后下同序列的线性相关

表达：\(\rho(k)=\gamma(k)/\gamma(0)\)

用途：候选时间模型与残差诊断。易混点：有限样本图不证明总体截尾。

<a id="g138"></a>

## 偏自相关函数（Partial Autocorrelation Function (PACF)）

控制中间滞后后的远端线性关系

表达：总体AR(k)线性投影最后系数

用途：辨别AR候选阶数。易混点：有限样本估计器不同；不是因果效应。

<a id="g139"></a>

## 创新项（Innovation）

模型中不能由既有信息线性解释的新冲击，具体信息集须指定

表达：AR例为\(\varepsilon_t\)

用途：预测误差和风险尺度。易混点：白噪声假设不自动给独立创新。

<a id="g140"></a>

## 可逆性（Invertibility）

可由当前与过去可观测序列稳定恢复创新的表示条件

表达：MA(1)通常\(\vert\theta\vert<1\)

用途：时间模型识别与估计。易混点：不可逆不等于不平稳。

<a id="g141"></a>

## 滞后算子（Lag Operator）

把序列向过去移一个观测步的算子

表达：\(LX_t=X_{t-1}\)

用途：ARMA/差分多项式表达。易混点：月步不是固定自然日数。

<a id="g142"></a>

## 预测区间（Prediction Interval）

未来观测的模型不确定性范围，含未来冲击

表达：\(\hat X\pm z\sqrt{V_h}\)

用途：评价覆盖与误差。易混点：与条件均值置信区间不同；非保证。

<a id="g143"></a>

## 滚动起点预测（Rolling-Origin Forecast）

在递增预测时点仅用此前前缀估计与预测

表达：每期训练截至\(T\)，目标\(T+1\)

用途：时间顺序模型验证。易混点：不自动解决数据发布时间/PIT。

<a id="g144"></a>

## 差分阶数（Integration Order）

本章整数阶，d次差分达弱平稳短记忆I(0)，更少次数不行

表达：\(\Delta^d y_t\sim I(0)\)

用途：选择水平、差分或协整模型。易混点：弱平稳本身不保证短记忆。

<a id="g145"></a>

## 单位根（Unit Root）

AR多项式单位圆根；本章ADF聚焦+1根

表达：\(y_t=y_{t-1}+\varepsilon_t\)

用途：避免随机趋势伪回归。易混点：−1等根需区分，非所有检验都由普通ADF解决。

<a id="g146"></a>

## Engle–Granger协整检验（Engle–Granger Test）

长期回归残差的专用单位根检验

表达：\(u_t=y_t-\alpha-\beta x_t\)

用途：探索I(1)候选的长期关系。易混点：估计残差不能用普通ADF临界值。

<a id="g147"></a>

## Granger预测检验（Granger-Causality Test）

给定信息集下过去x是否增加对y的预测信息

表达：y方程中x的滞后系数联合为零

用途：检查指定方向增量预测。易混点：不是干预的结构因果。

<a id="g148"></a>

## 错误发现率（False Discovery Rate (FDR)）

被拒绝假设中错误发现比例的期望，无拒绝时比例取0

表达：\(E[V/\max(R,1)]\)

用途：明确多重筛查家族与BH条件。易混点：不等于FWER；本项R为拒绝数而非收益。

<a id="g149"></a>

## 家族错误率（Family-Wise Error Rate (FWER)）

家族至少一个错误拒绝的概率

表达：\(P(V\ge1)\)

用途：解释Holm等检验族目标。易混点：BH旨在FDR，依赖条件未核不能保证控制。

<a id="g150"></a>

## 已实现方差（Realized Variance (RV)）

同一区间子区间对数收益的平方和

表达：\(RV=\sum_i x_i^2\)

用途：事后路径风险度量、预测代理。易混点：不去均值；不是样本方差或潜在条件方差真值。

<a id="g151"></a>

## 二次变差（Quadratic Variation (QV)）

适当细网格平方增量和的极限路径对象

表达：连续部分积分方差加跳跃平方

用途：联系价格过程与RV。易混点：有限网格和微观结构噪声破坏简单等同。

<a id="g152"></a>

## 条件方差（Conditional Variance）

给定此前信息的目标期收益方差

表达：\(h_t=Var(r_t\mid\mathcal F_{t-1})\)

用途：一期风险预测和风险预算输入。易混点：信息集、频率和单位须明示；非方向预测。

<a id="g153"></a>

## 波动聚集（Volatility Clustering）

收益尺度/平方创新的时间依赖表现

表达：平方创新样本ACF诊断

用途：提出动态风险模型假设。易混点：不是每次大跌后必然继续大跌。

<a id="g154"></a>

## 指数加权移动平均（Exponentially Weighted Moving Average (EWMA)）

新冲击平方与旧预测按指数权重更新方差

表达：\(h_{t+1}=\lambda h_t+(1-\lambda)\epsilon_t^2\)

用途：透明风险递推基准。易混点：初始化必需；零冲击会衰减，无独立长期方差锚。

<a id="g155"></a>

## 自回归条件异方差（ARCH）

条件方差由过去创新平方生成

表达：\(h_t=\omega+\sum_i\alpha_i\epsilon_{t-i}^2\)

用途：波动动态基准。易混点：创新是去条件均值的收益；不同于AR收益均值模型。

<a id="g156"></a>

## 广义自回归条件异方差（GARCH）

ARCH再加入过去条件方差

表达：\(h_t=\omega+\alpha\epsilon_{t-1}^2+\beta h_{t-1}\)

用途：持续风险与多步方差预测。易混点：有限二阶矩、严格平稳、四阶矩是不同条件。

<a id="g157"></a>

## 准极大似然（Quasi-Maximum Likelihood (QML)）

用工作密度优化参数，实际分布可不同但须有正则条件

表达：高斯目标含\(\log h+\epsilon^2/h\)

用途：风险参数估计。易混点：非正态不自动有效；一致性与稳健标准误分开。

<a id="g158"></a>

## 准似然损失（QLIKE）

正方差预测的对数项加代理除以预测

表达：\(L(q,h)=\log h+q/h\)

用途：同目标月份预测比较。易混点：可以为负；代理条件无偏未证明不保证稳健排序。

<a id="g159"></a>

## 市场微观结构噪声（Market Microstructure Noise）

观测价与有效价之间的测量/交易结构成分

表达：\(Y_i=X_i+u_i\)（简化）

用途：采样频率与RV稳健性分析。易混点：不一定独立；更密采样未必更准。

<a id="g160"></a>

## 状态空间模型（State-Space Model）

把潜在状态转移与观测映射分开的模型

表达：\(x_t=Fx_{t-1}+\eta_t, y_t=h_tx_t+\epsilon_t\)

用途：动态暴露和潜在风险递推。易混点：状态变量未必可识别；符号需对照软件。

<a id="g161"></a>

## 潜在状态（Latent State）

描述动态但不能直接观测的模型变量

表达：动态\(x_t=[\alpha_t,\beta_t]^\top\)

用途：状态恢复和不确定性分析。易混点：估计状态不是直接观测真值。

<a id="g162"></a>

## 过程噪声（Process Noise）

驱动状态转移的随机变化

表达：\(Cov(\eta_t)=Q\)

用途：描述暴露可变程度。易混点：与观测收益噪声R不同。

<a id="g163"></a>

## 观测噪声（Observation Noise）

观测相对状态映射的误差

表达：\(Var(\epsilon_t)=R>0\)

用途：区分测量与状态不确定性。易混点：R符号在statsmodels另有含义。

<a id="g164"></a>

## 滤波状态（Filtered State）

使用截至当前观测的信息估计当前状态

表达：\(E[x_t\mid y_{0:t}]\)

用途：月末更新下一期暴露。易混点：不能回填同月月初信号。

<a id="g165"></a>

## 平滑状态（Smoothed State）

还使用目标时点之后观测的状态估计

表达：\(E[x_t\mid y_{0:T}],T>t\)

用途：事后历史解释。易混点：本章未实现smoother；不是实时信号。

<a id="g166"></a>

## 创新方差（Innovation Variance）

本期观测与先验观测差额的模型方差

表达：\(S_t=h_tP_t^-h_t^\top+R\)

用途：标准化创新、更新尺度。易混点：与状态协方差P单位/维度不同。

<a id="g167"></a>

## 卡尔曼增益（Kalman Gain）

将观测创新映为状态均值修正的系数

表达：\(K_t=P_t^-h_t^\top/S_t\)

用途：融合状态与新观测信息。易混点：不是概率；beta/收益增益可大于1。

<a id="g168"></a>

## 动态对冲比率（Dynamic Hedge Ratio）

随状态估计改变的明确名义/风险比率

表达：资产名义A对应市场名义\(-\beta A\)

用途：样本外风险控制假设。易混点：beta不是直接股份比；需价格、币种、成本、时间戳。

<a id="g169"></a>

## 全局最小方差组合（Global Minimum Variance Portfolio (GMV)）

预算约束下风险最低的组合；本章闭式解允许卖空且要求正定

表达：\(w=\Sigma^{-1}1/(1^\top\Sigma^{-1}1)\)

用途：组合风险基准。易混点：不同于长仓约束最小方差解。

<a id="g170"></a>

## 有效前沿（Efficient Frontier）

可行集合中不被任何其他点支配：风险不更高、均值不更低，且至少一项严格

表达：正定无约束情形取均值不低于GMV的分支

用途：排除均值—方差占优组合。易混点：下半支不是有效分支。

<a id="g171"></a>

## 资本配置线（Capital Allocation Line (CAL)）

按比例混合现金和一个风险基金的均值—波动直线

表达：\(\mu_p=r_f+S_T\sigma_p\)（正超额方向）

用途：给定矩下优化资金配置。易混点：CAPM均衡市场基金的最优线才是CML。

<a id="g172"></a>

## 切点组合（Tangency Portfolio）

给定同利率现金借贷时最优风险方向的预算归一化基金

表达：\(w_T\propto\Sigma^{-1}(\mu-r_f1)\)

用途：最大Sharpe方向。易混点：正预算正超额基金要求归一化分母正。

<a id="g173"></a>

## 协方差收缩（Covariance Shrinkage）

将样本矩阵向结构目标混合，降低估计损失

表达：\(S^*=\kappa mI+(1-\kappa)S\)

用途：改善病态风险估计。易混点：不会自动保证未来风险估计正确；常数数据仍为零矩阵。

<a id="g174"></a>

## 等风险贡献（Equal Risk Contribution (ERC)）

每项波动贡献相等的风险预算组合

表达：\(w_i(\Sigma w)_i/\sigma_p=\sigma_p/n\)

用途：管理事前风险集中。易混点：逆波动权重只在特定结构下等于ERC；不等于等权。

<a id="g175"></a>

## 布莱克—利特曼模型（Black–Litterman）

将反向优化先验与有误差的收益观点更新

表达：\(\pi=\delta\Sigma w_m\)

用途：明确观点不确定性。易混点：超额收益、均值误差协方差、下一期预测协方差不同。

<a id="g176"></a>

## 凯利准则（Kelly Criterion）

在合法收益域内最大化期望对数财富增长

表达：\(\max E\ln(1+r_p)\)

用途：分析增长与杠杆风险。易混点：\(\Sigma^{-1}m\) 是附条件二次代理，非任意离散收益的精确解。

<a id="g177"></a>

## 行业中性（Sector Neutrality）

每个完整互斥行业的有符号资金权重之和为零，不是绝对值之和

表达：\(Zw=0\)

用途：剔除行业净方向。易混点：完整行业中性蕴含金额中性，不蕴含beta中性；基准相对中性另定义。

<a id="g178"></a>

## 金额中性（Dollar Neutrality）

多空金额净和为零

表达：\(1^\top w=0\)

用途：管理净方向。易混点：不等于beta中性或零风险。

<a id="g179"></a>

## 再平衡前漂移权重（Pre-trade Drifted Weights）

上期目标持仓随实现收益变化后的权重

表达：\(\widetilde w_i=w_i(1+r_i)/(1+w^\top r)\)

用途：计算买卖合计换手。易混点：不应直接用上期目标权重；扣费自融资需进一步求解。

<a id="g180"></a>

## 研究链（Research Chain）

从假设、数据、信号、组合、成本到样本外评价的可追溯研究步骤

表达：输入→处理→输出→留痕

用途：第22章按环节冻结决策并记录尝试。易混点：流程图本身不是外部预注册，也不证明先后。

<a id="g181"></a>

## 冻结研究计划（Frozen Research Plan）

在查看留出结果前固定假设、样本、定义、指标、判据与变体预算的计划版本

表达：规范化计划的哈希标识本地字节

用途：第22章冻结研究计划，再只评价留出期。易混点：本地哈希不等于独立时间戳或预注册。

<a id="g182"></a>

## 试验账本（Trial Ledger）

记录每次看过结果的规格、指标、样本量与状态的只增记录

表达：\(N_{\mathrm{trials}}\) 为已评价尝试数

用途：第22章和第32章估计搜索规模并披露失败与未定义尝试。易混点：不等于唯一参数数；重复运行也可能是一项已看结果的试验。

<a id="g183"></a>

## 留出期（Holdout Period）

预先保留、只用于最终评价的一段时间样本

表达：发现期结束 \(<\) 留出期开始

用途：仅在模型、阈值与流程冻结后评价一次。易混点：不是随机交叉验证折，也不能因结果不理想而回流调参。

<a id="g184"></a>

## 分叉路径（Forking Paths）

研究者根据已经看到的数据在多种分析选择间作决定，增加未记录的隐性比较

表达：多种可选分析路径

用途：第22章说明即使无故意 p-hacking 也会产生选择空间。易混点：不要求有恶意；不同于单次预先规定的稳健性分析。

<a id="g185"></a>

## 同日截面（Same-date Cross-section）

固定日期 \(t\)，对当时有效资产 \(i\) 的信号与标签作横向比较

表达：\(\{(s_{i,t},y_{i,t})\}_{i=1}^{N_t}\)

用途：第23章逐日计算 IC、名次与分位桶。易混点：不同于把所有日期混在一起的 pooled correlation。

<a id="g186"></a>

## IC 衰减（IC Decay）

固定信号形成时点，观察其与不同未来期限收益的相关如何变化

表达：\(\mathrm{IC}(k)=\mathrm{Corr}_i(s_{i,t},R_{i,t+k})\)

用途：第23章比较信号对不同预测期限的持续性。易混点：不等于策略 Sharpe 衰减，也不自动等于信号自相关。

<a id="g187"></a>

## 分位桶（Quantile Bucket）

按截面信号名次把资产划分为 \(q\) 组

表达：\(g_i=\lfloor q(r_i-\tfrac12)/n\rfloor+1\)

用途：第23章比较各桶未来收益与多空差。易混点：不是单个分位数统计量；并列可能造成桶大小不等或空桶。

<a id="g188"></a>

## Fama–MacBeth 回归（Fama–MacBeth Regression）

每期先做横截面回归，再对各期系数时间序列取均值与标准误的两步法

表达：\(y_{i,t}=a_t+b_t x_{i,t}+e_{i,t}\)，再汇总 \(b_t\)

用途：第23章估计信号与未来收益的平均截面关系。易混点：不等于把面板合并做一次 OLS；标准误依赖跨期假设。

<a id="g189"></a>

## 重叠持有（Overlapping Holdings）

同时持有多个不同形成月份产生的策略批次

表达：每月更新 \(1/K\) 的 \(K\) 个持有批次

用途：第23、25章平滑持有路径并说明换手口径。易混点：不意味着批次收益独立，也不消除标签重叠。

<a id="g190"></a>

## 账面市值比（Book-to-Market Ratio (B/M)）

最近可得普通股账面权益相对同一信号时点市值的比率

表达：\(B_{i,t}/M_{i,t}\)

用途：第24章作为价值收益率信号，正值越高表示账面权益相对价格越便宜。易混点：不是市净率 M/B；非正账面权益需有明确入样规则。

<a id="g191"></a>

## 盈利收益率（Earnings Yield (E/P)）

归属普通股的盈利相对市值的比率

表达：\(E_{i,t}/M_{i,t}\)

用途：第24章按收益率方向排序，说明负盈利处理。易混点：与 P/E 倍数方向相反；负 E/P 不代表最便宜。

<a id="g192"></a>

## 企业价值（Enterprise Value (EV)）

将股权价值与债务等非普通股索取权合并并扣除现金后的企业层面价值

表达：市值 + 债务 + 优先股 + 少数股东权益 − 现金 − 非经营资产（具体桥接项需声明）

用途：第24章匹配企业口径 FCFF 与 EV/EBITDA。易混点：不等于股权市值；银行保险的 EV/EBITDA 不适用。

<a id="g193"></a>

## 企业价值倍数（EV/EBITDA）

企业价值相对于息税折旧摊销前利润的倍数

表达：\(EV/EBITDA\)

用途：第24章以较低正倍数表示相对便宜。易混点：不是收益率；非正 EBITDA 下不应机械排序。

<a id="g194"></a>

## 价值陷阱（Value Trap）

估值比率看似便宜，但便宜来自基本面恶化，预期回报并不因此较高

表达：高 \(B/M\) 与低质量可能并存

用途：第24、26章检查最便宜组中的盈利、杠杆与现金流质量。易混点：不是一个独立比率，也不等于短期价格下跌本身。

<a id="g195"></a>

## 同版本规则（Same-version Rule）

一个财务比率的分子、分母来自同一报告期间和同一申报版本

表达：重述可得前用原版；可得后整组切换

用途：第24、26章防止混用不同提交版本的账面数据。易混点：不同于只把每列各自取最新值。

<a id="g196"></a>

## 横截面动量（Cross-sectional Momentum）

按资产相对形成期收益排序，买入赢家并卖出输家

表达：信号月末 \(s\)、持有月 \(s+1\)：\(\prod_{j=s-11}^{s-1}(1+R_j)-1\)，跳过月 \(s\)

用途：第25章比较行业组合相对强弱。易混点：不依赖市场方向；不同于时间序列动量。

<a id="g197"></a>

## 时间序列动量（Time-series Momentum (TSMOM)）

按单个资产自身过去收益的方向建立多空头寸，常按事前波动缩放

表达：\(\operatorname{sign}(R_{t-12,t})\,R_{t,t+1}/\sigma_t\)（缩放常数需说明）

用途：第25章按自身趋势方向对每项期货或行业序列建仓。易混点：不同于同日资产之间排序的横截面动量。

<a id="g198"></a>

## 动量崩溃（Momentum Crash）

赢家减输家组合集中出现极端负收益，历史上常见于熊市后急速反弹状态

表达：以最差月份、偏度及市场状态描述

用途：第25章用条件状态说明尾部风险。易混点：不等于任意一次负收益，也不代表本章行业组合复现原论文个股结果。

<a id="g199"></a>

## 连续期货合约（Continuous Futures Contract）

将不同到期月份的期货价格按规则首尾拼接成的分析序列

表达：换月规则决定拼接点

用途：第25、27章用于显示远期合约价格路径。易混点：拼接价差不是持有单一合约的已实现收益。

<a id="g200"></a>

## 期货展期（Futures Roll）

到期前卖出近月合约并买入较远到期合约的交易

表达：在换月日记录两腿成交与持仓

用途：第25、27章区分可交易收益和拼接收益。易混点：不等于连续合约价格调整，也不等于展期收益。

<a id="g201"></a>

## 杜邦分解（DuPont Decomposition）

把股东权益回报率分解为净利率、资产周转与权益乘数

表达：\(N/E=(N/S)(S/A)(A/E)\)

用途：第26章分离盈利能力、经营效率与杠杆。易混点：会计恒等式不说明哪一项造成未来收益。

<a id="g202"></a>

## 毛利润对资产（Gross Profitability (GP/A)）

本章教学口径为收入减销售成本后除以平均资产；与论文特定资产时点口径须区分

表达：\((S-C)/\bar A\)

用途：第26章衡量不扣利息的经营毛利能力。易混点：不同于 GP/Equity 或 OP；金融机构没有可比销售成本。

<a id="g203"></a>

## 营业盈利能力（Operating Profitability (OP)）

收入扣销售成本、销售管理费用及利息费用后除以正账面权益的特定口径

表达：\((S-C-G-I)/E\)

用途：第26章依 Fama–French 2015 表8记录的口径计算。易混点：口径因研究而异；不可无说明地当成通用会计行。

<a id="g204"></a>

## 应计项目比率（Accrual Ratio）

净利润减经营现金流后按平均资产缩放的差额

表达：\((N-F)/\bar A\)

用途：第26章衡量盈利与经营现金流的差异。易混点：不是差额占净利润的比例；负利润时后者更不稳定。

<a id="g205"></a>

## 盈利稳定性（Earnings Stability）

最近若干财年 ROA 或 ROE 的样本标准差

表达：\(s(ROA_{t-n+1:t})\) 或 \(s(ROE_{t-n+1:t})\)

用途：第26章以五年窗口为例，年限不足则缺失。易混点：小标准差不保证高盈利或未来稳定。

<a id="g206"></a>

## 套息或持有收益成分（Carry）

市场条件不变时头寸的可事前计算收益成分；期货口径依合约与抵押资本定义

表达：\(C_t=(S_t-F_t)/X_t\)

用途：第27章分解期货、外汇、债券与商品持有收益。易混点：不等于总预期收益、已实现收益或无风险利差。

<a id="g207"></a>

## 远期升贴水（Forward Premium）

远期价格相对现货价格的比例差

表达：\(F/S-1\)，报价方向须说明

用途：第27章与货币 carry 一并核对。易混点：符号随报价方向变化；不等于远期合约收益。

<a id="g208"></a>

## 抛补利率平价（Covered Interest Parity (CIP)）

在匹配期限、利率与报价约定下，远期汇率由两种货币利率关系确定

表达：本币/外币报价下 \(F=S(1+r)/(1+r^*)\)

用途：第27章推导货币远期 carry 的无套利基准。易混点：不等于未抛补利率平价 UIP，也不表示实际融资可按基准利率完成。

<a id="g209"></a>

## 期货升水（Contango）

远月期货价格高于近月，期货曲线向上倾斜

表达：\(F_{\mathrm{far}}>F_{\mathrm{near}}\)

用途：第27章说明曲线不变时滚动持仓可能有负 carry。易混点：不意味着现货未来必跌。

<a id="g210"></a>

## 现货升水（Backwardation）

近月期货价格高于远月，期货曲线向下倾斜

表达：\(F_{\mathrm{near}}>F_{\mathrm{far}}\)

用途：第27章说明曲线不变时滚动持仓可能有正 carry。易混点：不意味着现货未来必涨。

<a id="g211"></a>

## 便利收益（Convenience Yield）

持有实物商品带来的非现金便利价值；第27章局部净项另扣仓储成本

表达：期货持有成本式中的 \(\delta\)

用途：第27章解释商品现货与期货价格关系。易混点：不是确定的现金票息，也不应与融资收益混为一项。

<a id="g212"></a>

## 滑降收益（Roll-down）

固定收益曲线不变时，债券剩余期限变短并沿曲线移动产生的价格变化

表达：对应收益率曲线斜率与久期近似

用途：第27章拆分零息债收益。易混点：不同于商品期货展期，也不等于单纯票息 carry。

<a id="g213"></a>

## 展期收益（Roll Yield）

曲线不变假设下，持仓随合约到期而沿期货曲线移动所体现的收益

表达：取决于近远月价差与换月规则

用途：第27章将其与现货价格变化分开报告。易混点：不等于拼接连续价格的换月跳跃。

<a id="g214"></a>

## 低波动（Low Volatility）

按事前估计的波动率排序并持有低波动资产的策略特征

表达：\(\sigma_i\) 或 \(\sigma_i^2\) 的事前排序

用途：第27章比较其与低 beta 的暴露差异。易混点：低波动不必然是低 beta。

<a id="g215"></a>

## 低 beta（Low Beta）

按事前市场 beta 排序并持有低 beta 资产的策略特征

表达：\(\beta_i=\mathrm{Cov}(r_i,r_m)/\mathrm{Var}(r_m)\)

用途：第27章构造低 beta 腿并讨论杠杆。易混点：低 beta 不保证低特质波动或低总风险。

<a id="g216"></a>

## 防御型（Defensive）

在市场下跌期相对少跌的资产或组合的操作性描述

表达：可报告下跌期条件收益与条件 beta

用途：第27章用条件表现描述，而非标准资产类别。易混点：不自动等于低波动、低 beta 或高质量。

<a id="g217"></a>

## 买入低 beta、卖出高 beta（Betting Against Beta (BAB)）

将低 beta 腿杠杆化至 beta 约为1，并将高 beta 腿去杠杆后做空的自融资组合

表达：\(r^{BAB}=r_L/\hat\beta_L-r_H/\hat\beta_H\)；rL/rH为同期间超额收益，估计腿beta须正，融资按27章

用途：第27章分别报告两腿 beta、杠杆、融资与估计误差。易混点：不保证真实市场 beta 为零；收缩估计会改变真实暴露。

<a id="g218"></a>

## Vasicek 收缩估计（Vasicek Shrinkage）

把噪声较大的个体估计向横截面先验均值收缩

表达：\(\tilde\beta_i=w\hat\beta_i+(1-w)\beta_{\mathrm{prior}}\)

用途：第27章把估计 beta 向横截面均值缩小。易混点：权重公式依模型假设；收缩后 beta 不是已知真实 beta。

<a id="g219"></a>

## 融资约束与融资风险（Funding Constraint and Funding Risk）

借款、保证金和融资利差限制杠杆头寸；约束收紧可能迫使去杠杆

表达：额度、保证金与融资成本需分列

用途：第27章在 BAB 解释中报告融资假设及敏感度。易混点：不是一般波动率，也不是所有策略收益变化的已证机制。

<a id="g220"></a>

## 缩尾（Winsorization）

将截面极端值替换为预定分位点上的边界值

表达：\(x_i'=\min(q^+,\max(q^-,x_i))\)

用途：第28章每个日期单独估计上下分位点。易混点：不删除观测；全样本估计分位点会泄漏未来分布。

<a id="g221"></a>

## z 分数（Z-score）

将数值减去指定样本均值后除以标准差

表达：\(z_i=(x_i-\bar x)/s_x\)

用途：第28章在同日截面标准化信号。易混点：结果依赖拟合样本和标准差约定，不是正态概率。

<a id="g222"></a>

## 正态分数（Normal Scores）

把名次映射到标准正态分位数以保留顺序并改变尺度

表达：\(\Phi^{-1}((r-\tfrac12)/n)\)

用途：第28章降低极端数值幅度对组合的影响。易混点：不是对原始数据正态性检验或拟合正态分布。

<a id="g223"></a>

## 信号中性化（Signal Neutralization）

将信号中可由指定行业或规模暴露解释的部分回归剔除

表达：\(s=Xb+\epsilon\)，以残差 \(\epsilon\) 为中性化信号

用途：第28章按同日行业与规模做信号中性化。易混点：不等于约束最终持仓，也可能删除真实有收益的暴露。

<a id="g224"></a>

## 正交化（Orthogonalization）

以回归残差构造与先前信号样本内不相关的后续信号

表达：\(z_2^\perp=z_2-\hat b z_1\)

用途：第28章比较两种因子顺序及组合 IC。易混点：顺序会改变残差与合成结果；不代表经济独立。

<a id="g225"></a>

## 合成信号（Composite Signal）

按预先规定的权重合并多个已对齐并已处理的信号

表达：\(s_{\mathrm{comp}}=Z w\)

用途：第28章比较等权合成、正交化与优化权重。易混点：训练或评价期挑权重会引入选择偏差。

<a id="g226"></a>

## 缺失因子（Missing Factor）

合成时某个资产或日期缺少一个或多个因子值的状态

表达：补零与对可用因子重归一化是不同规则

用途：第28章报告覆盖率并比较缺失处理对尺度的影响。易混点：缺失不等于真实因子值为零。

<a id="g227"></a>

## 全样本拟合标准化（Full-sample Fit Standardization）

在训练与评价期合并数据上估计标准化参数后再评价

表达：\(\bar x_{\mathrm{all}},s_{\mathrm{all}}\) 使用所有日期

用途：第28章将其作为前视反例；只在训练窗拟合。易混点：对每个日期做当日截面标准化不等于全时间样本拟合。

<a id="g228"></a>

## 因子相关（Factor Correlation）

两个因子收益序列在指定频率和窗口上的相关程度

表达：\(R_{ij}=\mathrm{Corr}(f_i,f_j)\)

用途：第28章检查相关是否跨时期变化。易混点：不等于因子信号相关，也不保证未来分散化。

<a id="g229"></a>

## 拥挤（Crowding）

多个投资者在相近资产或方向持有重叠头寸，使退出与冲击风险上升的状态

表达：需持仓重叠、卖空或资金流等证据

用途：第28章只把重叠持仓作为侧面，不据此断言拥挤。易混点：信号重叠比例不是实际投资者共同持仓的证明。

<a id="g230"></a>

## 协整筛选（Cointegration Screening）

在候选配对中用训练期协整检验筛选可能存在平稳线性组合的资产对

表达：\(y_t-\hat\beta x_t\sim I(0)\) 的检验流程

用途：第22章将多次配对检验纳入试验账本。易混点：筛选显著不证明交易盈利或未来稳定；需校正选择与结构变化。

<a id="g231"></a>

## 对冲比率（Hedge Ratio）

使一项头寸抵消另一项特定风险的数量或价值比例

表达：配对例常写 \(y_t-\beta x_t\)

用途：配对研究按训练窗估计并在样本外应用。易混点：与 Dynamic Hedge Ratio 的时变估计不同；不自动是美元中性。

<a id="g232"></a>

## 选择效应（Selection Effect）

按某一结果或特征筛选资产后，样本构成与总体不同所产生的描述性差异

表达：\(\mathbb{E}[Y\mid S=1]\) 与 \(\mathbb{E}[Y]\) 的差

用途：第28章讨论因子重叠与候选集变化。易混点：不等于因果处理效应；与同样本择优造成的统计偏差有关但不相同。

<a id="g233"></a>

## 自融资账本（Self-financing Ledger）

通过现金、持仓、现金流与费用逐期守恒地记录组合净值的账本

表达：\(NAV_t=C_t^{cash}+\sum_iq_{i,t}P_{i,t}\)

用途：第29章按价格区间、公司行动和交易费用逐笔对账。易混点：对账一致不证明价格数据真实或时间戳没有泄漏。

<a id="g234"></a>

## 漂移后权重（Drifted Weights）

资产价格变化后，在不交易的持有区间内被动变化的组合权重

表达：\(w_{i,t+1}=w_{i,t}(1+r_{i,t+1})/(1+r_{p,t+1})\)

用途：第29章用漂移权重作为下一次调仓的真实起点。易混点：不等于新信号产生的目标权重。

<a id="g235"></a>

## 扣费后净值（Post-fee NAV）

调仓费用支付后用于按目标权重分配资金的净资产值

表达：\(V'=V_{\mathrm{pre}}-c\sum_i\lvert w_i^*V'-x_i\rvert\)

用途：第29章先求 \(V'\)，再计算目标持仓与剩余现金。易混点：不等于调仓前净值；费用可能使调仓不可行。

<a id="g236"></a>

## 选择偏差（Selection Bias）

根据同一批结果挑选模型、资产或参数后，再用该批结果估计表现所产生的偏高或失真的推断

表达：选择后的估计需把搜索过程纳入推断

用途：第30章拆分数据窥探、参数挖掘与样本筛选。易混点：不同于仅报告子群体差异的 Selection Effect。

<a id="g237"></a>

## 参数挖掘（Parameter Mining）

在多个参数组合中用评价结果选出表现最好者

表达：\(j^*=\arg\max_j \widehat{SR}_j\)

用途：第30章只用训练期选参数并保留样本外评价。易混点：参数网格越大，最大值越受搜索影响；不等于单纯拟合一个预定参数。

<a id="g238"></a>

## 交易成本模型错误（Transaction Cost Model Error）

成本口径、费率或成交量与真实执行不符，造成净收益测量偏差

表达：\(R_{\mathrm{net}}=R_{\mathrm{gross}}-\mathrm{fees}-\mathrm{impact}-\cdots\)

用途：第30章展示成本遗漏或错误费率对净值的影响。易混点：回测扣了费用不代表费用估计真实或含全部市场冲击。

<a id="g239"></a>

## 标签区间（Label Interval）

样本特征时点之后、用于构造预测目标的收益区间

表达：\(I_i=(t_i,e_i]\)

用途：第31章按区间交集净化训练样本。易混点：不等于单一观测日，也不应误把端点接触当作重叠。

<a id="g240"></a>

## 标签可得时点（Label Availability Time）

标签真实值完成结算或发布、最早可供训练程序使用的时刻

表达：\(a_i\ge e_i\) 可成立

用途：第31章训练样本须满足 \(a_i\le t_{\mathrm{predict}}\)。易混点：不等于标签测量终点 \(e_i\)；存在发布延迟时不能替代。

<a id="g241"></a>

## 净化前推验证（Purged Walk-forward Validation）

训练集只用过去样本，测试集取紧随其后的未来区间，并剔除标签窗口与测试区间重叠的训练样本

表达：train dates \(<\) test dates；按 \(I_i\cap I_j\) 净化

用途：第31章模拟部署时序并控制重叠标签。易混点：不等于随机 K-Fold，也不保证模型参数稳定。

<a id="g242"></a>

## 净化 K 折交叉验证（Purged K-Fold）

时间轴划分为连续块，每折用一块测试、其余块训练，再按标签区间净化

表达：\(S_{\mathrm{train}}\leftarrow\{i:I_i\cap I_j=\emptyset\ \forall j\in S_{\mathrm{test}}\}\)

用途：第31章在允许双向训练数据的估计任务中使用。易混点：含未来训练块，不等于严格因果前推验证。

<a id="g243"></a>

## 嵌套验证（Nested Validation）

外层估计样本外表现，内层只在外层训练集里选超参数与特征

表达：外层 test 不参与内层选择

用途：第31章避免把调参结果当成独立评价。易混点：不是简单重复交叉验证；所有预处理也要嵌入训练折。

<a id="g244"></a>

## 时间序列划分间隙（TimeSeriesSplit Gap）

训练末端与测试起点之间跳过的离散样本行数

表达：\(g=\) skipped rows

用途：第31章比较固定 gap 与标签区间 purge。易混点：不是自然日天数；多资产按日期成块时行数 gap 可能失效。

<a id="g245"></a>

## 复合年化增长率（Compound Annual Growth Rate (CAGR)）

将起点至终点财富的复合增长折算为年率

表达：\((W_T/W_0)^{1/Y}-1\)

用途：第32章与简单收益均值分开报告长期增长。易混点：不等于平均单期收益乘频率。

<a id="g246"></a>

## 最大回撤（Maximum Drawdown (MaxDD)）

财富路径相对历史峰值的最大下降幅度，按正损失幅度报告

表达：\(\max_t\lvert W_t/\max_{s\le t}W_s-1\rvert\)

用途：第32、33章描述路径损失。易混点：不描述回撤发生概率或恢复时间。

<a id="g247"></a>

## 卡尔马比率（Calmar Ratio）

CAGR 相对最大回撤的比率

表达：\(\mathrm{CAGR}/\mathrm{MaxDD}\)

用途：第32章作为增长与路径损失的描述指标。易混点：分母为零时未定义；不是通用风险调整推断。

<a id="g248"></a>

## 下行偏差（Downside Deviation）

相对指定最低收益门槛的下方偏差均方根

表达：\(\sqrt{n^{-1}\sum_t\min(r_t-\tau,0)^2}\)

用途：第32章计算 Sortino 比率。易混点：与标准差不同；计算口径依赖目标门槛和分母约定。

<a id="g249"></a>

## 索提诺比率（Sortino Ratio）

超过目标门槛的平均收益相对下行偏差

表达：\((\bar r-\tau)/DD_\tau\)

用途：第32章与 Sharpe 对比收益下行风险。易混点：年化需要约定；忽略上行波动不代表无回撤风险。

<a id="g250"></a>

## 胜率（Hit Rate）

正收益观察占非平盘观察的比例，分母口径需声明

表达：\(\#(r_t>0)/\#(r_t\ne0)\)

用途：第32章作为描述性指标。易混点：不等于盈亏比、期望收益或胜率检验；与 IC 命中率不同。

<a id="g251"></a>

## 盈亏比（Profit Factor）

总正收益绝对额与总负收益绝对额之比

表达：\(\sum_{r_t>0}r_t/\lvert\sum_{r_t<0}r_t\rvert\)

用途：第32章补充报告收益分布特征。易混点：不含交易成本口径需说明；没有亏损时未定义。

<a id="g252"></a>

## 回测过拟合概率（Probability of Backtest Overfitting (PBO)）

CSCV划分中样本内赢家的样本外秩满足r≤(N+1)/2的比例；strict另用r<N/2

表达：\(\Pr(\lambda\le0)\) 的划分频率

用途：第32章用选择后的测试排名诊断策略选择脆弱性。易混点：两个阈值不同，不仅是同阈值<与≤；不是未来亏损或失效概率。

<a id="g253"></a>

## 组合对称交叉验证（Combinatorially Symmetric Cross-Validation (CSCV)）

把同步收益矩阵分成偶数时间块，穷举一半为训练、互补一半为测试的划分

表达：\(\binom{S}{S/2}\) 组切分

用途：第32章计算 PBO 所需的相对排名分布。易混点：不自动保持因果顺序，也不提供普适最佳块数。

<a id="g254"></a>

## 概率夏普比率（Probabilistic Sharpe Ratio (PSR)）

给定样本与矩条件下、以原频率Sharpe和阈值构造的频率学派正态近似检验量

表达：\(\Phi((\hat{SR}-SR^*)\sqrt{n-1}/\sqrt{1-\hat\gamma_3\hat{SR}+(\hat\gamma_4-1)\hat{SR}^2/4})\)

用途：第32章阈值与样本收益采用相同原生频率。易混点：不是贝叶斯后验，也不是未来赚钱概率；序列相关会破坏默认假设。

<a id="g255"></a>

## 紧缩夏普比率（Deflated Sharpe Ratio (DSR)）

将 PSR 的基准 Sharpe 提高到考虑试验选择偏差与非正态矩的阈值后计算

表达：\(\mathrm{DSR}=\mathrm{PSR}(SR_0)\)

用途：第32章以试验账本与候选相关度解释门槛。易混点：不是把 Sharpe 点估计任意缩小；有效试验数估计存在模型限制。

<a id="g256"></a>

## 有效独立试验数（Effective Independent Trials）

将相关候选策略折算成搜索膨胀估计中的独立试验规模

表达：DSR 文稿启发式：\(\hat N=\hat\rho+(1-\hat\rho)M\)

用途：第32章避免把候选列数直接当独立次数。易混点：是特定近似而非精确等价或普适自由度。

<a id="g257"></a>

## Pearson 原始峰度（Pearson Raw Kurtosis）

标准化四阶中心矩；正态分布值为 3

表达：\(\gamma_4=\mathbb E[(R-\mu)^4]/\sigma^4\)

用途：第32章 PSR 用 Fisher=False 的原始峰度。易混点：超额峰度等于原始峰度减3，正态基准为0。

<a id="g258"></a>

## 风险价值（Value at Risk (VaR)）

给定置信水平下损失分布的下侧分位数

表达：\(\operatorname{VaR}_\alpha(L)=\inf\{\ell:F_L(\ell)\ge\alpha\}\)

用途：第33章同时注明账户单位、置信水平与持有期限。易混点：不描述超过阈值后的损失严重度，也不是最大损失。

<a id="g259"></a>

## 置信水平（Confidence Level）

VaR/ES 所用损失分布分位位置 \(\alpha\)

表达：\(\alpha\in(0,1)\)，右尾概率为 \(1-\alpha\)

用途：第33章先定置信水平再计算风险量。易混点：此处 \(\alpha\) 不是回归截距或显著性水平。

<a id="g260"></a>

## 持有期限（Holding Horizon）

从损失起点到风险评价终点的时间区间长度

表达：\(h\)，\(L_{t,h}=-(V_{t+h}-V_t)\)

用途：第33章按组合实际重估间隔选风险窗口。易混点：不等于 VaR 回测滚动步长或清算所需天数。

<a id="g261"></a>

## 分数尾部质量（Fractional Tail Mass）

离散分布下，VaR 阈值处只取补足尾部概率所需的部分概率质量

表达：补入概率质量 \(F_L(v)-\alpha\)；ES贡献为 \(v[F_L(v)-\alpha]/(1-\alpha)\)

用途：第33章避免把整块阈值原子都塞进尾部均值。易混点：不同于严格超过阈值或包含全部等于阈值的条件均值。

<a id="g262"></a>

## VaR 超越（VaR Exceedance）

实现损失超过事前 VaR 阈值的一次观察

表达：\(\mathbf1\{L_t>\operatorname{VaR}_{\alpha,t}\}\)

用途：第33章用未参与估计的窗口统计超越。易混点：离散阈值有原子时，超越概率未必恰为 \(1-\alpha\)。

<a id="g263"></a>

## Kupiec 无条件覆盖检验（Kupiec Unconditional Coverage Test）

用二项失败计数检验 VaR 超越频率是否符合目标率的似然比检验

表达：比较 \(H_0:p=1-\alpha\) 与样本超越率

用途：第33章说明测试窗中超越次数与检验能力。易混点：不检验超越是否聚集，也不拒绝不等于模型准确。

<a id="g264"></a>

## 压力情景重估（Stress Scenario Revaluation）

对当前实际持仓施加明示价格、波动或流动性冲击并重新估值

表达：\(V^{stress}=\operatorname{revalue}(q,P^{stress},cashflows)\)

用途：第33章把风险结果传回下一期可执行目标权重。易混点：构造情景不是历史 VaR，也不是预测事件概率。

<a id="g265"></a>

## 清算期限（Liquidation Horizon）

在给定成交量参与率与流动性假设下平掉头寸所需的时间

表达：可按持仓名义额、ADV 与参与率估计

用途：第33章把清算天数与市场冲击分列。易混点：不等于统计风险持有期限 \(h\)，也不保证期间可按均价成交。

<a id="g266"></a>

## 赫芬达尔集中度指数（Herfindahl–Hirschman Index (HHI)）

归一化风险资产权重平方和，用于描述权重集中

表达：\(\sum_i \tilde w_i^2\)，\(\tilde w_i=\lvert w_i\rvert/\sum_j\lvert w_j\rvert\)

用途：第33章补充组合集中度指标。易混点：不包含相关性或尾部共振信息。

<a id="g267"></a>

## 方向准确率（Directional Accuracy (Hit Rate)）

有仓位且收益非零的日子里预测方向正确的比例

表达：\(\frac1{T'}\sum_t c_t\)

用途：第37章与幅度加权准确率、净收益并列报告。易混点：对每天等权，不等于盈亏。

<a id="g268"></a>

## 幅度加权准确率（Magnitude-weighted Accuracy）

按 \(\lvert r_t\rvert\) 加权的方向正确比例

表达：\(\sum\lvert r_t\rvert c_t/\sum\lvert r_t\rvert\)

用途：\(\pm1\) 仓位下 \(\sum p_tr_t=(\sum\lvert r_t\rvert)(2\mathrm{Acc}_{\lvert r\rvert}-1)\)。易混点：仓位大小可变时恒等式不成立。

<a id="g269"></a>

## 样本外决定系数（Out-of-Sample \(R^2\)）

测试期相对基准预测的平方误差改进

表达：\(1-\sum(y-\hat y)^2/\sum(y-\bar y^{base})^2\)

用途：第37–39章同时报告相对零与相对训练均值。易混点：基准不同数值不同；个股文献常用零基准。

<a id="g270"></a>

## 数据泄漏（Data Leakage）

训练或选择模型时用到预测时点不可得的信息

表达：目标/前视/预处理/选择/重叠五类

用途：第37章分类，第38章给数值反例。易混点：不只是“用了未来价格”。

<a id="g271"></a>

## 有效样本量（重叠标签）（Effective Sample Size (overlapping labels)）

相关样本所含的等价独立信息量

表达：独立日收益下 \(h\) 日重叠标签约 \(n/h\)

用途：第37章修正 \(t\) 值。易混点：不等于观测行数。

<a id="g272"></a>

## 状态切换（Regime Shift）

预测关系在未知时点改变

表达：\(b_t=b^{(1)}\to b^{(2)}\)

用途：第37章：斜率反号使 \(R^2_{OS}<0\)。易混点：样本内 \(R^2\) 不会提示。

<a id="g273"></a>

## 拟合时点（Fit Time）

外层折拟合模型、形成首个测试预测的收盘

表达：\(D_s\)

用途：训练行须 label\_available\_at \(\le D_s\)。易混点：不是训练末日或测试成交日。

<a id="g274"></a>

## 按日期分组前推验证（Date-grouped Walk-forward）

以唯一日期为单位划分，同日全部资产同侧，训练行按标签可用时点过滤

表达：排除 \(\ell+h-1\) 个信号日（无缺失时）

用途：`quant_course.ml_pipeline.date_walk_forward`。易混点：行数 gap 的 TimeSeriesSplit 不等价。

<a id="g275"></a>

## 截面变换（Cross-sectional Transform）

只用同一信号日数据计算的特征变换

表达：当日排名、当日 z-score

用途：第38章：无需训练拟合。易混点：跨日期估计参数的变换必须训练内拟合。

<a id="g276"></a>

## 校准斜率（Calibration Slope）

实现值对预测值回归的斜率

表达：\(\operatorname{Cov}(y,\hat y)/\operatorname{Var}(\hat y)\)

用途：第38章分池化与截面两种。易混点：只在内层验证集估计。

<a id="g277"></a>

## 岭回归（Ridge Regression）

残差平方和加 L2 惩罚

表达：scikit-learn：\(\lVert y-Xw\rVert^2+\alpha\lVert w\rVert^2\)

用途：第39章：正交时收缩 \(n/(n+\alpha)\)。易混点：\(\alpha\) 与 Lasso 的 \(\alpha\) 尺度不同。

<a id="g278"></a>

## 套索回归（Lasso）

平均残差平方加 L1 惩罚

表达：scikit-learn：\(\tfrac1{2n}\lVert y-Xw\rVert^2+\alpha\lVert w\rVert_1\)

用途：第39章：正交时软阈值。易混点：零系数不等于特征无用。

<a id="g279"></a>

## 弹性网（Elastic Net）

L1 与 L2 惩罚的组合

表达：\(\tfrac1{2n}\lVert\cdot\rVert^2+\alpha\rho\lVert w\rVert_1+\tfrac{\alpha(1-\rho)}2\lVert w\rVert^2\)

用途：第39章：正交解 \(S(z,\alpha\rho)/(1+\alpha(1-\rho))\)。易混点：`l1_ratio` 即 \(\rho\)。

<a id="g280"></a>

## 正则化路径（Regularization Path）

系数随正则强度变化的曲线

表达：\(\hat w(\alpha)\)，\(\alpha\) 由大到小

用途：第39章图39-1。易混点：路径不是调参结果。

<a id="g281"></a>

## 方差膨胀因子（Variance Inflation Factor (VIF)）

共线性使 OLS 系数方差相对正交情形放大的倍数

表达：两特征相关 \(r\) 时 \(1/(1-r^2)\)

用途：第39章共线性。易混点：不衡量偏差。

<a id="g282"></a>

## 回归树（Regression Tree (CART)）

逐层按“特征≤阈值”切分、叶内预测平均值的分段常数模型

表达：增益 \(\frac{n_Ln_R}{n}(\bar y_L-\bar y_R)^2\)

用途：第40章：在日期 walk-forward 折内拟合回归树，作为非线性模型与零预测、训练均值和正则化线性模型比较。。易混点：与线性回归不同，阈值和交互由分段常数表示；逐层贪心切分不保证全局最优。。

<a id="g283"></a>

## 叶样本数（Min Samples Leaf）

每个叶子至少包含的训练行数

表达：sklearn `min_samples_leaf`

用途：第40章：在训练内日期验证的参数网格中选择叶样本数，以限制面板树叶的复杂度。。易混点：计数单位是股票—日期训练行，不是独立观测；同日横截面相关使行数不能直接解释为独立样本量。。

<a id="g284"></a>

## 随机森林（Random Forest）

自助抽样与随机抽特征的树的平均

表达：方差 \(\rho\sigma^2+\frac{1-\rho}{B}\sigma^2\)

用途：第40章：在外层日期折中平均多棵树；Project 6 v2 在训练内选择 `max_features`、`max_samples` 与叶样本数。。易混点：与只做自助抽样的装袋相比，随机森林还可在每次切分抽取特征以降低树间相关；本章所用sklearn环境默认 `max_features=1.0` 时不做特征子采样。。

<a id="g285"></a>

## 梯度提升（Gradient Boosting）

逐轮用浅树拟合负梯度并按学习率累加

表达：\(F_m=F_{m-1}+\nu h_m\)；平方损失下拟合残差

用途：第40章：用 HGB 在日期 walk-forward 中逐轮拟合；轮数由训练内日期验证选择，再在外层测试折评价。。易混点：与随机森林的树平均不同，提升树按轮次累加；轮数与学习率需在训练内共同选择。。

<a id="g286"></a>

## 学习率（收缩）（Learning Rate (Shrinkage)）

每轮更新乘的系数 \(\nu\)

表达：HGB 叶值 \(\nu\cdot\frac{n_R}{n_R+\lambda}\bar r\)

用途：第40章：在 Project 6 v2 的 HGB 网格中比较学习率，并用内层日期验证选择参数与轮数。。易混点：学习率缩小每轮步长；较小步长通常需要更多轮，不能脱离轮数单独解释。。

<a id="g287"></a>

## 早停（Early Stopping）

验证误差不再下降时停止增加轮数

表达：内层日期折上 `staged_predict` 选轮

用途：第40章：关闭 HGB 内置早停，用训练内日期折的 `staged_predict` 选择 `max_iter`。。易混点：sklearn 内置随机行留出不等于日期验证；面板中同日行和重叠标签可能跨到训练侧。。

<a id="g288"></a>

## 不纯度重要性（Mean Decrease in Impurity (MDI)）

使用该特征的切分带来的加权 SSE 减少之和（归一化）

表达：`feature_importances_`

用途：第40章：把 MDI 作为拟合模型后的训练期诊断，与内层日期置换重要性并列查看。。易混点：不是样本外预测重要性；训练不纯度重要性偏向可切分点较多的连续特征，不用外层测试信息筛特征。。

<a id="g289"></a>

## 按日期置换重要性（Permutation Importance (by date)）

在未参与拟合的验证集上，同日内打乱某特征后的损失增加

表达：\(I_j=\overline{\mathrm{MSE}(X^{(\pi,j)})}-\mathrm{MSE}(X)\)

用途：第40章：在最后一个内层日期验证折内按日期置换特征，计算 MSE 增量；训练内可据此做前10特征消融。。易混点：相关特征可以互相替代，单列重要性可能很低；外层测试置换仅作事后诊断。。

<a id="g290"></a>

## Shapley 值（SHAP / Shapley Value）

按合作博弈把 \(f(x)-Ef\) 分给各特征

表达：\(\phi_j=\sum_S\frac{\lvert S\rvert!(p-\lvert S\rvert-1)!}{p!}[v(S\cup j)-v(S)]\)

用途：第40章：用 Shapley 分配模型预测相对背景值的特征贡献，并检查交互项的分摊。。易混点：解释模型输出不等于识别因果机制；条件式与干预式价值函数可能给出不同解释。。

<a id="g291"></a>

## 消融（Ablation）

预先登记的去掉某组件的对照运行

表达：Project 6 v2 无价格特征/仅价格/训练内前10

用途：第40章：按已登记特征组变体重跑同一日期折与成本账本，比较该组件对预测和组合指标的贡献。。易混点：消融是整组配置的对照运行，不等于单特征置换重要性；比较沿用相同折与评价口径。。

<a id="g292"></a>

## 主成分分析（Principal Component Analysis (PCA)）

依次找方差最大的正交方向

表达：\(\Sigma v=\lambda v\)

用途：第41章：每个训练窗内拟合缩放与 PCA，再投影后续日期；Project 6 v2 另以 PCA+Ridge 作辅助消融。。易混点：PCA 按特征方差排序，不利用未来收益标签；高方差方向不必有预测力。。

<a id="g293"></a>

## 解释方差比例（Explained Variance Ratio）

特征值占特征值总和的份额

表达：\(\lambda_j/\sum\lambda\)

用途：第41章：报告训练窗各主成分的方差份额，作为压缩程度的描述，再单独核对样本外表现。。易混点：是训练特征方差的份额，不是未来收益预测力或样本外重构表现。。

<a id="g294"></a>

## 样本外重构 \(R^2\)（Out-of-sample Reconstruction \(R^2\)）

在训练中心/尺度下，相对零向量基准的测试重构误差改进

表达：\(1-\sum\lVert\tilde x-VV^\top\tilde x\rVert^2/\sum\lVert\tilde x\rVert^2\)

用途：第41章：仅用过去窗口估计缩放参数和 PCA 方向，再在后续21日窗口计算重构 \(R^2\)，检查方向能否迁移。。易混点：不等于标签预测的样本外 \(R^2\)，也不等于训练解释方差；中心化和缩放须沿用训练参数。。

<a id="g295"></a>

## 随机矩阵噪声上界（Marchenko–Pastur Bound）

独立噪声样本相关矩阵特征值的极限区间

表达：\(\sigma^2(1\pm\sqrt{N/T})^2\)

用途：第41章：把样本相关矩阵特征值与噪声区间作参照，并结合后续窗口重构表现检查信号方向。。易混点：依赖独立同分布和大样本条件，是噪声参照线而非通用显著性检验或金融市场硬阈值。。

<a id="g296"></a>

## k 均值聚类（k-means）

最小化簇内平方距离的划分

表达：Lloyd：分配—更新

用途：第41章：在训练窗标准化过去21日波动率和63日收益特征并拟合 \(K=2\)，再把后续日期分配到已拟合中心。。易混点：簇编号不代表经济机制，且初值与缩放会影响局部最优；训练后按波动率中心对齐标签。。

<a id="g297"></a>

## 调整兰德指数（Adjusted Rand Index (ARI)）

两种划分一致性的随机校正度量

表达：完全一致为 1

用途：第41章：对聚类重拟合或自助样本的两组划分计算 ARI，量化所选扰动下的划分敏感性。。易混点：与逐元素标签命中率不同，ARI 不受簇编号互换影响；行自助抽样不能证明重叠日期特征上的时间稳定性。。

<a id="g298"></a>

## 滤波/平滑概率（Filtered / Smoothed Probability）

\(\Pr(s_t\mid x_{1:t})\) / \(\Pr(s_t\mid x_{1:T})\)

表达：前向递推 / 前向—后向

用途：第41章：用训练窗估计参数并逐日更新滤波概率形成在线状态输入；平滑概率仅用于回看历史状态。。易混点：滤波概率只用截至 \(t\) 的观测；平滑概率使用未来观测，不可当作当时可交易信号。。

<a id="g299"></a>

## 事后状态标签（Regime Label (ex post)）

用全样本或未来数据给日期标注的状态

表达：居中窗口、平滑概率

用途：第41章：在第8.4节构造状态策略比较中作泄漏对照，展示事后标签与可得在线信号的差别。。易混点：与在线标签或滤波概率不同，事后标签含未来信息；不能与同日收益配对后当成可交易结果。。

<a id="g300"></a>

## 多层感知机（Multilayer Perceptron）

仿射层与非线性激活的组合，输入为h0=x

表达：\(h_l=\phi_l(W_lh_{l-1}+b_l)\)，各层维度匹配

用途：第42章把训练内特征映射成收益预测，和线性基准比较。易混点：本章小网络是教学；网络复杂度不证明交易优势。

<a id="g301"></a>

## 反向传播（Backpropagation）

沿计算图应用链式法则求标量损失对参数的梯度

表达：\(\nabla_\theta L=J_{z,\theta}^{\top}\nabla_zL\)，J是中间变量z对θ的Jacobian

用途：第42章核对矩阵梯度并更新训练参数。易混点：求梯度不等于选好学习率，也不保证找到全局最优。

<a id="g302"></a>

## 小批次（Mini-batch）

单次梯度更新使用的样本子集B

表达：\(\widehat g_B=\lvert B\rvert^{-1}\sum_{i\in B}\nabla_\theta\ell_i\)，本式为可加样本损失

用途：控制训练计算量；金融数据另按日期决定批次与验证。易混点：一个batch中的多个股票不等于多个独立日期。

<a id="g303"></a>

## 早停（Early Stopping）

以验证误差选择停止轮数并恢复最佳验证检查点

表达：\(e^*=\arg\min_e L_{val}(e)\)；只在预定候选轮数/耐心规则内选

用途：第42章限制过拟合，再用未参与选择的测试集评价。易混点：不是按测试误差停，也不是最佳训练误差保证泛化。

<a id="g304"></a>

## 平移等变性（Translation Equivariance）

输入平移使输出按相同规则平移

表达：\(f(T_\tau x)=T_\tau f(x)\)，Tτ为平移算子

用途：第42章解释序列卷积共享局部检测器的结构。易混点：不等于平移不变；有限边界、valid位置和步长须核。

<a id="g305"></a>

## 循环神经网络（Recurrent Neural Network）

用递推隐藏状态处理顺序输入，ht保留历史表示

表达：\(h_t=\tanh(W_hh_{t-1}+W_xx_t+b)\)

用途：第42章说明历史窗口如何进入序列状态。易混点：双向/未来状态不自动可在线使用，递推不保证长程梯度稳定。

<a id="g306"></a>

## 长短期记忆（Long Short-Term Memory）

门控加法细胞状态缓解长程信息衰减；f/i/o为遗忘/输入/输出门

表达：\(c_t=f_t\odot c_{t-1}+i_t\odot\widetilde c_t\)，\(h_t=o_t\odot\tanh(c_t)\)

用途：第42章把候选记忆、保留比例和输出比例分别解释。易混点：门控不是所有梯度稳定的保证；正文列向量与代码行向量权重须转置匹配。

<a id="g307"></a>

## 缩放点积注意力（Scaled Dot-Product Attention）

用Q/K相似度生成行归一化权重并加权V，dk为key维度

表达：\(A=\operatorname{softmax}_{row}(QK^{\top}/\sqrt{d_k}+M)V\)

用途：第42章手算历史位置之间的信息加权。易混点：权重不自动是因果解释；softmax按行且掩码/形状要匹配。

<a id="g308"></a>

## 因果注意力掩码（Causal Attention Mask）

禁止位置i读取未来位置j>i

表达：\(M_{ij}=0\)若j≤i，j>i取\(-\infty\)

用途：第42章把未来token注意力权重置零，核时间顺序。易混点：只控制注意力访问，不能修复上游PIT、标签或预处理泄漏。

<a id="g309"></a>

## 位置编码（Positional Encoding）

给序列位置增加表示，使相同内容在不同位置可区分

表达：正弦例：\(PE_{p,2i}=\sin(p/10000^{2i/d})\)，对应奇通道用cos，p为位置、d为维度

用途：第42章在token表示中保留时间次序。易混点：位置序号不是日历可得时间，不取代时间戳契约。

<a id="g310"></a>

## 共轭先验（Conjugate Prior）

与指定似然结合后，后验仍属于先验同一分布族

表达：条件独立Bernoulli例：\(Beta(a,b)\to Beta(a+s,b+n-s)\)，a/b>0，n次中s次成功

用途：第43章用可解析后验演示小样本概率更新。易混点：共轭是先验—似然配对性质，不证明金融观测独立或模型正确。

<a id="g311"></a>

## 后验预测分布（Posterior Predictive Distribution）

对参数后验积分得到未来观测的分布，D为已有数据

表达：\(p(\widetilde y\mid D)=\int p(\widetilde y\mid\theta)p(\theta\mid D)d\theta\)

用途：第43章区分未知参数误差和新观测噪声，给未来事件概率。易混点：不是把后验均值代入就得到全部不确定性；未来多期可因共享θ相关。

<a id="g312"></a>

## 部分池化（Partial Pooling）

组内数据与共同先验共同影响组参数；本章正态例超参数已知

表达：\(m_g=w_g\bar y_g+(1-w_g)\mu\)，\(w_g=\tau^2/(\tau^2+s_g^2)\)；τ²为正先验方差，sg²为正均值观测方差

用途：第43章让小样本组向共同均值收缩，区分后验均值/方差。易混点：不等于所有组强行同值；未知超参数须另估计并计不确定性。

<a id="g313"></a>

## 潜在结果（Potential Outcomes）

同一单位在不同干预下可能得到的结果，二值处理T仅显露一个

表达：\(Y=TY(1)+(1-T)Y(0)\)，\(ATE=E[Y(1)-Y(0)]\)

用途：第43章说明平均处理效应的目标和识别假设。易混点：同一单位不能同时观测两个结果；观测组间差不是自动ATE。

<a id="g314"></a>

## 正值性（Positivity）

在目标总体协变量Z各相关层中，两处理都有正概率

表达：\(0<P(T=1\mid Z=z)<1\)

用途：第43章诊断缺少可比较组的分层、限制可识别总体。易混点：不是证券价格必须正；接近0/1还会造成估计不稳定。

<a id="g315"></a>

## 对撞变量（Collider）

两变量共同指向的节点，条件化可能打开原本关闭的路径

表达：\(T\to C\leftarrow Y\)

用途：第43章识别选择样本/控制变量引入的关联。易混点：不等于混杂节点；调整越多不一定越好。

<a id="g316"></a>

## 词频—逆文档频率（TF-IDF）

按训练语料中的文档频率缩放词频

表达：本章sklearn约定：\(idf_j=\log[(1+n)/(1+df_j)]+1\)；n为训练文档数、dfj为含词文档数，随后按设定归一

用途：第43章只在训练窗拟合词表和IDF，再变换未来文本。易混点：不是唯一行业公式；全样本词表/IDF会泄漏未来，权重不自动等于情感。

<a id="g317"></a>

## 词表外词（Out-of-Vocabulary）

当前训练词表未收录的token

表达：无单一公式；稀疏词袋只映射既有词表，未知词不新增列

用途：第43章检查未来文本的词表覆盖与可能信息损失。易混点：稀疏词袋未知词忽略与子词模型分解不同，不能事后扩词再称原模型。

<a id="g318"></a>

## 嵌入（Embedding）

将离散对象映射为固定维度向量

表达：\(e(w)=E_{index(w),:}\)，E为嵌入矩阵

用途：第43章用向量相似度表示文本关系，并记录模型版本。易混点：人工矩阵不是预训练语言模型；相似度不是事实或因果证据。

<a id="g319"></a>

## 幻觉（Hallucination）

模型产生看似可信但错误或无来源支撑的内容

表达：无单一公式；核事实/引用要与可验证原始来源对照

用途：第43章审查LLM辅助摘要、数据抽取与引用。易混点：JSON/schema正确不证明内容真，流畅程度不能替代核读。

<a id="g320"></a>

## 布朗运动（Brownian Motion）

从0出发、连续路径、独立高斯增量，未来增量独立于当前相容滤过

表达：Var(ΔW)=Δt，W单位sqrt(年)

用途：第44章扩散模型。易混点：有限随机游走路径不等于Brownian；路径不可普通求导。

<a id="g321"></a>

## 滤过 / 适应过程（Filtration / Adapted Process）

信息随时刻增长；X_t关于F_t可测

表达：F_s包含于F_t

用途：第44章可用信息。易混点：Itô积分还需合适联合可测与可积条件。

<a id="g322"></a>

## 鞅（Martingale）

适应、可积、E[M_t\|F_s]=M_s

表达：指定测度和信息流

用途：条件定价。易混点：无条件均值常数不足以定义鞅。

<a id="g323"></a>

## 二次变差（Quadratic Variation）

平方增量在所列网格/概率条件下的极限

表达：Brownian [W]_t=t

用途：Itô二阶项。易混点：有限QV不必恰等t，确定性划分前提不可省。

<a id="g324"></a>

## 伊藤积分 / 等距（Itô Integral / Isometry）

可预测或渐进可测平方可积过程的简单过程L2延伸

表达：E[(∫H dW)²]=E∫H²dt

用途：第44章随机收益。易混点：数组形状不证明适应；任意不规则H不自动由逐点采样收敛。

<a id="g325"></a>

## 几何布朗运动（Geometric Brownian Motion）

dS=βSdt+σSdW，显式指数解

表达：P β=μ−q；Q β=r−q

用途：模拟价格与对冲。易混点：Euler可负；本章强RMSE与弱均值差不同。

<a id="g326"></a>

## 吉尔萨诺夫 / 诺维科夫条件（Girsanov / Novikov）

正指数密度重新加权并平移Brownian漂移

表达：λ=(μ−r)/σ，W_Q=W_P+λt

用途：常系数有限时域定价测度。易混点：σ=0转换另处理；未给一般完整证明。

<a id="g327"></a>

## 自融资复制（Self-financing Replication）

股票/现金调整由组合内部资金支付

表达：dV=Δ(dS+qSdt)+r(V−ΔS)dt

用途：第44章无套利PDE。易混点：有费/离散/跳跃不能保证连续完美复制。

<a id="g328"></a>

## 希腊字母敏感度（Greeks）

对股票、期限、波动和利率的局部导数

表达：Vega/Rho按单位参数，Theta按日历年

用途：第44章差分与风险。易混点：到期折点无普通唯一导数；1pp乘.01。

<a id="g329"></a>

## 对偶变量（Antithetic Variates）

用独立z对生成相关z/−z支付，再以配对均值推断

表达：SE=std(pair mean)/sqrt(M)

用途：第44章MC。易混点：不能把2M相关路径当独立；一次区间覆盖非正确性证明。

<a id="g330"></a>

## 费曼–卡茨表示（Feynman–Kac Representation）

在所列解/矩条件下连接PDE与扩散条件期望

表达：V=E_Q[e^(−rτ)h(S_T)\|F_t]

用途：第44章受限GBM。易混点：局部鞅不能自动取均值；不对任意系数/支付保证。

<a id="g331"></a>

## 幂等性（Idempotency）

以稳定的逻辑运行键和输入身份识别同一任务的重试，并依据已持久化成交只补尚未完成的目标。

表达：无单一公式：同 `run_key` 与输入指纹重跑不得增加账本成交；同键异指纹拒绝，既有 `STOPPED` 运行拒绝继续成交。

用途：第45章：重触发同一任务时查 SQLite 运行与成交账本；已完成且产物哈希核验通过则返回缓存，同键异输入则拒绝。。易混点：依赖本地状态库中已确认的成交；不保证外部券商 exactly-once，也不撤销已提交成交或消除网络未知结果。。

<a id="g332"></a>

## 数据血缘（Data Lineage）

记录规范化输入、配置、代码版本与输出产物之间的来源关系，供运行追溯。

表达：无单一公式：关联输入／配置／代码哈希与输出身份或哈希，并以状态库锚定的产物哈希核验。

用途：第45章：每次离线运行保留规范化输入、配置、`lineage.json`、代码身份和输出校验值，以回溯结果所依赖的版本。。易混点：哈希和来源链接不证明数据正确、完整或已获授权；规范化 JSON 也不会使运行时字典不可变。。

<a id="g333"></a>

## 异常停单（Kill Switch）

风险、输入校验或对账闸失败后，将运行状态持久置为 `STOPPED` 并阻断后续成交。

表达：无单一公式：触发事件 → 持久 `STOPPED` → 拒绝后续订单请求／模拟成交。

用途：第45章：核心流程在风险或独立对账失败时写入状态与事件；操作者据账本核对失败点后决定后续处置。。易混点：不回滚已经确认的成交；状态停止与告警、取消外部订单是不同动作，未知外部订单结果仍须查询确认。。

<a id="g334"></a>

## 模型漂移（Model Drift）

随时间发生的输入分布或成熟预测误差分布变化，需要按预定规则调查。

表达：无单一公式：监控协议须指定指标、观察窗口和告警条件；告警本身不证明模型失效或授权重训。

用途：第45章：按模型／数据版本监控输入分布与已成熟误差，在预定窗口更新统计量，触发后进入调查或停用评估流程。。易混点：输入边际变化不自动意味着条件关系或 Alpha 变差；阈值须事先校准，告警不等于自动重训。。

<a id="g335"></a>

## 资本资产定价模型（Capital Asset Pricing Model (CAPM)）

在本章共同预期、一期均值—方差选择等均衡假设下，资产预期超额收益由对市场组合的系统风险决定；市场方差须为正

表达：\(E[R_i]-r_f=\beta_i(E[R_M]-r_f)\)，\(\beta_i=\operatorname{Cov}(R_i,R_M)/\operatorname{Var}(R_M)\)；收益同期间，beta无量纲

用途：区分风险补偿假设与实现收益回归，作为市场风险归因基准。易混点：样本OLS斜率不是理论假设成立的证明；CML是有效组合关系，SML是beta定价关系。

<a id="g336"></a>

## Fama–French三/五因子模型（Fama–French Three-/Five-Factor Models (FF3/FF5)）

用市场超额收益、SMB、HML解释资产超额收益；五因子加RMW、CMA并使用其对应SMB构造，分别为规模、价值、盈利和投资的组合收益代理

表达：\(R_i-r_f=\alpha_i+\beta_i(R_M-r_f)+s_iSMB+h_iHML+\varepsilon_i\)；FF5加\(r_iRMW+c_iCMA\)，收益同期间，载荷无量纲

用途：对组合风险暴露、残差与alpha作统计归因，数据百分数先转统一单位。易混点：FF5的SMB不是直接照搬FF3的SMB；因子收益不是原始财务信号，载荷不等于持仓权重，截距不自动成为净alpha。

<a id="g337"></a>

## 时间加权平均价调度（Time-Weighted Average Price (TWAP) Scheduling）

将有符号父订单Q在N个等时片等额请求；正Q为买、负Q为卖

表达：\(q_k=Q/N\)，Q与q单位股，k为时间片

用途：为缺少可靠量曲线的执行建立简单基准，再检查剩余额度和容量。易混点：请求量不等于成交量；等时调度不保证实际成交均价等于某一事后TWAP。

<a id="g338"></a>

## 成交量参与率算法（Percentage of Volume (POV) Algorithm）

按明确分母约定和当时已可得外部量调度剩余母单；本章使用上一片已观测量

表达：外部量分母：\(q_k=\operatorname{sgn}(Q)\min(\lvert Q_{rem,k}\rvert,\rho V^{obs}_{k-1})\)；含本单总量分母改为\(\rho V^{obs}_{k-1}/(1-\rho)\)，\(0<\rho<1\)

用途：用量的可得时间与发送时间约束参与节奏，并限制剩余额度。易混点：滞后量只是请求代理，不保证当前实际参与率；未来或尚未结算的当片总量不可预先读取。

<a id="g339"></a>

## 实施短缺（Implementation Shortfall (IS)）

以决策价P_d无摩擦完成有符号目标Q的纸面终值，减实际执行终值；实际成交F_k同方向，剩余R=Q−ΣF_k，终值价P_T，显式费C

表达：\(IS=\sum_k F_k(P_{fill,k}-P_d)+R(P_T-P_d)+C\)，单位货币

用途：把延迟、执行、未成交机会成本与显式费用对到现金/持仓终值。易混点：到达价分解各项之和须守恒；成交价已含点差/冲击时不重复扣；未成交机会成本可为负。

<a id="g340"></a>

## 伊藤公式（Itô's Lemma / Itô Formula）

若\(dX_t=b_tdt+a_tdW_t\)，对满足适用条件的\(f\in C^{1,2}\)，随机链式法则包含Brownian二次变差项

表达：\(df=(f_t+b_tf_x+\tfrac12a_t^2f_{xx})dt+a_tf_xdW_t\)；各项与f同单位

用途：推导GBM对数收益、期权PDE与随机收益敏感度。易混点：不是普通微积分链式法则，也不是Itô积分定义；二阶项不能省略，任意不光滑支付须另论。

<a id="g341"></a>

## Black–Scholes–Merton模型与公式（Black–Scholes–Merton Model / Formula）

常r/q/σ、连续自融资复制等假设下的欧式期权定价；S/K为正，剩余年限τ和σ为正，q为连续股息率

表达：\(C=Se^{-q\tau}\Phi(d_1)-Ke^{-r\tau}\Phi(d_2)\)，\(d_1=[\log(S/K)+(r-q+\sigma^2/2)\tau]/(\sigma\sqrt\tau)\)，\(d_2=d_1-\sigma\sqrt\tau\)；按一单位标的用同币种价格，τ为年，r/q为年率，σ为1/√年，Φ为标准正态CDF

用途：将复制、风险中性期望、PDE和Greeks连起来；put由对应支付或平价得到。易混点：真实漂移μ不必等r；Φ(d1)不是未加权的Q行权概率；API有保守浮点支持域与到期/零波动分支，非生产库精度保证。

<a id="g342"></a>

## 随机微分方程（Stochastic Differential Equation (SDE)）

以漂移和随机积分描述状态；W是相容滤过下Brownian运动，积分须满足相应可测/可积条件

表达：\(X_t=X_0+\int_0^t b_sds+\int_0^t a_sdW_s\)；b单位状态/时间，a单位状态/√时间

用途：表达价格、利率或隐状态动态，再选符合模型的数值离散方法。易混点：dW不能当普通导数；系数任意给定不保证解存在/唯一；Euler近似不自动保持价格正性。

<a id="g343"></a>

## Almgren–Chriss最优执行模型（Almgren–Chriss Optimal Execution Model）

在本章线性永久/临时冲击、给定波动等模型中，按风险厌恶权衡预期执行成本与剩余库存风险

表达：\(\min_{n_k}E[IS]+\lambda\operatorname{Var}(IS)\)，\(n_k\ge0,\sum n_k=X\)；卖出X股，IS为货币，λ为1/货币

用途：推出清算库存轨迹与成本—风险前沿，比较风险中性TWAP和更快清算。易混点：模型最优不等于实盘最优；冲击系数/量/延迟未校准时仅为教学，离散凸性条件须检查。

<a id="g344"></a>

## 扩展窗口验证（Expanding-Window Validation）

历史训练起点固定，截止随折向前扩大，之后区间评价；标签还须在拟合时可得并排除事件重叠

表达：第k折训练\([t_0,T_k]\)，后续测试，\(T_{k+1}>T_k\)；端点按时间契约

用途：模拟不断积累历史数据的训练，内层拟合预处理和选参。易混点：与固定长度rolling window不同；时间顺序本身不能消除未成熟标签、数据修订或跨折泄漏。

<a id="g345"></a>

## 因果有向无环图（Causal Directed Acyclic Graph (DAG)）

用无环有向图表达变量间假设的因果路径；边表示因果假说，不是从相关自动恢复的事实

表达：\(G=(V,E)\)，V为变量、E为有向边；识别仍需条件与目标总体

用途：分辨混杂、后门和对撞路径，说明为何调整某变量及ATE识别假设。易混点：调整所有变量并不更好；控制对撞物可引入偏差；统计调整后的差值无条件下不能称真实因果。

<a id="g346"></a>

## 隐含波动率微笑/偏斜（Implied-Volatility Smile / Skew）

固定到期下，把有效期权报价反解的BSM隐含波动率画成执行价或moneyness函数；价格/股息/利率/期限口径一致

表达：求\(V_{BSM}(\sigma_{imp};S,K,r,q,\tau)=V_{obs}\)；σ为1/√年

用途：描述常波动模型对不同执行价报价的拟合差异，并建立曲面风险语境。易混点：隐含波动率不是未来实现波动率的保证；无效报价/到期/边界可能无可识别有限解，本章未做真实曲面校准。

<a id="x000"></a>

## 实施短缺（implementation shortfall）

见有符号父单IS及36章；纸面决策价终值减实际成交/余量/显式费终值。

<a id="x001"></a>

## 排除自成交量参与率（exclusive participation rate）

自身成交量除外部市场量；事前滞后量请求不保证实际比率。

<a id="x002"></a>

## 包含自成交量参与率（inclusive participation rate）

自身成交除外部加自身总量；对外部量V，目标rho对应rhoV/(1−rho)，0<rho<1。

<a id="x003"></a>

## 截止余量（cutoff remainder）

有符号母单减有符号成交；截止机会成本可负，不补造成交。

<a id="x004"></a>

## 在途预留量（reserved in-flight quantity）

后续发送时尚未确认的已发数量；预留避免超母单，不等于已成交。

<a id="x005"></a>

## 事前预测量排程（forecast-volume schedule）

首次发送前冻结量预测并排请求，不把未来实际量当事前预测。

<a id="x006"></a>

## 临时冲击（temporary impact）

模型当前成交价分量，与持久更新分开；需校准，markout不自动识别因果。

<a id="x007"></a>

## 永久冲击（permanent impact）

指定执行模型中的持久价格更新，不是有限markout自动识别的因果估计。

<a id="x008"></a>

## 有效点差（effective spread）

两倍方向修正的成交减到达mid，单位每份价格；与报价/实现点差分开。

<a id="x009"></a>

## 实现点差（realized spread）

两倍方向修正的成交价减预设期限后mid；期限影响结果，不自动识别逆向选择。

<a id="x010"></a>

## 整股执行支持域（whole-share execution domain）

P5对实际分数股账户在日计提前拒绝；精确拆股权益换算不同于支持分数股执行。

<a id="x011"></a>

## 仓位事件（position episode）

首次离开空仓成交至双腿回零；未闭事件不进已闭交易胜率。

<a id="x012"></a>

## 首次到达价（first-arrival price）

父单多次部分成交保持同首次到达锚；逐次重置会改变IS分解。

<a id="x013"></a>

## 冻结价差（frozen spread）

交易窗使用形成期系数/均值/标准差，不读未来交易结果重拟合。

<a id="x014"></a>

## 同向对冲（same-direction hedge）

负对数价格弹性可在局部关系下给同号腿，不属于正beta多空选择域。

<a id="x015"></a>

## 上市支持集（listed support set）

约束组合可用的全部信号列坐标；无alpha名称也可能对冲。

<a id="x016"></a>

## 有效阿尔法集（alpha-valid set）

初排序使用的非缺失分数子集，不必等于优化器上市支持全集。

<a id="x017"></a>

## 齐次约束（homogeneous constraints）

Aw=0保共同缩放，非零目标一般不保；投影后归一需核。

<a id="x018"></a>

## 信噪比（signal-to-noise ratio）

模型中明示的信号方差/噪声方差比；不同于样本预测分数或独立样本量。

<a id="x019"></a>

## 可靠性图（reliability diagram）

分组预测均值对实现均值；分类校准文档不自动支持回归斜率定义。

<a id="x020"></a>

## 组置换（group permutation）

同日对一组列用同一行置换，保组内关系、破与目标联系。

<a id="x021"></a>

## 子空间主角（principal angles）

子空间间夹角，不等于单轴旋转；重复特征值下固定符号仍不唯一。

<a id="x022"></a>

## 白化（whitening）

把PC分数缩到单位方差会改变固定Ridge惩罚，不是原正交控制比较。

<a id="x023"></a>

## 隐马尔可夫模型（hidden Markov model）

潜在Markov链，本模型给完整状态路径后观测条件独立；滤波/平滑信息不同。

<a id="x024"></a>

## 结构归纳偏置（structural inductive bias）

结构对函数类的限制，如局部共享卷积；不证明交易优势。

<a id="x025"></a>

## 恒定误差回路（constant error carousel）

LSTM加法细胞的固定门直接导数路径，不消除全部总梯度衰减。

<a id="x026"></a>

## 条件可交换性（conditional exchangeability）

给充分协变量后潜在结果独立于处理，是识别假设，不由构造表验证。

<a id="x027"></a>

## 稳定个体处理值假设（stable unit treatment value assumption）

个体间无干扰且无隐藏处理版本，属因果设计假设，不是拟合指标。

<a id="x028"></a>

## 分层标准化（stratified standardization）

双处理组用同目标权重汇总层内结果，ATE解释仍需识别假设。

<a id="x029"></a>

## 预训练语料截止（pretraining corpus cutoff）

声明截止不等于可审计历史资产/输入版本，未知模型/更新仍重要。

<a id="x030"></a>

## 强误差（strong error）

此处共噪声精确/Euler终端L2 RMSE；独立路径差含抽样噪声。

<a id="x031"></a>

## 弱误差（weak error）

此处g(S)=S配对均值差及SE，不等于逐路径RMSE或任意支付保证。

<a id="x032"></a>

## 市场风险价格（market price of risk）

常系数模型lambda=(mu−r)/sigma，单位年^−1/2，须sigma>0。

<a id="x033"></a>

## 数据闸（data gate）

执行前核schema/单位/Bool/非有限；通过不证明许可或真实。

<a id="x034"></a>

## 时点闸（timing gate）

信号前核版本/可得/入库及新鲜度，日期相同不够。

<a id="x035"></a>

## 执行闸（execution gate）

新成交前核风险及持久成交余量，请求不等于确认成交。

<a id="x036"></a>

## 对账闸（reconciliation gate）

独立方程按容差核现金/量/NAV，不证明市场有效。

<a id="x037"></a>

## 恢复闸（recovery gate）

区分未发布暂存、有效已发布和损坏已发布，不静默修坏证据。

<a id="x038"></a>

## 命名空间原子性（namespace atomicity）

同文件系统rename可原子换名，不等于断电持久或券商多文件事务。

<a id="x039"></a>

## 协变量偏移（covariate shift）

定义为P(X)变而P(Y|X)不变，输入告警不自动证明该条件。

<a id="x040"></a>

## 锁定报告（locked reporting）

对已暴露历史施加未来访问/报告约束，不恢复盲留出身份。

<a id="x041"></a>

## 等权重（equal weight）

对纳入的N项资产，w_i=1/N；资金等权一般不等于风险贡献相等。

<a id="x042"></a>

## 风险预算（risk budgeting）

组合波动sigma_p>0时，RC_i=w_i(Sigma w)_i/sigma_p。一般风险预算要求RC_i=b_i sigma_p，所给b_i非负且之和为1；ERC为b_i=1/N的特例，仍须满足解的存在性及权重约束。

<a id="x043"></a>

## 符号不确定性（sign indeterminacy）

特征向量v与−v张成同一主轴，载荷换号时得分也换号。重复特征值对应空间内还可作正交旋转，仅固定符号不能唯一确定各轴。

<a id="x044"></a>

## 剩余期限（remaining maturity）

以年计tau=T−t；固定到期日T时，日历Theta=dV/dt=−dV/dtau，与对剩余期限的导数符号相反。

<a id="x045"></a>

## 渐进可测（progressively measurable）

相对滤过(F_t)，对每个t，H在[0,t]上的限制须关于B([0,t])与F_t的乘积sigma代数可测；仅适应不足以推出此性质，Ito被积过程还须满足章内平方可积条件。

<a id="x046"></a>

## 可预测过程（predictable）

关于由适应且左连续过程生成的可预测sigma代数可测（含初始时点约定），表达积分时点前可用；适应性本身不足以保证可预测，章内Ito构造另要求平方可积。

<a id="x047"></a>

## 样本外（out-of-sample）

在未用于拟合及所声明模型选择步骤的观察上评价；有效设计仍须遵守时间、标签可得及预处理边界，反复查看会污染最终留出身份。样本外R²只是该样本上的一种指标，不是样本外本身的定义。

<a id="a000"></a>

## 量化金融（quantitative finance）

用数学、统计与计算研究金融问题，范围不限于交易alpha。

<a id="a001"></a>

## 金融工程（financial engineering）

按假设、支付与约束设计和估值金融索取权或系统。

<a id="a002"></a>

## 系统化交易（systematic trading）

按明确可重复规则交易，仍需数据、执行和风险验证。

<a id="a003"></a>

## 算法交易（algorithmic trading）

程序执行交易决策或订单排程，自动化不自动带来优势。

<a id="a004"></a>

## 预测（forecast）

有明确起点、目标和期限的未来条件估计，不是实现结果。

<a id="a005"></a>

## 目标权重（target weight）

执行前期望资金配置，实际权重受成交、费用与漂移影响。

<a id="a006"></a>

## 订单（order）

含方向、量、价格与时间条件的交易请求，不是已确认成交。

<a id="a007"></a>

## 成交（fill）

按价格和时点确认的实际成交量，与请求分开记账。

<a id="a008"></a>

## 持仓（position）

指定时点、单位的实际持有数量或合约敞口。

<a id="a009"></a>

## 协方差（covariance）

中心化变量乘积的期望，收益协方差用同频收益平方单位。

<a id="a010"></a>

## 正定（positive definite）

实对称矩阵所有非零方向二次型严格正；比半正定更强且可逆。

<a id="a011"></a>

## 最小方差前沿（minimum-variance frontier）

每个目标均值的最小可行方差轨迹，含无效率下支。

<a id="a012"></a>

## 仿射组合（affine combination）

系数和为1的组合，系数不必全非负。

<a id="a013"></a>

## 总体矩（population moments）

指定生成分布的矩，不同于有限样本窗口估计。

<a id="a014"></a>

## 估计矩（estimated moments）

按窗口、估计法与可用信息从样本得到均值/协方差等。

<a id="a015"></a>

## 标准行业分类（Standard Industrial Classification）

来源采用的行业分类代码，映射与版本须核。

<a id="a016"></a>

## 开盘最高最低收盘价和成交量（Open High Low Close Volume）

区间价格与量摘要，不是逐事件订单成交，也不是行业收益文件。

<a id="a017"></a>

## 美国证券交易委员会（U.S. Securities and Exchange Commission）

美国证券监管机构；教育页、staff解释与正式规则效力不同。

<a id="a018"></a>

## 数组（array）

按轴和维度组织的数值，须说明类型及缺失规则。

<a id="a019"></a>

## 形状（shape）

各数组轴的长度，明确时间、资产和特征轴。

<a id="a020"></a>

## 标签对齐（label alignment）

按索引键配对而非按行位置，核目标/特征时间资产身份。

<a id="a021"></a>

## 扩展窗口（expanding window）

固定起点至移动截止的全部合格历史，不同固定长度滚动窗。

<a id="a022"></a>

## 时间重采样（resampling）

按日历时间分箱汇总，声明标签与端点，箱标签不等于成交时点。

<a id="a023"></a>

## 查询计划（query plan）

惰性数据引擎拟执行及优化的扫描过滤步骤，collect前可查看。

<a id="a024"></a>

## 应用程序接口（application programming interface）

软件输入输出及错误契约，文档不证明金融假设。

<a id="a025"></a>

## 集成开发环境（integrated development environment）

辅助开发的编辑工具环境，不替代运行解释器与验证。

<a id="a026"></a>

## 拆股调整价格（split-adjusted price）

按拆股规则换算成可比股份单位的价格，不一定是历史可成交报价。

<a id="a027"></a>

## 应收款（receivables）

已确认未来收款权，支付可仅把应收转现金而不新增财富。

<a id="a028"></a>

## 双时间数据（bitemporal data）

同时保来源有效时间与系统记录时间，版本资格核两轴。

<a id="a029"></a>

## 夏令时（daylight saving time）

按时区数据库改变本地偏移，使用IANA时区并以UTC核经过时间。

<a id="a030"></a>

## 微积分（calculus）

研究局部变化与累积，明确正则条件及单位。

<a id="a031"></a>

## 全微分（total differential）

可微函数的一阶线性增量，即梯度与输入增量内积。

<a id="a032"></a>

## 余项（remainder）

展开截断后余项，其阶数依光滑性与邻域条件。

<a id="a033"></a>

## 中心差分（central difference）

用x±h的对称差分近似，截断与舍入均受步长影响。

<a id="a034"></a>

## 可行方向（feasible direction）

允许小步仍满足定义域和活动约束的局部方向。

<a id="a035"></a>

## 线性代数（linear algebra）

研究向量、线性映射和矩阵系统，明确基、轴、维度。

<a id="a036"></a>

## 张成空间（span）

给定向量全部线性组合，相关向量不增加独立方向。

<a id="a037"></a>

## 主成分得分（principal component score）

去中心数据在训练主成分方向上的投影坐标。

<a id="a038"></a>

## 样本空间（sample space）

指定概率试验的所有可能结果集合。

<a id="a039"></a>

## 事件（event）

可被概率测度赋值的可测结果子集。

<a id="a040"></a>

## 概率测度（probability measure）

可列可加、非负且全空间归一为1的事件赋值，无量纲。

<a id="a041"></a>

## 概率质量函数（probability mass function）

离散变量各点概率，合计为1。

<a id="a042"></a>

## 概率密度函数（probability density function）

积分得到区间概率的密度，单位是变量单位的倒数。

<a id="a043"></a>

## 累积分布函数（cumulative distribution function）

F(x)=Pr(X≤x)，无量纲非减概率函数。

<a id="a044"></a>

## 大数定律（law of large numbers）

在明确抽样条件下均值收敛，不保证有限样本准确。

<a id="a045"></a>

## 强大数定律（strong law of large numbers）

均值几乎必然收敛，IID且有限绝对一阶矩是常见充分条件。

<a id="a046"></a>

## 中心极限定理（central limit theorem）

在独立或依赖及矩条件下标准化均值的极限定律。

<a id="a047"></a>

## 共同随机尺度（shared random scale）

整条构造序列共享一个潜在尺度，零协方差不证明独立或遍历。

<a id="a048"></a>

## 混合分布（mixture distribution）

按指定权重对潜在状态或分量分布求平均。

<a id="a049"></a>

## 均方误差（mean squared error）

估计或预测误差平方的期望，估计量MSE分为方差加偏差平方。

<a id="a050"></a>

## 显著性水平（significance level）

零假设下预设第一类错误目标，不是定价alpha。

<a id="a051"></a>

## 四阶矩（fourth moment）

E[Z⁴]有四次方单位，中心正态方差v时为3v²。

<a id="a052"></a>

## 条件外生性（conditional exogeneity）

给定回归变量/信息的误差条件均值为零，不由样本残差正交证明。

<a id="a053"></a>

## 高斯—马尔可夫条件（Gauss–Markov assumptions）

经典线性无偏估计方差比较所需条件，含明示误差协方差结构。

<a id="a054"></a>

## 残差平方和（residual sum of squares）

拟合残差平方和，单位为响应平方。

<a id="a055"></a>

## 总平方和（total sum of squares）

中心化响应平方和，通常R²需其为正。

<a id="a056"></a>

## 决定系数（coefficient of determination）

相对明确基准的拟合改进，样本内R²非因果或交易收益。

<a id="a057"></a>

## 调整决定系数（adjusted R squared）

自由度调整的样本内R²，要求残差自由度正。

<a id="a058"></a>

## 残差自由度（residual degrees of freedom）

满秩模型观察数减含截距参数数。

<a id="a059"></a>

## 非冗余限制（nonredundant restrictions）

约束矩阵满行秩，重复约束不增加独立检验数。

<a id="a060"></a>

## 帽子矩阵（hat matrix）

满秩OLS中把响应映为拟合值的投影矩阵。

<a id="a061"></a>

## 次梯度（subgradient）

凸函数支撑斜率/向量，绝对值在零处允许[−1,1]。

<a id="a062"></a>

## 决策变量（decision variable）

优化可选择的量，须明确定义域与单位。

<a id="a063"></a>

## 可行点（feasible point）

满足全部定义域与约束的点，不一定最优。

<a id="a064"></a>

## 凸集（convex set）

包含任意两点之间全部线段的集合。

<a id="a065"></a>

## 线性规划（linear program）

线性目标及仿射等式/不等式约束的优化。

<a id="a066"></a>

## 强对偶（strong duality）

适用条件下原始/对偶最优值相等，不同于弱界。

<a id="a067"></a>

## 互补松弛（complementary slackness）

乘子与约束松弛乘积为零，非活动不等式乘子为零。

<a id="a068"></a>

## 相对内部（relative interior）

在集合仿射包内定义的内部，不是全空间内部。

<a id="a069"></a>

## 活动约束（active constraint）

取等号的约束，活动不必有正乘子。

<a id="a070"></a>

## 定义域（domain）

函数或模型有定义的输入集合，不默认全实向量。

<a id="a071"></a>

## 股息应收（dividend receivable）

支付前确认的股息权，后续收现金不一定新增收益。

<a id="a072"></a>

## 名义敞口（notional exposure）

参考经济敞口，不等于抵押品或净投入资本。

<a id="a073"></a>

## 修正久期（modified duration）

固定现金流及收益率约定下，价格一阶导数取负除以价格。

<a id="a074"></a>

## 凸性（convexity）

债券价格对收益率二阶导数除正价格，明确现金流与复利。

<a id="a075"></a>

## 期权支付额（option payoff）

到期合约支付额，未扣期权费、融资与交易费。

<a id="a076"></a>

## 简单收益（simple return）

指定持有区间与现金流下财富变化除初财富。

<a id="a077"></a>

## 对数收益（log return）

正财富或价格比的自然对数，匹配区间可跨时间相加。

<a id="a078"></a>

## 弱平稳增量（weakly stationary increments）

增量均值方差固定、协方差只依lag，不使累计水平平稳。

<a id="a079"></a>

## 结构性基准行（structural baseline row）

如初财富的展示基准行，不加入收益样本统计。

<a id="a080"></a>

## 归母净利润（net income attributable to the parent）

归属母公司所有者的利润，有优先分配时不等于普通股可用盈利。

<a id="a081"></a>

## 普通股可用盈利（earnings available to common shareholders）

匹配普通股索取权、扣适用优先分配后的盈利。

<a id="a082"></a>

## 非经营资产（nonoperating assets）

匹配经营现金流范围外、单独估值的资产。

<a id="a083"></a>

## 终值（terminal value）

显式预测终点价值，稳定增长永续需贴现率大于增长率。

<a id="a084"></a>

## 权益法（equity method）

按适用准则核算联营/合营的方式，不是全面并表。

<a id="a085"></a>

## 状态价格（state price）

未来指定状态支付一单位的现价，q=p·m不必合计1。

<a id="a086"></a>

## 完备市场（complete market）

可交易支付张成指定状态支付空间的市场，唯一性另需定价假设。

<a id="a087"></a>

## 证券市场线（Security Market Line）

CAPM预期收益对beta关系，不同于均值波动CML。

<a id="a088"></a>

## 同期归因（contemporaneous attribution）

用同期已实现因子解释收益，不是事前预测。

<a id="a089"></a>

## Holm逐步校正（Holm step-down adjustment）

对明示检验族排序逐步校正；项目九截距族不包含未登记搜索。

<a id="a090"></a>

## 随机过程（stochastic process）

有指定联合分布、按时间索引的随机变量族。

<a id="a091"></a>

## 一次实现（realization）

一条观察或生成路径，不是总体分布。

<a id="a092"></a>

## 遍历性（ergodicity）

连接适当时间均值与总体期望的条件，平稳本身不够。

<a id="a093"></a>

## 误差修正模型（error-correction model）

协整模型下短期差分加滞后长期偏离项。

<a id="a094"></a>

## 稳态初始化（stationary initialization）

从模型平稳分布取初态，有限burn-in仅作近似。

<a id="a095"></a>

## Joseph协方差更新（Joseph covariance update）

展开更新同时保先验传播与观测噪声项以助数值稳定。

<a id="a096"></a>

## 后验均值协方差（posterior-mean covariance）

估计均值的不确定性，不同于未来收益观察协方差。

<a id="a097"></a>

## 二次增长代理（quadratic growth proxy）

明示二阶近似，不是任意离散收益的精确期望log效用。

<a id="a098"></a>

## 权重换手代理（weight-turnover proxy）

指定口径目标或持有权重绝对变化，不自动等于实际交易额。

<a id="a099"></a>

## 阻尼Newton法（damped Newton method）

Newton方向加线搜索保定义域和目标改善，仍核原方程残差。

<a id="a100"></a>

## 胜者诅咒（winner's curse）

被选表观效果偏大，多重检验校正不自动修正效果量。

<a id="a101"></a>

## 配对内重排名（reranking within valid pairs）

先取双方有限配对再各自排名，分别drop缺失可能错位。

<a id="a102"></a>

## 有效日期数（number of valid dates）

有定义逐时点统计数，不同信号数、资产配对数和候选标签日。

<a id="a103"></a>

## 结果曝光（result exposure）

记录结果已经被看过，后设本地hash不能恢复盲态。

<a id="a104"></a>

## 持仓批次（vintage）

一个形成日期的目标权重集，替换批次不等于实际成交量。

<a id="a105"></a>

## 形成区间（formation interval）

估计信号或价差的观察窗，明确端点与记录数。

<a id="a106"></a>

## 权益乘数（equity multiplier）

资产除权益，余额时点匹配，区分期末与平均。

<a id="a107"></a>

## 抵押资本（collateral capital）

抵押或分配资本，收益分母须与合约名义额分开。

<a id="a108"></a>

## 名义金额（notional）

按乘数计算的价格乘合约单位，不同于抵押资金。

<a id="a109"></a>

## 全额抵押指数（fully collateralized index）

按财富重调名义额的指数约定，不同固定一合约现金账本。

<a id="a110"></a>

## 合成信息系数（composite information coefficient）

加权信号与目标相关，需可行联合矩及合成方差正。

<a id="a111"></a>

## 完全随机缺失（missing completely at random）

缺失机制独立于讨论变量，是假设而非NaN自动性质。

<a id="a112"></a>

## 执行价（execution price）

实际或模型成交价，E=P仅收盘mark代理，不保证实测成交。

<a id="a113"></a>

## 标记价（mark price）

指定时点估值价，不一定可执行。

<a id="a114"></a>

## 自由现金（free cash）

账户受限抵押之外可用现金。

<a id="a115"></a>

## 受限抵押（restricted collateral）

隔离抵押余额，现金抵押内部转移在总NAV相抵。

<a id="a116"></a>

## 借券回扣（borrow rebate）

按明示基准的卖空抵押利息或回扣，不重复计息。

<a id="a117"></a>

## 不交易区域（no-trade region）

给定静态目标下费用后不宜调仓的当前漂移状态区域。

<a id="a118"></a>

## 总回报代理水平（total-return proxy level）

已含分派的合成财富指数单位，不再加同股息。

<a id="a119"></a>

## 执行副本（execution copy）

保留原研究信号、按执行资格调整的目标副本。

<a id="a120"></a>

## 回测偏差（backtesting bias）

由信息、选择或记账污染导致的失真，需指出实际渠道。

<a id="a121"></a>

## 选择最大值（selection maximum）

搜索后最大值，其期望不是家族检验临界分位数。

<a id="a122"></a>

## 逆Mills比率（inverse Mills ratio）

固定截断及位置尺度约定下正态密度除相应尾概率。

<a id="a123"></a>

## 期望最大值（expected maximum）

给定候选分布和数目的极值期望，不同临界分位数。

<a id="a124"></a>

## 保证金余量（margin headroom）

可用抵押减所需保证金，属融资约束而非持仓方向。

<a id="a125"></a>

## 尺度参数（scale parameter）

分布声明的尺度，t标准差另依自由度且可能不存在。

<a id="a126"></a>

## 订单簿扫单（order-book sweep）

按余量政策计算静态可见簿成交，不是完整撮合器。

<a id="a127"></a>

## 事后市场均价（ex-post market VWAP）

对指定外部交易/区间加权均价，自身交易是否计入须明示。

<a id="a128"></a>

## 执行风险（execution risk）

执行尚有库存期间的价格风险，不是确定实现费用。

<a id="a129"></a>

## 暗池路由（dark-pool routing）

按规则向非显示场所路由，模型阈值需相应证据。

<a id="a130"></a>

## 配对交易（pairs trading）

双腿相对价值方法，需训练筛选、冻结参数、成交融资及失效分析。

<a id="a131"></a>

## 拆股权益（split entitlement）

拆股后的精确股份或现金权，不同执行器分数股支持域。

<a id="a132"></a>

## 出场补单（exit retry）

继续完成出场的后续请求，受样本、容量与执行支持域约束。

<a id="a133"></a>

## 特征工程（feature engineering）

按来源、变换、窗口与可用时间构造模型输入。

<a id="a134"></a>

## 截面误差（cross-sectional error）

同日去均值后的平方误差，目标与预测尺度仍重要。

<a id="a135"></a>

## 无核衰减截断（unweighted covariance truncation）

截至带宽无衰减加总自协方差，不同固定Bartlett NW。

<a id="a136"></a>

## 固定带宽Bartlett核（fixed-bandwidth Bartlett kernel）

至预设q的权重1−k/(q+1)，单位依实际日历索引。

<a id="a137"></a>

## 构造展示回放（constructed display replay）

读取冻结构造载荷不新拟合，新展示图也不是重训。

<a id="a138"></a>

## 树桩（decision stump）

只有一次切分的树，阈值和叶输出仍是估计量。

<a id="a139"></a>

## 干预式SHAP（interventional SHAP）

从背景联合取缺失坐标的Shapley价值函数，不等于因果识别。

<a id="a140"></a>

## 条件式SHAP（conditional SHAP）

背景条件于已观察坐标的价值函数，依赖结构改变归因。

<a id="a141"></a>

## 主成分回归（principal component regression）

在保留PC分数上回归，截断可丢低方差预测方向。

<a id="a142"></a>

## 雅可比矩阵（Jacobian matrix）

向量函数偏导矩阵，固定门LSTM细胞直接路径为diag(f)，非全导数。

<a id="a143"></a>

## 互相关（cross-correlation）

此CNN有效互相关不反转核，边界与步长影响形状。

<a id="a144"></a>

## 遗忘门（forget gate）

LSTM保留细胞状态的比例门，直接增益不同递推全导数。

<a id="a145"></a>

## 边际似然（marginal likelihood）

对参数积分后的数据概率或密度，归一化后验。

<a id="a146"></a>

## 后验精度（posterior precision）

后验方差倒数，单位为变量平方的倒数。

<a id="a147"></a>

## 词袋（bag of words）

无序token计数表示，本身不作词统计独立假设。

<a id="a148"></a>

## 均值池化（mean pooling）

按token平均向量，后续归一要求均值向量非零。

<a id="a149"></a>

## 费用容忍度（fee tolerance）

对明示比例费率的敏感性，不是资金规模容量。

<a id="a150"></a>

## 除息价格（ex-dividend price）

不含单独分红现金的价格，价格漂移与总收益漂移不同。

<a id="a151"></a>

## 列投影下推（projection pushdown）

实体化前只扫描请求列。

<a id="a152"></a>

## 过滤下推（filter pushdown）

扫描或行组选择时下推过滤，元数据剪枝不代替完整谓词核验。

<a id="a153"></a>

## 全额成交（full fill）

请求数量在引擎支持域内全成交，正实数股不等于已核lot size。

<a id="a154"></a>

## 累计均值（cumulative mean）

截至当前t全部合格观察均值，每条成熟观察只更新一次。

<a id="a155"></a>

## 费后目标（post-cost target）

目标金额为权重乘费后NAV，不是费前NAV。
