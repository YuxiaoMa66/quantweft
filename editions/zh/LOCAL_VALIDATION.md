# 运行环境与兼容性 / Runtime environment and compatibility

完整课程包的运行说明见[入口](README.md)和[Notebook 导读](NOTEBOOK_GUIDE.md)。仓库声明 Python 3.12 或更高版本；[requirements-macos-arm64-py314.lock](../../requirements-macos-arm64-py314.lock) 提供 macOS arm64、CPython 3.14 环境的依赖锁定示例。该锁文件针对特定平台和 Python 版本，不能据此推定其他平台或版本兼容。

The complete package setup is described in the [reader README](README.md) and [Notebook guide](NOTEBOOK_GUIDE.md). The repository declares Python 3.12 or later; [requirements-macos-arm64-py314.lock](../../requirements-macos-arm64-py314.lock) provides a dependency lock for macOS arm64 with CPython 3.14. That lock is specific to its platform and Python version and does not imply compatibility with every environment.

运行时默认路线使用构造数据，可在不下载市场数据的情况下学习代码与方法。French 原始、提取与处理数据不随包提供；市场实证需要适当的数据权利与可用数据。构造结果不是市场证据。

The default route uses constructed data and can be followed without downloading market data. French raw, extracted, and processed data are not included; market research requires suitable data rights and data. Constructed results are not market evidence.
