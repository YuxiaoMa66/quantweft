# Project 3 练习

完整解答见 [solutions.md](solutions.md)，默认运行说明见[导读](READER_GUIDE.md)。P3-01、P3-03、P3-04和P3-06可结合本书给出的输入与历史表回答。P3-02需历史primary_ledger.csv，P3-05的历史计算需French输入；它们不由默认构造分支生成，缺这些材料时阅读完整历史参考解，不要求启动市场分支。

**P3-01（手算账本）** 两资产组合在 1 月初的目标权重为 (0.6, 0.4)。1 月两资产收益为 +5% 与 −10%。2 月初目标权重仍为 (0.6, 0.4)，成本 25 bp/单位换手；2 月两资产收益为 +2% 与 +1%。计算 1 月末漂移后权重、2 月初换手、成本、2 月毛收益与净收益。

**P3-02（账本恒等式）** 读取 outputs/primary_ledger.csv，对每一行验证 \(\text{cost}=0.001\times\text{turnover}\) 与 \(\text{net}=(1-\text{cost})(1+\text{gross})-1\)，并验证每个策略相邻两月的 train_end 都早于 holding_month。

**P3-03（滞后为何不影响等权）** sensitivity.csv 中等权在滞后 0 与滞后 1 下指标完全相同，最小方差略有不同。解释原因，并说明这对“时点假设是否重要”的推断意味着什么。

**P3-04（区间解读）** ERC 的年化净 Sharpe 比等权高 0.016，块自助法 95% 区间为 [−0.014, 0.050]，平均净收益差为 −0.38%/年。能否说 ERC 优于等权？写出你会接受的结论措辞。

**P3-05（未预注册的探索）** 有人提议把窗口改成 24 个月“看看会不会更好”。用 src/project03_backtest.py 的函数在主规格其他参数不变时运行 W=24 的最大 Sharpe，报告年化净 Sharpe，并说明这类结果在报告中应如何标注。

**P3-06（研究设计）** 若要把本项目改造成可交易研究，列出必须替换或新增的数据、时点、成本与评价要素，并给出一条会推翻“ERC 降低风险集中而不损失收益”这一说法的证据。
