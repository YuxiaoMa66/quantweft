# Project 5 研究报告：预注册walk-forward配对交易

本报告使用c5/v2构造结果，并按2026-10-14整股执行边界解释。**真实价格实证：blocked（数据许可）。** 全部数值来自教学构造面板，只说明流程、账本与检验方法能按契约运行，不是任何真实配对盈利或协整的证据。c1–c4的v1结果属于不同设定，不作为本报告的c5结论。

## 1. 研究问题与可证伪假设

第17章说明：两条非平稳价格若存在平稳线性组合（协整），价差会回到均值；相关只描述同步变动，不保证价差回归。本项目问：在**预先固定**的8个经济上相关的美国上市配对中，只用训练段筛选协整并冻结参数，下一段按z-score做一多一空的相对价值交易，计入双腿成本、借券与融资后，组合是否有稳健的正超额收益。

判断规则（`claim_rule`，v1与v2相同）：主规格的正结果必须在成本网格与“screened对ungated”选择效应对照下都保持，才可写“支持”；否则写“证据不支持该策略”，并保留全部零与负结果。阈值网格与252日形成窗只作描述，不得用于挑选版本后再报告同一样本。

## 3. 时间契约

| 字段 | 定义 |
|---|---|
| event_time | 交易日 \(d\) 的开盘（09:30）与收盘（16:00），America/New_York |
| available_at | 开盘价09:30可得；收盘价与当日全天成交量16:00后可得；DFF观测日 \(s\) 的利率自 \(s\) 次日可得（发布滞后近似为1个日历日） |
| signal_time | 收盘 \(t\)：z-score只用 \(\le t\) 的TR与形成期冻结参数 |
| trade_time | 下一交易日开盘 \(t+1\)；没有同收盘成交 |
| return interval | 相邻收盘标记之间；NAV从形成期末收盘的 \(W_0\) 起，N+1个点给N个收益 |
| label interval | 无（信号不使用未来收益标签），故walk-forward无需purge/embargo |

同一天的事件顺序：隔夜结息（前一收盘可得利率、前一收盘标记）→拆股→股息→两腿按09:30开盘价标记→开盘成交→日内结息（当日开盘可得利率、开盘标记）→收盘标记。

## 4. 方法

**形成（只用训练段）。** 每个504日形成窗对 \(\log TR_y=\alpha+\beta\log TR_x+e\) 做OLS，冻结 \(\alpha,\beta\) 与残差均值、标准差；EG检验用statsmodels `coint`（常数项、AIC滞后），临界值是MacKinnon协整残差分布，而不是普通ADF（第17章）。v2选入条件：未校正 \(p<0.05\) 且 \(\beta>0\)；窗口内BH \(q\) 值只报告不用于筛选。

**信号。** \(z_t=(s_t-\bar s)/\hat\sigma_s\)，\(s_t\) 用冻结的 \(\alpha,\beta\) 代入新TR。\(|z|\ge2\) 入场（\(z>0\) 做空价差：空 \(y\)、多 \(x\)），\(|z|\le0.5\) 或穿越零出场，\(|z|\ge4\) 止损且同窗不再入场；窗口最后一个收盘发出强制退出请求，实际完成仍受样本、容量与整股支持域约束。

**对冲与仓位。** 对数价差的 \(\beta\) 是弹性（\(x\) 变动1%时 \(y\) 平均变动 \(\beta\)%）：美元暴露 \(w_y=s/(1+|\beta|)\)、\(w_x=-s\beta/(1+|\beta|)\)，毛暴露为信号收盘NAV的1倍；信号时目标股数 \(n_t=\operatorname{trunc}(w W_t/C_t)\)，先向零取整，再换算到次日拆股后的股数 \(r_{t+1}n_t\)；次日除息不增加目标股数，持有期不再平衡。取整前绝对股数比 \(|n_x|/|n_y|=|\beta|P_y/P_x\)、有符号比 \(n_x/n_y=-\beta P_y/P_x\)，取整后只近似相等；水平回归 \(P_y=a+bP_x+e\) 的有符号对冲比为 \(-b\)（练习P5-01）。\(\beta<0\) 时两腿同向，同向仓位在一阶上也能对冲负相关关系（\(\beta=-1.2\) 时两腿美元45.45万与54.55万同向，\(d\log y=-1.2\,d\log x\) 下一阶总损益为0）；v2只是把项目限定为一多一空。IS决策参考价独立按次日开盘的公司行动换算：\(P^{dec}=C_t/r_{t+1}-D_{t+1}\)。

**执行与成本（情景，未校准）。** 令Q为请求、F为实际非零成交；先按容量与整股规则得F，只有F更新现金/持仓。每条腿分别计：佣金0.005美元/股；半点差ETF 1bp、个股2bp；临时冲击 \(\eta\sigma_{20}\sqrt{|F|/ADV_{20}}\)（\(\eta=0.1\)，\(\sigma_{20}\)、\(ADV_{20}\) 截至信号收盘）。此处open为原未复权开盘价代理，不是可观测mid；成交价 \(=\) 开盘价 \(\times(1+\text{sgn}(F)(\text{半点差}+\text{冲击}))\)；点差与冲击只在成交价中，现金只另扣佣金（第35章防重扣）。**开盘成交预算**：每腿最多成交截至信号收盘的ADV20的5%，换算到成交日拆股后股数。这是未校准的开盘成交情景，不是实际开盘市场容量，也不保证实际参与率；成交日全天量和 \(|q|/\)全天量只在收盘后作诊断，不改变09:30成交。`matched` 政策下两腿按较小可成交比例同比例成交，入场剩余在到达时撤单；出场剩余不以撤单冒充平仓，按协议逐日补单；完成受有限样本、容量与整股支持域限制；`independent` 只作压力情景。

**融资与借券。** ACT/360，区间开始现金 \(\times\)（DFF−25bp，若现金为正；DFF+50bp，若为负）；借券费 \(=|q^{short}|\times P^{avail}\times 0.25\%\times\Delta d/360\)（实际空头股数、区间开始已可得标记：隔夜区间为前一收盘，日内区间为当日09:30开盘，拆股日为拆股后股数与拆股后开盘价）；空头在除息日补偿股息。没有历史借券费与可借量数据，借券召回只能以 `locate_unavailable` 情景表示。

**IS。** 全部求和只对实际非零成交集合进行，空和为0；不将零成交乘未定义均价。每个母单只有一个首次到达价：延迟 \(Q(P^{arr}-P^{dec})\) 只计一次；每次（含跨日补单）成交 \(F_k(P^{fill}_k-P^{arr})\)；被新入场取代或样本末仍未完成的出场剩余计机会成本；入场剩余在到达时撤单，机会成本为0（第36章）。

**交易统计。** 一次交易（episode）按仓位定义：从离开空仓的第一笔成交，到两腿都回到零的那笔成交；出场未完成时出现的新入场单并入同一次交易，记为reentry。交易损益 \(=\) 成交现金流 \(-\) 佣金 \(+\) 持仓期股息 \(-\) 借券费，不含现金利息。胜率为已闭合交易中损益为正的比例，持有天数为首笔到闭合成交之间的交易日数；样本末未平仓的交易单独计数，不进胜率；无已闭合交易时胜率与持有天数为缺失。换手只按实际成交金额：双边 \(\sum|q|P^{fill}\)，年化单边换手 \(=0.5\times\)双边\(/\)日均NAV\(\times252/N\)；不使用订单数量。无交易分仓的超额Sharpe也记缺失（超额收益只是计息离散误差）。

**walk-forward。** 504日形成、126日交易、126日步长滚动。每对同时运行screened（只在通过v2筛选的窗交易）与ungated（每窗都交易）两套独立账本，每套 \(W_0=1{,}000{,}000\) 美元；组合为等资本分仓之和。

## 5. 实现验证（构造面板）

- c5历史测试40项通过；P5-ALIGN历史52项通过（含新增股数与真实入口反例）。c5新增：只扰动成交日全天成交量时，当日09:30成交、价格、现金与当日收盘前NAV逐项不变；开盘预算等于由输入面板手算的ADV20×5%（含拆股换算）；无成交既存空头、一腿成交日与拆股日的日内借券基数均由输入价格和实际持仓独立推出；单笔交易的损益、胜率、持有天数与双边成交金额手算一致；未平仓交易不进胜率；v2排除 \(\beta\le0\) 的窗且CLI拒绝v1。
- 变异检验：改回“成交日全天量定容量”、删去开盘标记、去掉 \(\beta>0\) 条件，各有对应新测试失败（c5作者检查）。
- 账本现金恒等式 \(\text{现金}=W_0+\text{利息}-\text{借券}+\text{股息}-\text{成交额}-\text{佣金}\) 在全部账本残差约 \(10^{-9}\) 美元。

P5-ALIGN的实际订单例中，信号收盘价100、权重0.5、NAV一百万、次日每股股息1时，旧规则下订单为5,050股，整股修订后为5,000股，IS参考价仍为99。正负腿、同时拆股与股息、取整顺序，以及包含成交、佣金、股息、利息与借券的现金恒等式均有对应构造检查。真实价格入口仍因数据权限与字段条件未满足而拒绝执行。

## 7. 稳健性（构造，全部格点见 `robustness.csv`）

![稳健性](../figures/p05_fig_e_robustness_grid.png)

图5：左为成本网格中借券25bp时screened组合超额Sharpe随半点差倍数与 \(\eta\) 的变化；右为入场/出场阈值网格。

- 成本网格（27格）：screened组合超额Sharpe全部为负，−0.41至−0.12；借券费从25bp升到5%时区间由−0.21至−0.12降到−0.41至−0.32。

- 252日形成窗：screened组合超额Sharpe −0.02、ungated −0.77。
- 部分成交压力（\(W_0=10^9\)、预算为ADV20的5%）：`matched` 下4个入场母单（8条腿）只成交下单量的1.6%–2.0%（中位1.9%），组合收益主要是利息，决定结果的是容量预算，不是信号；`independent` 政策下首次成交的实际股数比可偏离下单比约64%（练习P5-09，预算为ADV20的1%）。收盘后诊断显示，实际成交量占当日全天量的比例最高到6.4%，高于5%的事前预算：预算不是实际参与率保证。

按预注册判断规则，构造面板上主规格没有正结果可供“支持”，结论为证据不支持该策略；这些负结果全部保留。
