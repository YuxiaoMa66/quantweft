# Project 5 练习

本组练习使用构造教学面板，并按整股执行边界解释。完整解答见 [solutions.md](solutions.md)，参考实现见 `projects/project05/solutions_code.py`。代码题使用 `src/p05_constructed.py` 的**教学构造面板**，用于演示方法，不是市场证据。真实价格实证因数据许可缺口尚未进行；见研究报告第2节。

先修：第16、17章（平稳性、协整）；第29、31章（账本、walk-forward）；第35、36章（成本、执行与IS）。

**P5-01（对冲单位，手算）** 训练段对数价差回归 \(\log TR_y=\alpha+\beta\log TR_x+e\) 得 \(\beta=1.2\)。信号收盘价 \(P_y=80\)、\(P_x=50\)；本题为简化股数估算，假定信号收盘至建仓没有拆股或股息，并按这两个价格建仓，不另模拟隔夜价格变化及成交成本，做多价差、目标毛暴露 1,000,000 美元。按 \(w_y=1/(1+|\beta|)\)、\(w_x=-\beta/(1+|\beta|)\) 求两腿美元暴露、向零取整股数、绝对与有符号股数比、净美元暴露。股数比为什么不等于 \(\beta\)？取整后它与 \(|\beta|P_y/P_x\) 还严格相等吗？若改用水平价差 \(P_y=a+bP_x+e\)，\(b\) 的单位是什么？

**P5-02（公司行动，手算）** 这是独立于P5-01建仓的公司行动情景：事件前已持有多 \(y\) 5,681股、空 \(x\) 10,909股，事件前收盘分别为80和50美元。次日 \(y\) 2:1拆股（除权日开盘），\(x\) 除息每股0.30美元。写出两腿股数与现金变化；再用前向TR公式 \(TR_t/TR_{t-1}=r_t(C_t+D_t)/C_{t-1}\) 计算：\(y\) 前收80、拆股后收盘40.6；\(x\) 前收50、除息日收盘49.9。说明若再用供应商复权价成交会发生什么。

**P5-03（融资与借券，手算）** 回到P5-01的原建仓，不承接P5-02的拆股/股息状态。初现金1,000,000美元、无初持仓、忽略建仓费用；本构造现金模型允许借券卖出所得全部计息，故初NAV也为1,000,000美元，不能只由目标毛暴露推出。建仓后现金为多少？周五16:00至周一09:30按UTC或无夏令时切换的周末计65.5小时，题设假定区间开始已知DFF为5.33%（题设给定利率），现金贷记利率=DFF−25bp，借券费年化25bp，空头标记用区间开始已可得的周五收盘50美元，ACT/360。求区间天数、利息、借券费与区间末现金。

**P5-04（跨日部分成交的IS，手算）** 出场卖出 \(Q=-10{,}000\) 股，决策价（信号收盘、事件后单位）41.00。第1天开盘40.80，容量只成交6,000股，半点差2bp、冲击5bp；第2天开盘40.50补卖4,000股，半点差仍为2bp、冲击4bp；佣金每股0.005美元。按第36章单一到达价写出延迟、执行、费用与总IS，并用直接金额法核对。考察以下具体错误算法：保留原全额Q的首次到达延迟，第2天执行项却改用第二日开盘为锚，并另加F2乘以“第二日开盘−决策价”的延迟。它会多算多少？若首日延迟只分配给F1，重新锚定还一定错误吗？

**P5-05（相关≠协整，代码）** 对构造面板的TA/TB，在每个504日形成窗计算水平相关、日收益相关和EG \(p\)。高相关为什么不能代替协整检验？

**P5-06（泄漏诊断，代码）** 把第一个形成期末之后的全部价格乘1.5，重估该窗的Formation，比较 \(\beta\)。再用全样本价差均值替代形成期均值，说明它为何是泄漏、会怎样影响z-score。运行 `solutions_code.py` 的 `leakage_checks()`，说明它检查的三个通道各排除了什么、为什么通过也不等于“没有泄漏”。

**P5-07（临界值，代码）** 对CA/CB第一个形成窗的OLS残差，分别给出EG统计量及其5%临界值、普通ADF的5%临界值。用哪一个判断？若误用普通ADF临界值，结论会怎样变？

**P5-08（选择效应与多重检验，代码＋判断）** 按预注册v2（EG \(p<0.05\) 且 \(\beta>0\)）运行三对构造配对的screened与ungated。共做多少次检验？EG通过几次、v2选中几次？若全部为原假设，预期多少个 \(p<0.05\)？比较screened与ungated的超额Sharpe、闭合交易胜率、持有天数和换手，说明“只展示通过筛选或盈利的配对”会造成什么偏差。IA_IB在窗5为何被排除？\(\beta<0\) 能否被同向仓位对冲？v1旧结果（screened组合0.39）与v2结果的差别能说明什么、不能说明什么？把形成窗换成252日，组合超额Sharpe怎样变化？

**P5-09（部分成交与单腿风险，代码）** 把W0设为1e9、开盘成交预算设为ADV20的1%，比较 `matched` 与 `independent` 成交政策：部分成交行数、出场补单次数、首次成交的“实际股数比/下单股数比−1”的最大值。入场剩余撤单对损益意味着什么？为什么不能把撤销出场余单当作已经平仓？逐日补单受哪些样本、容量与整股支持域约束？为什么当日全天成交量不能用来决定09:30成交？

**P5-10（研究判断）** 真实价格数据因许可阻断。写一段研究报告结论：哪些可以声称、哪些不能，给出数据到位后需要从哪个节点重跑哪些步骤，以及什么结果会让你得出“不支持该策略”。
