# Project 5 缺口表

这是A5筛选准备层的缺口，不是对后来c5/ALIGN构造实现的缺失声明。真实数据、权利与PIT缺口仍在；构造实现不能关闭它们。

| 缺项 | 影响 | 本层怎么处理 | 谁来补 |
|---|---|---|---|
| 证券级调整后价格（含公司行动） | 不能做真实配对筛选与回测 | 用 French 聚合行业组合演示；标注不可交易 | 用户提供或授权数据源 |
| 历史股票池与退市 | 幸存者偏差 | 没有证券，所以未涉及；不声称无偏 | 同上 |
| 借券可得性、费率、召回 | 卖空腿成本与可行性 | 未实现；`not_included` 列出 | 同上 |
| 双腿成本口径 | 净收益 | 未实现 | 同上 |
| available_at（数据可得时间） | 时点性 | French 数据没有；声明非时点 | 无法补 |
| entry/exit、风控、交易滞后、空仓 | 策略层 | 未实现（契约要求） | 完整 Project 5 阶段 |
| 样本外的多窗口 walk-forward | 稳健性 | 只给两个窗口的“训练后窗口诊断”，不做 walk-forward 评价 | 完整 Project 5 阶段 |
| 结构突变与协整破坏的检验 | 失效窗口 | 只用 frozen spread 的半衰期与 ADF 描述；不做断点检验 | 完整 Project 5 阶段 |
| 之后窗口含缺失值时的诊断 | frozen spread 的 ADF 与半衰期需要完整月序列 | 训练段筛选与之后窗口分开校验；训练段须包含 train_end；之后窗口须恰好包含 train_end 下一月至 test_end 的全部月份，各一次。缺月、缺端点、重复、空窗、NaN/无穷值直接报错，不插补，也不压缩时间；test_end 之后的数据不参与校验 | 完整 Project 5 阶段决定真实数据缺失规则；准备层拒绝不完整输入 |
