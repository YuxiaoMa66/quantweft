# Project 1 练习

先尝试作答，再看 [参考答案](solutions.md)。收益输入均为小数；除题目另说外，忽略外部现金流。

1. **复利与两种收益。** 初始财富为 100，连续两个月的简单收益为 +10% 与 −10%。求每月末财富、两月累计简单收益、两月算术平均收益和两月平均对数收益。它们为什么不同？
2. **读取报告。** 2010–2019 年 HiTec 的平均月简单收益高于 NoDur。报告中 HiTec 的财富指数、年复合增长率（CAGR）与波动率分别是多少？这些数值能否推出“HiTec 是未来更好的投资”？说明理由。
3. **同月 RF。** 某月行业收益为 2.0%，该月 RF 为 0.4%。求该月算术超额收益。若误将同年 4% 的年 RF 从每个月收益中各扣一次，会造成什么单位或频率错误？
4. **峰值回撤。** 财富路径为 `[1.00, 1.50, 0.75, 1.20]`。逐点计算相对历史峰值的回撤，并给出最大回撤。求全路径期末累计简单收益，并解释它为什么与最大回撤不同。中途财富 0.75 相对初值的 −25% 跌幅又与最大回撤有什么区别？
5. **分段比较。** 用结果表比较 2010–2014 与 2015–2019 的三类行业。哪个行业在这两个区间的年复合增长率排名第一？能源组合的 2015–2019 夏普比率（Sharpe Ratio）为负，应怎样解释？这算不算检验了未来可交易策略？
6. **图形阅读。** 财富指数、滚动波动率、回撤和箱线图各回答什么问题？说明财富图横轴上的初始点代表什么，并指出滚动波动率前 11 个月为何没有值。
