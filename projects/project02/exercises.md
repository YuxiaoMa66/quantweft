# Project 2 练习

先独立作答，再看 [参考答案](solutions.md)。除题目另说，收益以小数表示，模型结果来自固定 2010–2019 样本。

1. **同月 RF 与因子单位。** 某月 HiTec 总收益为 2.0%，同月 RF 为 0.3%，Mkt-RF 已发布值为 1.7%。写出该月因变量。若再从 Mkt-RF 中减一次 RF，会错在哪里？如果只有资产总收益而没有 RF，能否称作 CAPM 超额收益回归？
2. **解释条件 Beta。** HiTec 的 FF3 市场 Beta 为 1.158，HAC 95% 区间为 [1.075, 1.242]。用百分点解释同月 Mkt-RF 增加 1 个百分点时的线性条件关系。这个数是否证明市场变动因果地使 HiTec 收益变化？
3. **解释模型 Alpha。** NoDur-CAPM 的 Alpha 为 0.2603% / 月，HAC 95% 区间为 [−0.1223%, 0.6429%]，名义 p=0.1804，九项 Holm p=1.0000。解释其单位、区间和证据边界。
4. **复核样本方差。** NoDur-CAPM 的超额收益总样本方差、拟合方差和残差方差分别为 0.001039486、0.000582943 和 0.000456543（小数收益平方）。检验数值恒等式，并把拟合份额和残差份额换成百分比。这能否被称为未来风险的因果分解？
5. **对比 FF3 与 FF5。** HiTec 的 R² 从 FF3 的 0.864 上升至 FF5 的 0.893。指出至少两个不应把此差值直接解释成“新增 RMW/CMA 的纯增量”的理由。
6. **HAC 3/6/12 敏感性。** Enrgy-FF3 的 Alpha 在 HAC3/6/12 下点估计都为 −0.6629% / 月；95% 区间分别为 [−1.2950%, −0.0308%]、[−1.3091%, −0.0167%]、[−1.3154%, −0.0104%]。哪些量变化，哪些不变？是否有理由把三种带宽当作三次独立验证？
7. **多重比较与负结果。** 三个能源模型在 HAC6 下的 Alpha 均为负，单项 p 值分别为 0.0061、0.0444、0.0249。Holm 调整后分别为 0.0549、0.3111、0.1995。如何写出谨慎结论？报告是否可以只保留 CAPM 的名义 p 值？
8. **时间顺序切分。** 2010–2014 估计的 HiTec-FF5 Alpha 为 −0.098% / 月，2015–2019 误差 RMSE 为 1.562 个百分点 / 月。为什么这仍不是实时预测或策略收益？至少列出未来净 Alpha 研究需要补充的三类信息。
