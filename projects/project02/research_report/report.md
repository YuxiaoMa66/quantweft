# Project 2 研究报告：CAPM 与 Fama–French 因子归因

本项目使用资本资产定价模型（Capital Asset Pricing Model, CAPM）、Fama–French 三因子模型（Fama–French Three-Factor Model, FF3）与五因子模型（Fama–French Five-Factor Model, FF5）。普通最小二乘法（Ordinary Least Squares, OLS）估计系数；异方差与自相关一致协方差估计（Heteroskedasticity and Autocorrelation Consistent Covariance Estimation, HAC）用于推断；置信区间（Confidence Interval, CI）与 Holm 逐步多重检验校正（Holm Step-Down Multiple-Testing Adjustment）分别描述单项估计不确定性与所列检验族的校正。原理与手算见第8、15章。

状态：**verified**，已完成根与独立审核。本报告依据 [固定配置](../configs/analysis.json) 与 [冻结数据清单](../data_manifest.json) 编写；表格数值由可复现 CLI 计算。

## 结论

对 2010 年 1 月至 2019 年 12 月的 120 个月历史快照，FF5 的样本内 R² 在 NoDur、HiTec、Enrgy 上分别为 0.727、0.893、0.696；CAPM 分别为 0.561、0.829、0.597。增加因子后样本内拟合方差份额上升，但这只说明同期发布因子对同一批历史收益的线性拟合比例更高。

九个 Alpha 中，NoDur 与 HiTec 的 HAC 95% 区间均跨零。Enrgy 的三个 Alpha 都为负，HAC6 单项区间均低于零；对本报告展示的九个资产×模型 Alpha 作 Holm 调整后，最小 p 值为 0.0549，没有一项低于 0.05。这个结果不证明能源组合未来会继续落后，也不能把 Alpha 当成独立于模型的资产属性。所有负值和接近零的结果均保留。

研究没有因果识别、历史点时数据、信号、订单或成交账本。它不检验交易优势。成本、融资和借券在本数据中不适用；没有计算成本后策略收益或 Alpha。

## 研究问题、数据和时间

问题是：三个行业组合的超额收益与市场、规模、价值、盈利能力和投资因子的同月发布价差有何条件关系；加入因子后，Beta、模型相关截距、R² 和残差怎样变化；结果对 HAC 带宽和固定历史切片有多敏感？

资产是 Kenneth R. French 美国 10 行业组合中的非耐用品（NoDur）、高科技（HiTec）和能源（Enrgy），采用标准文件的价值加权月度总收益，含股息。French Data Library 与方法见[官方库](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)、[行业组合说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_10_ind_port.html)、[FF3 说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_factors.html)和[FF5 说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_5_factors_2x3.html)。原始研究页面见 Fama and French (1993) 与 (2015)：[1993](https://www.sciencedirect.com/science/article/pii/0304405X93900235)，[2015](https://www.sciencedirect.com/science/article/pii/S0304405X14002323)。

输入是 2026-10-05 下载并冻结的当前发布快照，FF3 与 FF5 文件头均声明 202608 CRSP 版本。数据清单记录三个输入各自的 ZIP、ZIP 成员 CSV、处理 CSV 路径与 SHA-256。CLI 核验全部哈希、ZIP CRC、成员和已保存原始 CSV 字节一致性，再通过共享月度读取器校验实际输入。项目没有重新下载、覆盖或重建 production 数据。

French 文件以百分数发布，冻结处理 CSV 已除以 100 一次；本项目读小数，不再转换。来源缺失哨兵 -99.99 和 -999 在预处理时变为空字段。任何所选值缺失、无穷、月份断档、重复或错位都会报错；不填补、不压缩缺口。主样本固定 2010-01 至 2019-12，每个资产与因子恰有 120 个相同月度 PeriodIndex。

官方说明自 2025 年 1 月发布起由旧 CRSP FIZ 切换至 CIZ Flat File Format 2.0，月度股息再投资时点有别；RF 代理来源也在 2024 年 6 月从 Ibbotson Associates 切换至 ICE BofA US 1-Month Treasury Bill Index。当前历史文件是单一修订快照，不是历史 PIT 档案。公开下载不是通用再分发许可；对外使用需保留 Fama 与 French 署名并核对当期条款。

月标签表示收益区间，不给出历史 event_time、available_at、signal_time 或 trade_time。清单下载时间只说明取得当前快照的时间，不能倒推历史可知性。没有信号，也没有未来收益标签。

## 模型、推断和解释

对资产 i 和月份 t，目标为 y(i,t) = R(i,t) − RF(t)，模型为：

\[
y_{i,t}=\alpha_i+\boldsymbol\beta_i^{\mathsf T}\mathbf f_t+\varepsilon_{i,t}.
\]

RF 只从含股息资产总收益扣一次；Mkt-RF、SMB、HML、RMW、CMA 是已发布价差，作为因子原值进入右侧。CAPM 取 FF3 文件的 Mkt-RF 和 RF；FF3、FF5 各用对应官方文件的全套因子及 RF。单位为小数月收益。没有内连接丢月、移位或重复百分数转换。

OLS 含截距。Alpha 是在特定样本、模型基准下的条件平均截距；因子集或样本变化会改变它。它不是已证明的定价误差、技巧或未来收益。Beta 是其他入模因子给定时的线性条件载荷。例如 Beta=0.8 表示同月因子价差上升 1 个百分点时，拟合超额收益条件均值对应变化约 0.8 个百分点。这是统计共变，不代表因果。SMB 是小市值减大市值，HML 是高账面市值比减低账面市值比，RMW 是高盈利能力减低盈利能力，CMA 是保守投资减激进投资的发布价差；组合 Beta 不能过度解释成公司层面机制。

主结果的 HAC 标准误使用 Bartlett 核、6 个按月观测行计的滞后、有限样本修正和 t 参考分布。另对 3、6、12 月滞后计算全部系数的标准误、区间和 p 值。改变 HAC 带宽不改变 OLS 点估计；它会影响推断。HAC 不会补出遗漏变量、解决内生性、消除结构变化或验证误差假设。小样本区间和 p 值是依赖假设的近似。

R² 表示样本内相对均值基准减少的平方误差比例；调整 R² 对自由度调整。含截距 OLS 的残差样本均值接近零。我们核验同一 120 月目标的 ddof=1 方差满足 Var(y)=Var(fitted)+Var(residual)。这是 OLS 投影的样本内会计恒等式，不是因果分解或未来预测能力。因子可能相关，所以不把边际 Beta 转成互相独立、可加总的因子风险份额。

Alpha 的 9 项检验族是三个固定资产乘三个固定模型；报告名义 HAC p 和 Holm step-down 调整值。Holm 只覆盖这九个已展示截距，不覆盖其他模型搜索、因子定义或窗口选择。Beta 区间是逐项区间，未校正整个规格搜索。

OLS 与四个月手算例见[第15章§6及§8](../../../part03/chapter15/content.md)，Bartlett HAC 夹心矩阵逐步数值例见该章§6.4。表中95%区间为逐项区间；Holm调整只作用于九个截距的p值，这些区间不是同时置信区间。

## FF3 与 FF5 因子差异

主结果保留各自官方发布序列。2010–2019 共同列差异为：

| 字段 | 最大绝对差（小数 / 月） | 不同月份数 |

| SMB | 0.0137 | 119 / 120 |
| HML | 0 | 0 / 120 |
| RF | 0 | 0 / 120 |

两份原始文件都声明 202608 CRSP 版本；本地都只转换一次单位，所选 HML 与 RF 完全相同，但 Mkt-RF 与 SMB 不同。SMB 的定义差异已有官方依据：[FF3 构造说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_factors.html)使用规模×账面市值比的六个组合；[FF5 构造说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_5_factors_2x3.html)将账面市值比、盈利、投资三组规模价差平均。因此不能把 SMB 的构造差异一概称为未知。本项目尚未用底层组合逐项复算各月差异；Mkt-RF 文件数值差异的具体原因也仍未查明，不猜测是舍入、修订或发布错误。共同因子取值不完全相同，因此 FF3 与 FF5 不是严格嵌套模型；不作两者嵌套 F 检验，也不把 R² 上升全部归因于新增 RMW/CMA。若要隔离增量作用，应固定同一基准因子再加入 RMW/CMA，并标成自定义组合，作为新研究。

成本、融资和借券在本项目**不适用**：没有信号、目标仓位、换手、订单、执行价格或交易账本。没有假定零成本，也没有把月 Alpha 年化成策略收益。

若后续研究净 Alpha，需新增可执行信号和生成时点、历史资产池与退市/行业成分、当时可用数据版本、权重与调仓规则、下单/成交时刻、成交价与买卖价差、佣金和税、市场冲击、融资与借券成本、股息和公司行动规则，以及逐日/逐笔持仓、订单、成交和现金账本。还需事前固定评价方案以避免使用未来因子或修订输入。本次数据不含这些字段，不能回答可执行性、净收益或未来交易优势。

结论只限于三个当前修订的行业组合历史序列。回归是观察性条件关联，不是因果设计；样本有限；Alpha 随因子基准而变；FF3/FF5 的 SMB 构造差异已知，但逐月差异未逐项复制，Mkt-RF 文件数值差异的具体原因未查明；没有 PIT 时间戳。HAC 与 Holm 不能覆盖所有未跑规格，也不建立未来优势。
