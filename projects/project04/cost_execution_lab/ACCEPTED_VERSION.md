# Cost and Execution Teaching Lab: Scope

This teaching material connects Chapters 35–36 to constructed cost and execution examples. The examples use seed `20261210`; they demonstrate ledger and fee methods but do not establish real-market alpha, costs, or capacity. Full real-data Project 4 research has not been performed.

Start with [Chapter 35](../../../notebooks/ch35_execution_ledger_constructed.ipynb), [Chapter 36](../../../notebooks/ch36_implementation_shortfall_constructed.ipynb), and this directory’s [lab guide](README.md).

For a new run, use a new empty output directory. R2R5 directory names in older examples are historical labels; do not overwrite existing results or infer an algorithm version from a directory name.
