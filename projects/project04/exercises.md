# 项目4：新编整合教学练习

本组为构造型整合教学扩展，使用独立P4-Txx题号；不是历史P4原题，也不是新的真实市场研究。原成本Exercise 1–6及其[完整答案](cost_execution_lab/solutions.md)保留原身份。本组[完整答案](solutions.md)在同项目独立列出；先读[导读](READER_GUIDE.md)、第29–31章和成本材料。

## 共用输入与简化

三个共同价格观测日为D0=2026-01-30、D1=2026-02-02、D2=2026-02-27。D0收盘决策，lag=1按下一价格索引D1执行。60个构造证券S01..S60：前30为行业G1，后30为G2，每行业前15名的已处理score为+1，后15为−1；共同规模暴露设为0。score是给定的已处理教学输入，不重新估计七字段alpha，不冒充原240公司×96月DGP。D0均已上市且有完整score，支持集门槛为至少60名；行业去均值和gross2比例恢复为本题组合步骤，其他实际研究门槛仍须另核。

用于讲版本的S01同一报告期v1，D0 14:00发布、14:05入库，利润10/权益100；v2为D0 16:30发布、D1 09:45入库，利润5/权益50。两次ROE碰巧同为10%，不允许拼接版本。

S60在D1退市，每股清算2；S02在D2退市，每股清算2。其他证券全期存活。初始NAV/现金1000 USD、无持仓；执行价均10 USD，D1收盘S01为11、其他存活者为10，D2收盘仍同价。S60自D1、S02自D2无有效行情，以NaN表示，并提供明确退市事件。无利息、股利、拆股、冲击、借券费、整股约束或追加保证金；费率0.001按总成交名义金额收费。基础引擎须显式allow_short=True、max_gross=2；这不证明真实可借券。

## P4-T01：版本、支持与信号

1. D0收盘允许哪个版本？D1收盘能否用v2？若D1 09:30前决策又如何？解释5/100为什么不合法。
2. 用生成规则计算两行业的均值、60名支持、gross2后的每名权重、net与各行业净权重。
3. D1还剩59名，能否重新生成满足≥60门槛的新信号？D0原信号中S60的权重应如何保存？区分当时信号与执行资格。

## P4-T02：执行副本、扣费净值与实际持仓

1. D1执行时把S60置0且不重缩其余59名。计算执行副本gross/net与现金目标，说明基础run_backtest直接收到原非零退市目标会发生什么。
2. 求扣费净值V′、手续费、各存活证券股数和现金；列出D1收盘NAV和S01实际收盘权重。为什么它不等于1/30？
3. D2如何清算原有S02持仓？求清算现金、价格损失及最终NAV。分别说明S60退市和S02退市为何不能一律“删列不计损失”。不得用执行副本覆盖D0信号或恢复gross/中性。
4. 按本题小规模输入调用基础账本，核对股数、费用、现金、NAV与reconcile；不要运行完整P4/A6 CLI、Notebook或历史研究。答案给出可独立核查的表和入口代码。

## P4-T03：标签可得性、前推选择与结果身份

这是独立的小标签时间轴，不把其中少量样本称为通过60名选股门槛。样本起点i=0..14，标签区间(i,i+2]，a_i=i+2，但a_4=7。拟合/预测在6，测试起点6..8；同端点先结算入库，再拟合预测。

1. 候选历史0..5中哪些可训练？与测试区间是否重叠？按本章后置定义是否还有Embargo？
2. 内层验证A：在2用可得历史训练、验证样本2；内层验证B：在3训练、验证样本3。分别列训练行。给定验证标签(1,−1)，两个候选模型的预测分别为A=(0.5,−0.5)、B=(1,0)，计算两折MSE并选参。标准化在哪些行拟合？
3. 只对选中的A做外层测试，标签为(0.2,−0.2,0)，预测(0.1,0.1,0.1)，求MSE。给定完整族有效名义p=(0.04,0.20)，在5%水平做Bonferroni/Holm。选中A是否等于发现可交易alpha？
4. 区分本题中现场计算的结果与从历史摘要读取的结果。哪些结果为负或为零？要开展真实市场研究，还需要哪些PIT数据、价格/成交字段与使用权？
