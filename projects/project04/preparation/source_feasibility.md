# Project 4 来源可行性

## 实际读取过的来源

**SEC“财务报表数据集”（Financial Statement Data Sets）的说明文件**（readme，副本属原历史独立证据、未随离线包捆绑；此短语是身份说明，不是文件路径，2026-10-06 取得并通读 SUB、TAG、NUM 的字段定义）。读到的事实：

| 事实 | 位置 | 对 PIT 的含义 |
|---|---|---|
| 数据来自 EX-101 附件的 XBRL，覆盖 10-K、10-K/A、10-Q、10-Q/A 等表单，提交日期从 2009-04-15 起 | 第 2 节 | 2009 年之前没有；覆盖只含 XBRL 提交的公司 |
| 所有数值是“as filed”，未更正，含修订与重复 | 第 2、3 节 | 保留重述版本，PIT 选取要靠 `accepted` 排序 |
| SUB 一行一份提交，主键 `adsh`；字段含 `cik`、`sic`（提交日的值）、`fye`、`form`、`period`（资产负债表日）、`fy`、`fp`、`filed`、`accepted`（受理日期与时间；5:30pm EST 之后受理的算次一营业日提交）、`prevrpt`（该提交后来被修订过） | 5.1 | `accepted` 可作 `available_at` 的来源；`period` 对应 `period_end`；`prevrpt` 标出被修订的提交；`sic` 是提交时的行业，可作当时已知的标签 |
| NUM 的主键 `adsh, tag, version, coreg, ddate, qtrs, uom`，`value` 未缩放；`qtrs = 0` 表示时点值 | 5.3 | 年度流量项要 `qtrs = 4`、存量项 `qtrs = 0`；单位 `uom` 要核对 |
| 数据按季度发布，季度最后一个营业日 5:30pm EST 之后受理的提交进入下一季度发布 | 第 1 节 | `ingested_at` 不能早于数据集的发布时间；用季度包时，入库时点远晚于 `accepted` |

**读到的限制与未读的部分。** readme 没有说明 `accepted` 的时区（只在说明里提到 EST）；转换成 UTC 之前必须核对。XBRL 标签（如净利润、资产、权益、收入、销售成本、销管费用、利息费用、经营现金流）到字段契约的映射，各标签的覆盖率与自定义标签的比例，TAG 表的取值，**没有读**，也没有下载任何季度包。因此下面的“候选标签”只是待核对的清单，不是已验证的映射。

## 结论

在用户提供价格、市值与历史股票池之前，完整的 Project 4 无法用真实数据执行；SEC 财报数据集可以提供 2009 年起的 as-filed 基本面与受理时间，但需要先核对标签映射、`accepted` 的时区和年度值筛选。准备层因此只用构造数据演示规则，不得声称任何真实公司的结论。
