# Project 4 缺口表

| 缺项 | 影响 | 本层怎么处理 | 谁来补 |
|---|---|---|---|
| 逐股时点基本面（含重述版本、`accepted`、上年比较余额） | 无法做真实的价值与质量信号 | 构造宇宙演示规则；SEC 数据集的实际读取范围见 `source_feasibility.md`；标签映射、时区与年度值筛选未核对 | 用户提供或授权下载；下载后核对 |
| 逐股价格与总回报、退市收益、公司行动 | 无法做动量与标签 | 构造总回报；退市月 $-25\%$ 是设定 | 用户提供或授权数据源 |
| 历史股票池与成分变更 | 幸存者偏差 | as-of 成员（构造）；不声称真实宇宙 | 同上 |
| 市值与流通股数的历史 | 价值比率与规模中性化 | 构造月末市值 | 同上 |
| 行业分类的历史版本 | 中性化的时点性 | 构造静态标签；SEC `sic` 随提交 | 同上 |
| 日度价格与交易日历 | “收盘信号在下一可交易时点执行” | 月度近似（相差至多一个交易日），在 `pit_event_graph.md` 规则 6 说明 | 同上 |
| beta 与市场数据 | beta 与暴露检查 | 未实现（只检查行业与规模暴露） | 完整 Project 4 阶段 |
| 交易成本、借券与融资、容量 | 净收益 | 本信号层没有；另有构造成本/执行教学，不提供真实借券或容量证据 | 完整 Project 4 阶段 |
| walk-forward 回测、因子消融与稳健性、研究报告 | 完整项目 | 本信号层没有；另有历史构造账本/成本报告，须区分重放与新算，不等于真实项目完成 | 完整 Project 4 阶段 |
| 数据授权与许可 | 能否使用与再分发 | 没有下载任何受限数据 | 用户确认 |
| EV 桥的少数股东权益、优先股、非经营资产 | 真实公司的 EV/EBITDA 与第24章定义不对账，差额方向与大小取决于缺失项 | `versions` 无这三个字段；契约显式假设为零（只在构造宇宙成立），不伪造数据 | 真实数据阶段补字段并对账 |

本表是信号层真实输入缺口，不否认已存在的构造账本与成本教学。上市支持集投影已按当前C13协议纠正；真实逐股数据、交易资格和融资借券缺口仍存在。
